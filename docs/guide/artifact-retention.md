## 로컬에만 남기는 파일

- 반복 렌더링한 프레임 이미지, 동영상, 대용량 모션 교환 덤프와 일반 실행 로그
- 이미 반입된 PNG의 납품용 복사본, ZIP 묶음, PDF 출력본, 문서에 근거로 채택되지 않은 검토 화면
- 포트폴리오 제작 중 내려받은 웹 페이지·외부 도구 및 촬영 결과
- 임시 소스·프리팹 백업, Python 캐시, Blender 연결·시작 상태 점검 도구, 대화 첨부파일
- 문서가 완료 화면으로 사용하지 말라고 명시한 `ingame-first.png`, `ingame-latest-final.png`와 채택 전 `dq-prototype.png`

재생성 가능 여부가 불확실한 파일도 삭제하지 않았다. 특히 로컬 백업과 검토 중간본을 무조건 삭제해도 된다는 의미는 아니다.

## 제작 코드의 사용 범위

이번에 보존한 코드는 과거 제작 절차의 기록이다. 범용 도구로 정비하거나 실행 검증한 것은 아니다. 당시 버전의 Blender 오브젝트·메시 정점 순서·리그 이름, Unity 씬과 에셋, 로컬 절대 경로와 설치된 라이브러리에 의존한다. 일부 스크립트는 실행 즉시 씬·에셋을 변경한다.

`tmp/` 아래의 Python 파일은 서로를 import하거나 기존 경로를 참조하므로 위치를 유지했다. `.cs.txt`는 Unity 에디터에서 실행했던 코드 조각이며 독립 C# 프로젝트가 아니다. 파일명을 참조하는 제작 데이터를 함께 남겼지만 모든 버전의 제작 과정을 새 환경에서 재현할 수 있다는 보장은 없다. 재사용하려면 입력 경로·버전·의존성을 먼저 확인하고 별도 작업 사본에서 검증한다.

기획서에 기록된 Blender `.blend` 제작 원본은 저장소 밖 `Desktop/Train_Survival_Blender/Raccoon_Production` 등에 있다. 이번 선별은 그 파일들을 반입하거나 백업하지 않았다. `output/raccoon-grip-v5/CH_Raccoon_TP.before.fbx`는 기획서에 보존 대상으로 명시된 교체 전 반입본이므로 별도 보존했다.

## 이후 파일을 추가할 때

`.gitignore`는 세 작업 폴더에 새로 생기는 파일을 기본 제외한다. 이미 추적 중인 611개 파일은 계속 변경 사항에 표시되고 일반적인 커밋으로 갱신할 수 있다.

새 제작 원본·도구·필수 검증 근거는 내용을 검토한 뒤 해당 파일만 `git add -f -- <파일 경로>`로 등록한다. 폴더 전체를 강제 추가하지 않는다. 새 범용 도구는 `tools/`, 게임에 사용하는 결과물은 `Assets/`, 설명과 승인 근거는 `docs/`에 두는 것을 우선한다.

선별된 기존 파일의 커밋 날짜는 파일 최종 수정 시각(한국 시간)을 사용한다. 이 보존 정책과 목록의 작성일은 2026-11-05이다. 기존 파일의 내용은 수정하지 않았다.
