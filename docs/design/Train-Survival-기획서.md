## 2. 코어 게임 루프

```
[낮] 집게로 자원 채집 → 제작/건설/요리/열차 증설
        ↓
[밤] 몬스터 웨이브 방어 (전투 자원 소모)
        ↓
[Day +1] 난이도 상승 → 3~5일마다 지역(계절) 전환
        ↓
[최종] 우주 진입 건축물 완성 → 클리어 or Day 챌린지 계속
```

- 낮에도 소수 몬스터가 습격하며, Day가 진행될수록 낮 습격 빈도·수 증가 → 후반에는 "채집 인원 vs 경계 인원" 분담이 전략 요소.
- 연료는 상시 소모되는 기본 압박 자원. 연료 고갈 = 감속 → 몬스터 추격 위기 연출.

### ⚠ 주기 축소에 따른 밸런스 노트
지역 주기가 15일 → 3~5일로 줄면서 **비축·건설에 쓸 수 있는 낮의 총량이 약 1/3로 감소**한다. 따라서 아래 항목의 동반 조정이 필요하다.
- 제작/건설 비용, 요리 재료 요구량, 강화 비용을 주기에 맞춰 하향.
- 다음 지역 예고 연출은 "지역 마지막 1~2일"로 앞당김 (예: 사막 진입 전 물 비축 경고).
- 한 지역에서 할 일을 2~3개의 명확한 목표로 압축 제시 (예: 숲 = 물탱크 + 기본 무기 + 방어벽).

## 3. 자원 채집 — 집게(하푼) 시스템

### 3.1 단계 (3단계 체계로 통합)

| 단계 | 명칭(안) | 기능 |
|---|---|---|
| 1단계 | 기본 집게 | 소형 자원(돌, 나뭇가지, 열매) 낚아채기. 사거리 짧음 |
| 2단계 | 강화 집게 | 중형 자원 채집. **나무에 발사 시 나무를 통째로 뜯어오는 연출**. 사거리·릴 속도 증가 |
| 3단계 | 파쇄·자기 집게 (통합) | 바위·광맥 파쇄 채집 + 금속/기계 부품·유적 아이템 자기 회수. 최종 단계 |

### 3.2 확정 시스템
- **전투 활용 (확정)**: 몬스터를 낚아채 기차 바퀴/톱니 쪽으로 끌어 처형하거나, 아군 앞으로 끌어와 협동 처치. 열차에 매달린 몬스터를 뜯어내는 용도로도 사용.
- **미스 페널티 (확정)**: 빗맞으면 릴 회수 시간 발생(수 초간 재발사 불가). 조준 손맛과 낮 채집의 긴장감 유지. 상위 단계일수록 회수 속도 증가로 페널티 완화.

### 3.3 추가 아이디어 (미채택, 보류)
- 대형 자원 2인 동시 집게 협동 채집.

## 4. 지역(계절) 설계 — 3~5일 주기

지역당 **3~5일** (확정: 15일 → 축소). 지역별 정확한 일수는 TBD이며, 아래는 기준안이다.

| 항목 | 숲 (봄) | 사막 (여름) | 황금빛 대초원 (가을) | 북극 (겨울) |
|---|---|---|---|---|
| 기준 일수(안) | 5일 (Day 1~5) | 4일 (Day 6~9) | 4일 (Day 10~13) | 3일 (Day 14~16) |
| 난이도 | 1 | 4 | 2 | 4 |
| 식량 | 2 | 1 | 4 | 0 |
| 식수 | 3 | 0 | 2 | 0 → 후반 얼음 정화 |
| 자원 | 3 (기초) | 1 (특수) | 2 (식량 위주) | 2 (강화/아이템) |
| 핵심 규칙 | 기반 구축·물 비축 | 낮 고온/밤 급랭, 물 관리 | 식량 대량 비축·보존 | 극한 추위·동상, 비축분 소모 |

### 4.1 숲 (봄) — 튜토리얼과 기반
- 목재·돌·섬유·가죽 등 기초 자원. 집게 조작, 제작대, 첫 방어전 학습.
- 숨은 목표: **물탱크 건설 + 식수 비축** (사막 대비). 마지막 1~2일에 사막 예고 연출.

### 4.2 사막 (여름) — 첫 번째 시험대
- 낮: 체온 상승(열사병) / 밤: 급랭. 온도·생필품 관리가 핵심.
- 자원 구성 — **"금속·화약·보존"의 군수 지역**:

| 자원 | 용도 |
|---|---|
| 고철·기계 부품 (모래에 묻힌 난파 열차) | 무기 제작, 열차 개조 |
| 유리 (모래 가공) | 물탱크 강화, 온실 차량, 조준경 |
| 초석·유황 | 화약 → 탄약 제작 |
| 선인장 | 소량의 물 + 섬유 (비상 수단) |
| 소금 | 식량 보존(육포 등) → 북극 대비 |

### 4.3 황금빛 대초원 (가을) — 풍요와 폭풍 전야
- 벼 수확 → 밥·요리 시스템의 기초. 사냥감 풍부.
- 핵심 목표: **북극행 식량 대량 비축** (소금 절임/훈제). 대초원의 비축량이 겨울 생존 기간을 결정.
- 몬스터 무리(스탬피드) 이벤트로 방심 방지.

### 4.4 북극 (겨울) — 최종 시험
- 상시 혹한, 밤 극한 추위, **동상(부위 디버프: 이동/조준 저하)**.
- 식량 수급 거의 불가 → 비축분 소모전. 얼음은 정화 장치로 식수화.
- 자원: 강화석·희귀 금속·유적 아이템 — 무기/장비 최종 강화 및 **우주 진입 건축물 핵심 부품**의 유일한 출처.

### 4.5 최종 지역 이후 (챌린지 순환)
- 지역 재순환(숲→사막→…) + 난이도 배율 상승, 몬스터 변종 등장.

## 5. Day / 난이도 시스템

- Day 경과에 따라 몬스터의 **수 → 체력/공격력 → 공격 방식(패턴)** 순으로 강화. 새로운 행동(열차 매달리기, 지붕 침투, 원거리 투사체, 연료칸 노리기)을 지역 전환마다 추가.
- **지역 마지막 밤 = 대형 웨이브 + 지역 보스** ("지역 졸업 시험"). 주기 축소에 따라 별도 미니보스 주기는 폐지하고, 지역 중간 밤에 강화 웨이브 1회 배치.
- 낮 습격도 Day에 비례해 증가.

## 6. 전투 및 장비

### 6.1 전투 기본
- 1인칭 총기 중심 슈팅. 밤 방어전은 열차 위 진지전 + 몬스터 승차 저지.
- 탄약은 제작 자원(화약 = 사막 유래) → 절약 압박 유지.
- 집게도 무기 슬롯 사용 가능 (3.2 참조).

### 6.2 무기 체계 — "개인 화기 + 근접 보조 + 열차 거치 무기" 3축

| 축 | 무기 | 역할 |
|---|---|---|
| 개인 화기 | 리볼버/권총 | 기본 지급, 탄약 저렴 |
| | 샷건 | 승차한 근접 몬스터 처리 (좁은 열차 공간과 궁합) |
| | 볼트액션 라이플 | 원거리 접근 저지 (저격 역할) |
| | 화염방사기 | 다수 저지 + 북극에서 주변 난방 효과 |
| 근접 보조 | 마체테/도끼 | 탄약 0일 때 최후 수단 (도끼는 채집 겸용) |
| | 창(작살) | 리치 확보, 매달린 적 밀어내기 |
| 설치형 | 자동 터렛 | 1인 플레이 보완, 탄약 다량 소모 |
| | 거치 기관총 | 밤 웨이브 화력, 1인 전담 조작 |
| | 지뢰/철조망 | 낮에 미리 설치하는 준비형 방어 |

- 설계 원칙: 탄약 3종 이내(권총탄/산탄/소총탄) · 근접은 무한 사용이되 위험 · 화기 강화는 북극 자원.

### 6.3 장비 (의류/방어구)

| 장비 | 효과 | 비고 |
|---|---|---|
| 가죽 옷 | 피해 감소(소) + 체온 상승(대) | 북극 필수 / 사막 낮에는 역효과 |
| 방어구(금속) | 피해 감소(대) + 체온 상승(소) | 전투 특화 / 사막 낮 소량 열 피해 디테일 |
| 사막 로브 | 낮 열 차단 + 밤 보온 소량 | 사막 전용 해법 |
| 방한 세트 | 부위별 동상 방지 | 북극 동상 시스템 연동 |

## 7. 확정 시스템 (v0.2 승격)

### 7.1 열차 증설/개조 (확정)
- 차량 칸 제작·연결: 온실칸, 무기고칸, 침실칸, 정수칸, 온돌칸 등. 기차 = 성장하는 기지.
- 트레이드오프: 칸이 늘수록 연료 소모·방어선 증가.
- 파괴/수리 규칙은 §9 참조 (칸 단위 파괴와 직접 연동되는 핵심 시스템).

### 7.2 역할 장비 특화 (확정)
- 강제 직업제가 아닌 **장비 기반 소프트 역할**: 기관사(연료/속도), 포수(거치 무기), 채집가(집게 특화), 제작자(수리/건설 효율) 전용 상위 장비 제공.
- 1인 플레이 시 장비 교체로 모든 역할 수행 가능해야 함.

### 7.3 요리 시스템 (확정)
- 대초원 벼 = 밥 기반 요리. 요리별 버프: 보온(북극 대비), 체력 재생, 야간 시야, 스태미나 등.
- 소금(사막) 기반 보존식으로 지역 간 비축 루프와 연결.

### 7.4 날씨 이벤트 (확정)
- 지역별 날씨: 모래폭풍(시야 차단), 폭설(집게 사거리 감소), 뇌우, 혹한파 등.
- 낮/밤 루프의 변주 장치이자 지역 정체성 강화 요소.

### 7.5 미채택/보류
- 정거장·분기 선로 탐사 이벤트 (추후 재검토).
- 대형 자원 2인 협동 채집.

## 8. 최종장

### 8.1 진입 조건 및 선택 분기
- 특정 건축물(가칭: **궤도 도약 기관**) 완성 시 우주 진입 가능.
- 선택지: **① 발사 (클리어 루트)** / **② 잔류 (Day 챌린지, 언제든 발사 가능)**.

### 8.2 진입 연출 — **B안 확정: 초가속 → 공간 왜곡**
1. 발사 결정 → 기관 점화, **가속 방어전** 시작: 몬스터 전 병력의 최후 추격. 플레이어는 연료를 계속 투입해 가속 게이지를 채우며 열차를 방어. *(연출을 플레이어블 이벤트로 구현)*
2. 게이지 만충 → 차창 밖 풍경이 빛줄기로 늘어지는 **공간 왜곡**, 화면 백화(白化).
3. 정적. 창밖에 별과 지구 — 기차는 별빛 궤도 위를 달린다. (완전한 무음 → 카타르시스)
- 세계관 장치: 왜곡의 원리는 북극 유적 기술(고대 동력원)로 설명 → 개연성 확보.

### 8.3 최종장 콘텐츠 (추천안 유지, 상세 미정)
- 무대: 성간 궤도를 달리는 우주 열차 (신규 관리 자원: 산소).
- 구성: ① 잠입 몬스터 소탕(내부 근접전) → ② 최종 보스 "근원(The Origin)" 추격전 — 거치 무기 총동원 + **집게로 약점을 뜯어내는 피날레** → ③ 엔딩 + 뉴게임+/무한 챌린지 해금.
- 서사: "몬스터가 기차를 쫓은 이유"를 최종장에서 해답 제시.

### 9.3 아트 톤 — 추천안
**추천: 스타일라이즈드(세미 카툰/로우폴리) + 디젤펑크 열차 디자인 언어**

| 근거 | 설명 |
|---|---|
| 지역 색채 대비 | "황금빛 대초원", 붉은 사막, 백색 북극 등 지역 정체성이 채도 높은 스타일라이즈드에서 가장 선명하게 살아남 |
| 협동 게임 톤 | 4인 협동은 공포보다 "긴박+유쾌"가 리텐션에 유리 (레퍼런스: Deep Rock Galactic, Raft, Valheim) |
| 제작 효율/최적화 | 밤 웨이브의 다수 몬스터 렌더링, 지역 4종 제작 비용 측면에서 리얼 톤 대비 압도적으로 유리 |
| 심의 유연성 | 몬스터 처형(집게 연출 등)을 과도한 고어 없이 표현 가능 → 등급 관리 용이 |
| 열차 정체성 | 기차·집게·거치 무기는 리벳/파이프/증기의 **디젤펑크 소품 언어**로 통일 → 스타일라이즈드 안에서도 세계관의 무게감 유지 |

- 대안 (차선): 리얼 기반 스팀펑크 톤 — 몰입감과 성인 타깃 소구는 높으나, 제작 비용·최적화 부담과 4계절 색채 표현의 채도 제약이 큼. 소규모 팀이라면 비추천.
