## 0. 사전 준비

- [x] **이번 차수는 씬 변경이 없다** — 코드 + 에셋 2건뿐:
  - `TrainExpansionSettings._demolishRefundRatio = 0.5` (반환 비율)
  - `RepairHammerSettings._demolishHoldSeconds = 0.5` (X 홀드 시간)
- [x] 건자재는 **숫자패드 9**, 특정 건축물 손상·파괴는 **숫자패드 6** (망치로 겨눈 부위)
- [x] 1차의 창고 칸당 1개 임시 가드가 **해제**됐다 — 같은 칸 창고 2개가 정상이다

**기준 수치** (전부 에셋)

| 항목 | 값 | 확인 |
|---|---|---|
| 반환량 | floor(비용 × 0.5) — 화덕 3 → **1** · 창고 4 → **2** · 강화 난방로 7 → **3** | 반환 자원 = 목재 (카탈로그 `_refundResource`) |
| 홀드 | X **0.5 s** + HUD 게이지(%) | 놓거나 표적이 바뀌면 리셋 |

## A. 철거 (§2.5 — 결정 ④·⑤·⑧)

- [x] **A1** 망치로 건축물을 겨누면 HUD에 **"[X 홀드] 철거 (반환: 목재 N)"**이 뜬다 —
      N이 위 표와 일치한다
- [x] **A2** X를 누르면 **"철거 중… NN%"** 게이지가 오르고, 0.5 s 충족 시 철거된다.
      중간에 놓으면 리셋된다 (오철거 방지)
- [x] **A3** 조준을 다른 건축물로 옮기면 게이지가 리셋된다 (표적 전환 시 이어지지 않음)
- [x] **A4** **가방 여유** — 반환 목재가 가방에 들어오고 보따리가 생기지 않는다 (자원 소실 0)
- [x] **A5** **가방 가득** — 들어가는 만큼 수납 + **잔여가 보따리 1개**로 철거 자리 갑판에
      나온다. 보따리 해체로 전량 회수된다 (부분 수납 분기)
- [x] **A6** **가방 전무(가득 채운 상태)** — 반환 전량이 보따리 하나로 나온다
- [x] **A7** 철거 배너 "**{종류} 철거 (#N번 칸)**"가 전 피어에 뜬다 (파괴 배너와 색 구분 — 노랑)
- [x] **A8** **이탈 칸 위 건축물은 철거 불가** — 철거 안내 자체가 뜨지 않는다 (피해 규칙과 동일)
- [x] **A9** 클라이언트도 철거 가능 — 반환은 **철거한 사람** 가방으로 들어간다
- [x] **A10** 철거된 자리에 즉시 재설치 가능 (셀 해방)

## B. 몬스터 파괴 무반환 — 회귀 (§2.5-5)

- [x] **B1** 몬스터(또는 숫자패드 6)로 건축물을 **파괴**하면 자원 반환이 **없다** —
      배너도 "파괴!"(빨강)로 뜬다. 철거(X 홀드)만 반환 경로를 탄다
- [~] **B2** 창고를 몬스터가 파괴하면 **내용물 보따리만** 나온다 (반환 자원 보따리 없음) —
      **부분 확인** (2026-08-19): QA 파괴 키(숫자패드 6)로 파괴가 일어나는 것까지는 확인.
      "내용물 보따리만 나오고 반환 자원 보따리는 없다"는 무반환 회귀 자체는 재확인 대상

## C. 창고 저장 모델 개편 (§2.8 — 결정 ⑦)

- [x] **C1** **한 칸에 창고 2개** 설치가 성립한다 (1차 가드 해제 확인)
- [x] **C2** 창고 2개에 서로 다른 내용물을 넣고, **각각 조준(근접 + 시선)하면 그 창고**가
      열린다 — 내용물이 섞이지 않는다
- [x] **C3** 창고 하나를 파괴하면 **그 창고의 내용물만** 보따리로 나오고, 남은 창고는 무사하다
      (swap-remove 후 Id 매핑 무결 — EditMode로도 고정)
- [x] **C4** **창고 철거** — 내용물 보따리와 반환 자원 보따리가 **별개로 2개** 나온다
      (§2.5-4: 묶으면 해체 UI가 혼합 목록이 되므로)
- [x] **C5** **칸 이탈 → 재결합** — 이탈 중 창고 내용물이 보존되고 재결합 후 그대로 열린다
      (블록이 Id 기준이라 칸 이동과 무관)
- [x] **C6** **칸 파괴** — 그 칸 창고들의 내용물이 지상 투척 보따리로 나온다 (현행 규칙 유지)
- [x] **C7** **소실 칸 자리 재건** — 옛 창고 블록이 보따리 없이 소실된다 (안전망 규약 유지)
- [x] **C8** **후발 접속** — 창고 여러 개 + 내용물이 있는 상태에서 새 클라 접속 시
      전부 동일하게 조회·이동 가능하다
- [x] **C9** QA 동시 경합(숫자패드 4) — 총량 보존이 새 블록 구조에서도 성립한다
