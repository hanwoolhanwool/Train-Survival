> **1차 목표** (계획 문서): **중도 이탈한 클라이언트가 재접속하면 같은 플레이어로 복귀한다** —
> 인벤토리·장비·집게 등급·생존 스탯이 끊김 시점 그대로다. Steam 의존 0 — UnityTransport·MPPM으로
> 검증하고 식별자는 `IPlayerIdentityProvider` 뒤에 격리했다.
> **검증 구성**: 개발 6원칙에 따라 **호스트 1 + 클라이언트 1** (MPPM 가상 플레이어).
> **되살림/편입**: M5 1차 **H3**(재접속 인벤토리 복원 — TBD ②)을 A 구역으로 되살리고,
> **M4 검증 ④**(후발 지형 표시)를 E 구역으로 편입했다.
> **M5 잔여 검증 56건**: 준비 문서 결정 ⑦(권장 ⓑ = 별도 "잔여 소화" 세션 분리)에 따라
> 이 문서에는 편입하지 않는다 — ⓐ/ⓑ 확정은 사용자 결정 대기.

## 0. 사전 준비

- [ ] **이번 차수는 씬·프리팹 변경이 있다** — Boot 씬 `NetworkManager.ConnectionApproval: 1` ·
      Player.prefab에 `PlayerSessionAgent` 부착 (YAML 직접 편집, GlobalObjectIdHash 무변
      확인 완료 = 1135503018). **접속 거부(ClosedByRemote)가 나오면** 양쪽 에디터의 프리팹
      해시를 비교한다 (풀링 프리팹 규칙 메모 참조)
- [ ] Boot 씬에서 Play → 호스트 시작. 클라이언트 = MPPM 가상 플레이어 접속
- [ ] 콘솔을 열어둔다 — 재접속 관련 로그가 판정 근거다:
  - `[PlayerSessionAgent] 끊김 스냅샷 캡처: client=N` (끊김 순간, 호스트 콘솔)
  - `[PlayerSessionAgent] 재접속 복원 적용: client=N respawnPending=…` (재접속 스폰, 호스트 콘솔)
  - `[NgoNetworkSessionService] 중복 식별 토큰 접속 — 기존 연결(clientId=N)을 킥…` (C 구역)
  - `[TerrainTileStreamer] 지역 경계 재판정 — 타일 N장 교체.` (E 구역, 후발 피어 콘솔)

**재현 수단**

| 시나리오 | 조작 |
|---|---|
| 끊김 → 재접속 | MPPM 가상 플레이어 **중지 → 재시작** 후 다시 접속 (Join) |
| 유령 연결 킥 (C 구역) | 타임아웃(10 s) 전에 빠르게 재접속 — 창을 닫지 않고 강제 재접속이 더 확실 |

**기준 수치·경로**

| 항목 | 위치 | 값 |
|---|---|---|
| 식별 토큰 파일 | `%USERPROFILE%\AppData\LocalLow\<회사>\<제품>\PlayerIdentity\token-<해시>.txt` | 인스턴스(dataPath 해시)별 분리 — 결정 ③ |
| 보존 유예 | 코드 (`PlayerSessionRegistry`) | 세션 끝까지 (결정 ④) |
| 버프(재생·보온) | — | **복원하지 않음 (결정 ⑤ — 의도적 포기, 결함 아님)** |
| 부활 대기 재개 | 코드 (결정 ⑦) | 사망 시각 + 대기 − 현재 (끊김 시간 포함), 잔여 ≤ 0 = 즉시 부활 |

## A. 재접속 복귀 — 인벤토리·장비·집게·스탯 (M5 1차 H3 되살림)

게스트가 생존 중 끊겼다가 재접속하는 기본 시나리오. 끊기 전에 상태를 만들어 둔다:
자원 채집(2종 이상), 장비 1부위 이상 착용, 집게 2단계 승급, 체력·허기를 일부 소모.

- [ ] **A1** 재접속한 게스트의 **핫바 종류·수량**이 끊김 시점 그대로다 (초기 지급으로 리셋되지 않음)
- [ ] **A2** **착용 장비**(부위 칸)가 그대로다 — 피해 감소·보온 효과도 착용 상태 기준으로 동작
- [ ] **A3** **집게 등급**이 그대로다 (HUD 표기 + 상위 무게 그랩 가능)
- [ ] **A4** **체력·허기·체온**이 끊김 시점 값 부근에서 이어진다 (재접속 사이 자연 감소분은 없음 — 스냅샷 그대로)
- [ ] **A5** **보따리 칸**이 있는 채 재접속해도 보따리 창이 같은 내용물로 열린다 (보관소 id 유효 — 세션 내)
- [ ] **A6** 버프(재생·보온) 잔여는 사라진다 — **정상** (결정 ⑤)
- [ ] **A7** 호스트 콘솔에 캡처·복원 로그가 짝으로 남는다 (0. 사전 준비의 로그 2종)

## B. 부활 대기 중 끊김 → 재접속 (결정 ②·⑦)

- [ ] **B1** 게스트가 **전투 사망**(체력 0) 후 부활 대기 중 끊김 → 대기 시간 안에 재접속 →
      **잔여 시간만** 기다린 뒤 부활한다 (접속을 유지한 경우와 같은 시점 — 처음부터 다시 세지 않음)
- [ ] **B2** 부활 대기 중 끊김 → **대기 시간을 넘겨** 재접속 → **즉시 부활**한다
- [ ] **B3** **이탈 사망**(후미 40 m) 경로도 B1과 같다 — 부활 대기부터 재개
- [ ] **B4** 부활 후 스탯이 기존 부활 경로대로 초기화된다 (사망 중 스탯은 복원되지 않음 — 결정 ②)
- [ ] **B5** 부활 재개로 복귀한 뒤 인벤토리·장비·집게는 A와 동일하게 유지돼 있다

## C. 동일 토큰 중복 접속 — 기존 연결 킥 (결정 ⑥)

- [ ] **C1** 게스트가 끊김 감지(타임아웃) 전에 빠르게 재접속 → 기존(유령) 연결이 킥되고 새 접속이
      승인된다 — 콘솔에 중복 킥 로그, 이후 A와 동일하게 상태 복귀
- [ ] **C2** 킥 경로에서도 스냅샷이 캡처된다 — 새 접속의 복원 내용이 유령 연결의 마지막 상태다

## D. 재접속 위치·스폰 순번 (결정 ① + §0 소규모 5)

- [ ] **D1** 재접속 스폰 위치가 **기관차 갑판 스폰 지점**이다 (끊김 위치가 아님 — 결정 ①)
- [ ] **D2** 여러 번 끊김·재접속을 반복해도 스폰 z가 **뒤로 계속 밀리지 않는다**
      (기존: clientId 기반이라 2 m씩 밀려 열차 밖 이탈 가능 — 접속 순번 기반으로 수정)

## E. 후발 접속 지형 표시 (M4 검증 ④ 재확인)

지역 전환을 만들려면 QA 키로 Day를 넘기거나 지역 일수를 짧게 조정한다.

- [ ] **E1** 호스트가 지역 전환(예: 숲 → 사막)을 **지난 뒤** 게스트가 접속 → 게스트 화면에서
      **과거 구간(후방) 타일이 이전 지역 프리팹**, 전방이 새 지역 프리팹으로 나뉜다
      (기존: 전 구간이 현재 지역 타일)
- [ ] **E2** 경계 위치가 호스트 화면과 게스트 화면에서 같다 (± 타일 1장 이내)
- [ ] **E3** 접속해 있는 동안의 지역 전환은 기존과 동일하게 전방 타일부터 순차 교체된다 (회귀)
- [ ] **E4** 게스트 콘솔에 재판정 로그가 남는다 (접속 직후 1회 — 어긋난 타일 교체)
- [ ] **E5** 오래 주행해도 경계 기록이 무한 누적되지 않는다 — 후방 가시 구간을 벗어난 경계는
      트림된다 (관측: 전환 여러 번 후에도 이상 없음이면 통과)

## F. 회귀·경계 확인

- [ ] **F1** **신규 접속**(세션에서 처음 보는 토큰)은 현행 그대로 초기 지급으로 시작한다
- [ ] **F2** 호스트 단독 플레이(시작·저장 없음 종료)가 기존과 동일하다 — 승인 콜백 경유로 달라진 점 없음
- [ ] **F3** MPPM 가상 플레이어와 본 에디터의 **토큰이 서로 다르다** (결정 ③ 스파이크 확인 —
      토큰 파일이 인스턴스별로 분리 생성됨. 파일 경로는 0. 기준 수치 표)
- [ ] **F4** 세션을 완전히 종료하고 **새 세션**을 시작하면 이전 세션의 스냅샷이 새어 들어오지
      않는다 — 새 세션 첫 접속은 초기 지급 (보존 유예 = 세션 끝까지, 결정 ④)
- [ ] **F5** 재접속 후 이동·그랩·사격·제작·창고 등 기존 조작이 정상이다 (스모크)
- [ ] **F6** Boot 씬 ConnectionApproval 활성화 후에도 기존 씬 전환(Main → Game)·클라 동기화가
      정상이다 (회귀)
