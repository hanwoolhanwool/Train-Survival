# M4 플레이 검증 항목 — 지역·난이도·날씨

작성일: 2026-08-02 · 대상: `feat/m4-region-weather` (커밋 28개) · 상태: **미실시**

> **완료 기준** (개발 가이드 §5 M4): 숲 5일 → 사막 진입의 전체 흐름이 플레이 가능하고,
> 밸런스 수치가 에셋 수정만으로 바뀐다.
> **검증 구성**: 개발 6원칙 1·2에 따라 **항상 호스트 1 + 클라이언트 1**로 확인한다.

## A. 지역 타임라인

- [ ] **A1** Play 직후 HUD에 `지역: 숲 · 1/5일` 표시 + `숲 진입` 배너
- [ ] **A2** 숫자패드 3 ×3 (Day 4) → `다음 지역 예고: 사막 (1일 뒤)` 주황색 표시
- [ ] **A3** 숫자패드 3 ×1 (Day 5) → `오늘 밤 — 지역 마지막 밤, 대형 웨이브` 빨강 표시
- [ ] **A4** 숫자패드 3 ×1 (Day 6) → `사막 진입` 배너 + `지역: 사막 · 1/4일`
- [ ] **A5** Day 10까지 진행 → `숲 · 1/5일 (2주기)` — 재순환과 주기 증가
- [ ] **A6** 2주기 숲의 밤 웨이브가 1주기보다 크다 (순환 난이도 가산 +0.5 → 물량 ×1.5)

## B. 난이도 곡선

밤 진입 시 콘솔의 `[MonsterWaveSpawner] 밤 웨이브 시작: Day N (지역명…), 총 N마리, 간격 Ns, 동시 상한 N, 체력 ×N` 으로 판정한다.

- [ ] **B1** Day가 오를수록 총량↑ · 간격↓ · 체력 배율↑
- [ ] **B2** **Day 5 밤**(숲 마지막) 로그에 `지역 마지막 밤` 표기 + 총량 ×2 · 간격 ÷2 · 체력 ×1.5
- [ ] **B3** **Day 6 밤**(사막 첫날) 물량이 숲 같은 Day 대비 약 1.6배, 체력 ×1.3
- [ ] **B4** 동시 존재 몬스터가 **12마리를 절대 넘지 않는다** (대역폭 방어선 — 배율이 겹쳐도 상한 유지)
- [ ] **B5** 체감상 몬스터가 더 단단해졌는지 (리볼버 처치 소요탄 증가)

## C. 지형·자원 전환

- [ ] **C1** Day 6 진입 후 **약 30초 뒤** 전방부터 모래색 지형이 도착
      → **즉시 안 바뀌는 게 정상이다.** 전방 타일 5장(200 m)이 이미 생성돼 있어 순차 교체된다
- [ ] **C2** 콘솔에 `[TerrainTileStreamer] 지형 타일 전환: 사막` 로그
- [ ] **C3** 사막에서 지상 자원 간격이 눈에 띄게 벌어진다 (12 m → 24 m)
- [ ] **C4** 지형 타일이 뒤에서 사라지고 앞에서 생기는 순환이 끊기지 않는다 (풀 반환 정상)

## D. 체온 (사막)

- [ ] **D1** 숲에서는 체온이 36.5 ℃ 근처로 유지되고 경고가 없다
- [ ] **D2** 사막 낮에 **열차 밖/건축물 없는 칸**에 서 있으면 체온이 오른다
- [ ] **D3** 38 ℃에서 `더위! 건축물 그늘로` 주황 경고 (피해 전 경고)
- [ ] **D4** 39 ℃ 초과 시 체력이 지속적으로 깎인다 — 노출 후 **약 16초**면 도달
- [ ] **D5** **건축물이 있는 칸 위로 올라가면 체온이 내려간다** (약 7초면 정상 복귀) ← M4의 유일한 완화 수단
- [ ] **D6** 건축물이 **없는** 칸 위에서는 완화되지 않는다 (차폐 판정이 건축물 유무를 본다)
- [ ] **D7** 파괴되거나 이탈한 칸의 건축물은 차폐가 되지 않는다
- [ ] **D8** 사막 **밤**에는 반대로 체온이 내려가고 `추위!` 하늘색 경고 → 34 ℃ 미만 피해
- [ ] **D9** 체온 피해로 사망 후 부활하면 체온이 정상(36.5 ℃)에서 다시 시작 — **즉사 루프가 없다**
- [ ] **D10** I 창 캐릭터 상태에도 체온과 `(더위)`/`(추위)` 표시

## E. 날씨 (모래폭풍)

- [ ] **E1** 사막 낮 시작 시 60 % 확률로 발생 — 안 뜨면 숫자패드 3으로 낮을 몇 번 반복
- [ ] **E2** 콘솔에 `[WeatherController] 날씨 시작: 모래폭풍 (Ns, 속도 ×0.65)`
- [ ] **E3** HUD 배너 `모래폭풍 발생 — 시야 차단·감속` + 상태 패널에 `날씨: 모래폭풍`
- [ ] **E4** 화면에 모래색 안개가 끼고 시야가 실제로 줄어든다
- [ ] **E5** **열차 속도(지형 흐름)가 눈에 띄게 느려진다** — 연료가 가득해도 감속된다
- [ ] **E6** 45~90초 뒤 저절로 갠다 — 안개가 걷히고 속도가 원래대로 복귀
- [ ] **E7** 밤이 되면 즉시 갠다 (M4의 날씨는 낮 이벤트)
- [ ] **E8** 폭풍 중 **연료를 투입해도 감속이 유지**되고, 폭풍이 갠 뒤 연료 기반 속도로 정상 복귀
      ← 환경 배율과 연료 감속이 서로 덮어쓰지 않는지 보는 항목
- [ ] **E9** 숲에서는 모래폭풍이 발생하지 않는다

## F. 몬스터 변종

외형이 같아 육안 구분이 어렵다 — **행동과 체감으로 판정**한다.

- [ ] **F1** Day 1~2 밤: 모든 몬스터가 같은 속도·맷집 (일반형만 등장)
- [ ] **F2** Day 3~ 밤: 눈에 띄게 **빠르지만 약한 개체**가 섞인다 (돌진형, 8.5 m/s · 체력 60)
- [ ] **F3** Day 6~ 밤: **느리지만 매우 단단하고 한 방이 아픈 개체**가 섞인다 (돌격형, 체력 220 · 공격 28)
- [ ] **F4** Day 8~ 밤: **멀리서 갑판으로 뛰어오르는 개체**가 있다 (도약형, 도약 사거리 8 m)
- [ ] **F5** 변종이 섞여도 스폰·회수·사망이 정상 (풀 반환 오류 없음)

> 구분이 어려우면 `MonsterWaveSpawner.SpawnOne`에 `DisplayName` 로그를 임시로 넣는 편이 빠르다.
> 필요하면 요청할 것 — 검증용 로그를 추가하고 검증 후 제거한다.

## G. 멀티플레이 정합성 (핵심)

지역·난이도는 RPC 없이 Day 번호에서 각자 파생하므로, **어긋나면 파생 로직이 아니라 Day 동기화 쪽 문제**다.

- [ ] **G1** 양쪽 화면의 **지역명·일차·주기가 항상 일치**
- [ ] **G2** 지역 전환 배너가 **양쪽에서 같은 시점에** 뜬다
- [ ] **G3** 예고·마지막 밤 경고가 양쪽 동일
- [ ] **G4** 모래폭풍이 **양쪽에서 동시에** 시작·종료되고 안개도 함께 낀다
- [ ] **G5** 사막 지형 교체 시점이 양쪽 동일
- [ ] **G6** 클라이언트에서 몬스터 이동이 워프·역행 없이 부드럽다 (변종별 속도 차이가 보간을 깨지 않는지)
- [ ] **G7** 체온은 **각자 자기 것만** HUD에 뜬다 (남의 체온이 섞이지 않는다)
- [ ] **G8** 클라이언트도 건축물 차폐로 체온이 회복된다 (호스트가 위치를 보고 판정)
- [ ] **G9** 클라이언트에서 숫자패드 3을 눌러도 양쪽 Day가 함께 넘어간다

## H. 완료 기준 — 데이터 조정 가능성

**코드 수정 없이 에셋만 고쳐서** 아래가 바뀌는지 확인한다 (Play 정지 → 에셋 수정 → 재시작).

- [ ] **H1** `Region_Forest.asset`의 `DayCount`를 5 → 3으로 바꾸면 Day 4에 사막에 들어간다
- [ ] **H2** `Region_Desert.asset`의 `WaveCountMultiplier`를 바꾸면 사막 밤 물량이 따라 바뀐다
- [ ] **H3** `Region_Desert.asset`의 `DayAmbientTemperature`를 30으로 낮추면 낮 더위 압박이 사라진다
- [ ] **H4** `Weather_Sandstorm.asset`의 `ScrollSpeedMultiplier`를 바꾸면 감속 폭이 따라 바뀐다
- [ ] **H5** `MonsterSettings_Brute.asset`의 `MinDayToAppear`를 3으로 낮추면 Day 3부터 돌격형이 나온다
- [ ] **H6** `RegionTimelineSettings.asset`의 `LoopAfterLastRegion`을 끄면 사막에 계속 머문다
