# M5 3차 플레이 검증 항목 — 건축물 종류화·난방·공유 창고·버리기·제작대·장비

작성일: 2026-08-06 · 대상: `feat/m5-combat-survival` · 상태: **검증 대기**

> **3차 목표** (개발 가이드 §5 M5 차수 분할): `StructureState` 종류화(4종) + 난방 건축물 +
> 공유 창고 건축물 + 아이템 버리기 + 제작대 건축물 + 장비(피해 감소·체온 보정) +
> 사막 밤 온도 9→2 ℃ 복원 — **"밤 추위를 난방·방한복으로 버티고, 창고·버리기로 슬롯 압박을
> 풀며, 건축물 선택(돔/난방/창고/제작대)이 칸의 개성이 되는" 생존 루프가 종단으로 성립**하고,
> 밸런스 수치가 에셋 수정만으로 바뀐다.
> **검증 구성**: 개발 6원칙 1·2에 따라 **항상 호스트 1 + 클라이언트 1**로 확인한다.
> 2차 이월 ②(낮/밤 사이클 실시간 회귀)를 이번 검증에서 겸사 확인한다 (→ H1).

## A. 건축물 종류화 (설치 UX·복제)

- [ ] **A1** 망치로 칸을 겨누면 "우클릭 {종류명} 설치 (소모: …) [R] 종류 변경"이 뜬다
- [ ] **A2** **R 키로 4종 순환** — 온실 돔 → 난방기 → 공유 창고 → 제작대 → 돔. 종류마다 비용 표시가 바뀐다 (창고만 4)
- [ ] **A3** 4종을 서로 다른 칸에 설치 → **외형이 서로 다르다** (돔 구형 / 난방 실린더 / 창고 상자 / 제작대 납작)
- [ ] **A4** 게스트 화면에서도 같은 칸에 같은 종류의 외형이 보인다 (Kind 복제)
- [ ] **A5** 설치 배너가 종류명으로 뜬다 — "난방기 설치! (#n번 칸)"
- [ ] **A6** 파괴된 자리(숫자패드 6 반복)에 **다른 종류**를 새로 지을 수 있다
- [ ] **A7** 몬스터가 새 종류 건축물도 공격한다 (밤 웨이브 — 표적 등록 회귀)
- [ ] **A8** 수리 망치 좌클릭 수리가 4종 모두에 동작한다

## B. 난방·체온 (사막 밤 2℃ 복원)

- [ ] **B1** 사막(Day 6+) 밤 노숙 → 체온이 계속 내려가 **34 ℃ 밑에서 지속 피해** (2 ℃ 복원 확인)
- [ ] **B2** 추위 경고 HUD에 **"추위! 난방 칸 위로"** 행동 지시가 뜬다
- [ ] **B3** **난방기 칸 위**로 올라가면 체온이 회복으로 돌아선다 (실효 17.2 ℃)
- [ ] **B4** 난방기 칸은 **사막 낮 더위를 막지 못한다** (그늘 아님 — 돔과 역할 분리)
- [ ] **B5** 돔 칸은 여전히 낮 더위만 막고 밤 추위를 못 막는다 (기존 계약 유지)
- [ ] **B6** 난방기가 파괴되면 즉시 완화가 사라진다 (체온 다시 하락)
- [ ] **B7** 게스트도 B1~B3 동일 (체온은 호스트 권위 — 서버 계산 정합)

## C. 공유 창고

- [ ] **C1** 창고 칸 근접 + 시선 → "E — 공유 창고 (#n번 칸)" 프롬프트 → E로 창 열림 (시점 정지·커서 표시)
- [ ] **C2** 창고 창 = 창고 10칸 + 핫바/가방 — 드래그로 **넣기·빼기·창고 내 재배치**가 된다
- [ ] **C3** 같은 자원을 겹치면 **병합**(스택 상한까지, 잔량은 원래 칸에 남음), 다른 아이템과는 **스왑**
- [ ] **C4** **무기·장비도 창고에 보관**할 수 있다 (잉여 무기 처분 경로 — 2차 B5 슬롯 압박 해소)
- [ ] **C5** 호스트가 넣은 물건이 게스트 창에 보이고, 게스트가 꺼내 가져갈 수 있다 (팀 공용)
- [ ] **C6** 창고 2개를 다른 칸에 설치 → **각자 독립 내용물** (창고별 개별 저장고)
- [ ] **C7** 창고 파괴(숫자패드 6 반복) → **내용물 소실** — 창이 열려 있었다면 닫힌다
- [ ] **C8** 범위를 벗어나면 창이 자동으로 닫힌다
- [ ] **C9** 창고 창이 열린 동안 무기 입력·시점 회전이 정지한다 (I 창 규약)
- [ ] **C10** 이탈 중인 칸의 창고에 접근할 수 있고, 재결합하면 내용물이 그대로다 (이탈 ≠ 소실)

## D. 아이템 버리기

- [ ] **D1** I 창에서 자원 칸을 **패널 밖으로 드래그** → 스택 전량이 사라지고 **열차 측면 지상에 노드로 낙하**한다
- [ ] **D2** 낙하한 노드를 **집게로 회수**할 수 있다 (종류·색 유지)
- [ ] **D3** 낙하 노드가 컨베이어로 뒤로 흘러가고, 멀어지면 회수(despawn)된다
- [ ] **D4** **무기·장비 칸은 패널 밖 드롭해도 사라지지 않는다** (버리기 불가 — 창고 보관 안내)
- [ ] **D5** 패널 안 공백에 놓으면 취소된다 (실수 방지선 유지)
- [ ] **D6** 게스트의 버리기도 동일 (확정 = 호스트)

## E. 제작대 건축물

- [ ] **E1** 제작대 건축물 칸 근처에서 E → **제작 창이 열린다** (기관차까지 안 가도 됨)
- [ ] **E2** 후미 칸 제작대에서 탄약·무기 제작이 정상 확정된다 (거리 재검증 통과)
- [ ] **E3** 기관차 고정 제작 지점도 **그대로 동작**한다 (시작 직후 루프 유지)
- [ ] **E4** 제작대가 파괴되면 그 칸에서는 창이 안 열린다 (기관차는 여전히 가능)

## F. 장비

- [ ] **F1** 제작 창에 장비 5줄 추가 — "가죽 옷 제작 → 가죽 옷 ×1" 등, 재료가 정확히 차감된다
- [ ] **F2** I 창 착용 행(머리·상체·하체·신발)에 **장비를 드래그 → 착용**된다 (인벤 칸이 비워짐)
- [ ] **F3** 착용 칸 드래그 → 인벤 칸에 놓으면 **해제**되어 첫 빈 칸으로 돌아온다
- [ ] **F4** 상체에 가죽 옷 착용 중 사막 로브를 착용하면 **자리를 맞바꾼다** (상체 경쟁)
- [ ] **F5** 무기·자원은 착용 칸에 놓아도 착용되지 않는다
- [ ] **F6** **가죽 옷 착용 → 몬스터 피해가 15% 준다** (풀셋 = 50%, 상한 확인은 I 구역)
- [ ] **F7** **가죽 옷 착용 → 사막 밤 체온 하락이 느려진다** (실효 6 ℃ — 경고는 뜨되 피해 지연)
- [ ] **F8** **가죽 옷 착용 → 사막 낮 체온이 더 빨리 오른다** (역효과 −0.15 — §6.3 트레이드오프)
- [ ] **F9** 사막 로브 착용 → 낮 더위가 완화된다 (실효 38.5 ℃)
- [ ] **F10** **체온 피해는 장비 피해 감소의 영향을 받지 않는다** (환경 피해 경로 분리 — 방한복 없이
      풀 방어구만 입고 밤 노숙 → 피해량 동일)
- [ ] **F11** 인벤토리 압박 없이 빈 칸이 없으면 해제가 실패하고 **장비가 착용 칸에 보존**된다
- [ ] **F12** 게스트의 착용·효과가 동일하다 (착용 확정·체온·피해 모두 호스트)

## G. 멀티 정합성 (횡단 확인)

- [ ] **G1** 게스트의 건축물 설치(R 순환 포함)가 호스트 확정으로 반영되고 양쪽 화면이 같다
- [ ] **G2** 창고 동시 접근 — 호스트·게스트가 같은 창고를 동시에 열고 각자 이동해도 상태가 어긋나지 않는다
      (마지막 확정 승리 — 손실·복제 없음)
- [ ] **G3** 게스트 접속이 정상이다 (프리팹·씬 해시 불변의 최종 판정 — 0. 사전 준비 참조)

## H. 회귀 확인

- [ ] **H1** **낮 채집 → 밤 웨이브 → Day+1 실시간 전체 사이클 정상** (2차 이월 ② — 장시간 관측)
- [ ] **H2** 기존 돔 설치·수리·칸 건설·재결합 루프가 그대로다 (망치 회귀)
- [ ] **H3** 채집 → 제작 → 사격 루프가 그대로다 (1·2차 회귀)
- [ ] **H4** 엔진 투입·건설 비용이 그대로다 (장비 아이템이 건자재로 새지 않음)
- [ ] **H5** 세션 종료·재시작(숫자패드 +) 시 오류 없음
- [ ] **H6** EditMode 279개 통과 (커밋 시점 확인 완료 — 재확인만)

- [ ] **I1** `StructureCatalog.asset` 난방기 체력 40 → 10 → 몬스터 몇 대에 파괴된다
- [ ] **I2** `StructureCatalog.asset` 창고 비용 4 → 1 → 설치 비용 표시·차감 반영
- [ ] **I3** `TemperatureSettings.asset` heaterFactor 0.8 → 0.2 → 난방 칸 위에서도 체온이 내려간다 (실효 5.8 ℃)
- [ ] **I4** `EquipmentCatalog.asset` 가죽 옷 Cold 0.5 → 0.9 → 밤 노숙 실효 9.2 ℃ (여전히 쾌적대 밖 — 클램프)
