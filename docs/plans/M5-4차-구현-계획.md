4. 요리·섭취·버프 — 제작 흐름 재사용 + 먹기 UX + 시간제 버프 2종 (보온·재생)

**소규모** (3차 검증 후속 — 결정 2026-08-07):

5. 버그 수정: **사망 상태에서 건설·수리 가능** (3차 발견 버그)
6. **Esc 우선순위**: 열린 UI 닫기 > 세션 메뉴 (3차 개선 방향)
7. 디버그 키: **몬스터 스폰 토글** — 3차 이월 검증 5건(밤 노숙 계열)의 선결 조건

**비범위** (5차 이후로 미룸 — 3차 문서 "개선 방향" 잔여):

- 버리기 UX 재설계 (근처 낙하 + E 획득 + 전 아이템 허용) · 창고 파괴 시 내용물 낙하
  — 요리 아이템과 낙하 표현의 접점이 있으나 차수 규모상 분리
- 온도 영향 일반화 (사막 외 지형) — 요리 보온 버프가 들어온 뒤 함께 밸런싱하는 편이 자연스러움
- 몬스터 갑판 장애물 회피 · 2차 이월 연출 9건 · 기획서 §7.3의 야간 시야/스태미나 버프

## 1. 허기 스탯 (3층 구조)

체온의 3층(`TemperatureSettings` SO → `TemperatureMath` 순수 로직 → `PlayerTemperature`
NetworkBehaviour)과 대칭으로 만든다. 환경 완충(건축물·장비 층)이 없으므로 체온보다 단순하다.

| 층 | 신규 파일 | 내용 |
|---|---|---|
| 데이터 | `HungerSettings.cs` + `HungerSettings.asset` | 최대치·자연 감소율·경고/기아 임계·기아 초당 피해 |
| 순수 로직 | `HungerMath.cs` | 감소 스텝·임계 판정·기아 피해량 (EditMode 테스트 대상) |
| 권위 | `PlayerHunger.cs` (NetworkBehaviour) | 호스트 시뮬레이션 + `NetworkVariable<float>` 임계 복제 (체온의 SyncThreshold 패턴) |

**수치 모델** (전부 에셋 — 초기값 제안):

- 최대 100 · 자연 감소 = 낮/밤 동일 (목표 체감: **Day당 식사 1~2회**, Day 길이는 `DayTimelineSettings` 기준으로 환산해 초기값 산정)
- 경고 임계 30 → HUD "허기! 음식을 먹어라" 행동 지시 (추위 HUD와 같은 규약)
- 0 도달 = 기아 → 초당 지속 피해 (체온 피해와 같은 방식)
- **기아 피해는 장비 피해 감소 미적용** — 환경 피해 경로 분리 (3차 F10과 같은 계약: 배율은 `PlayerHealth`의 물리 피해에만)
- 회복은 음식 섭취로만 · 사망~부활 사이 정상치 리셋 (체온과 동일 — 부활 즉사 루프 방지)

**HUD**: 체온 표시(`CoreLoopHud`·`InventoryHud` 상태 행) 옆에 허기 게이지 추가.

## 2. 식량 자원 (`ResourceType` 확장)

값 대역 규약 유지 (자연 자원 1~15 · 제작품 16+, 한 번 배정한 값 불변):

| 종류 | 값 | 대역 | 획득 |
|---|---|---|---|
| 식재료 (RawFood) | 5 | 자연 자원 | 지역 스폰 노드 — 숲·사막 공용 (가중치는 지역 에셋) |
| 구운 식사 (CookedMeal) | 19 | 제작품 | 화덕 요리 — 허기 회복 + 재생 버프 |
| 든든한 스튜 (HeartyStew) | 20 | 제작품 | 화덕 요리 (식재료 다량) — 허기 회복 대 + 소량 재생 + 보온 버프 |

- `ResourceCatalog` 등재: 표시명·스택 상한·식별 색. 건자재 아님 · 발열량 0 (식량은 연료 투입 불가 — 화약 원료와 같은 취급)
- 지역 스폰: `Region_Forest`·`Region_Desert`의 `_resourceSpawns`에 식재료 가중치 추가 — **에셋 수정만**
- 요리 이름·버프 구성은 §4 확정 후 조정 가능 (2종 유지가 기준)

## 3. 화덕 건축물 (5종째)

- `StructureKind.Campfire = 4` — byte 직렬화 값 규약 준수 (기존 0~3 불변)
- `StructureCatalog` 엔트리 추가: 체력 40 · 비용 3 제안 (난방기와 동급 — 전부 에셋)
- **난방 겸용 안 함** (`ProvidesHeat = false`): 돔=그늘 / 난방기=추위 / 화덕=요리로 역할 분리 유지
  (3차 B4·B5에서 검증한 "건축물 1종 = 역할 1개" 계약). 카탈로그 플래그라 밸런스 판단이 바뀌면 에셋으로만 뒤집을 수 있다
- **요리 지점**: `CraftingStation`의 지점 다중 패턴(`TryGetNearestCraftPoint` — 기관차 고정 + Workbench 생존 칸) 재사용.
  단, 레시피 필터가 다르다 → `CraftingRecipe`에 **요구 지점 종류** 필드 추가
  (기본 = 제작대/기관차, 요리 = 화덕). 제작 창은 근처 지점 종류에 맞는 레시피만 노출.
  기존 레시피는 필드 기본값으로 무변경 동작 (직렬화 하위 호환)
- 시각·복제: `StructureView._kindVisualRoots` 인덱스 4 추가 — R 순환(`NextKind`)·Kind 복제·표적 등록은 기존 규약으로 자동 편입
- ⚠ 프리팹·씬 편집 시 `GlobalObjectIdHash` 오염 주의 — 3차 전례 (검증 0. 사전 준비 규약 유지)

## 4. 요리·섭취·버프

**요리** — 제작 흐름 재사용: `Recipe_CookedMeal`·`Recipe_HeartyStew` (식재료 N → 요리 1).
산출이 `ResourceType`(스택)이므로 무기 산출과 달리 빈 칸 강제가 없다. `RecipeCatalog` 등재.

**섭취** — 핫바에서 요리 슬롯 선택 + **좌클릭 = 먹기** (확정 2026-08-07). 자원 슬롯 좌클릭 =
엔진 투입과의 충돌은 **요리가 비연료(발열량 0)** 라 엔진 경로가 거부하는 것으로 회피 — 요리를
든 좌클릭은 엔진 범위 안에서도 먹기로 처리한다 (구현 시 두 경로가 이중 소모되지 않음을 확인).
요청 RPC → 호스트가 (차감 + 허기 회복 + 버프 부여) **원자적 확정** (엔진 투입 규약과 동일).

**버프** — 호스트 권위 시간제 상태 2종:

| 버프 | 효과 | 적용 지점 |
|---|---|---|
| 재생 | 초당 체력 +n, N초 | `PlayerHealth` 회복 경로 |
| 보온 | 추위 단열 +0.3, N초 | `PlayerInventory.GetEquippedInsulation` 합산에 가산 — 기존 클램프 [−1, 0.9] 통과 (장비와 같은 수식, 3차 I4 검산 경로 재사용) |

- 데이터: **`FoodCatalog` SO** (신규 — `EquipmentCatalog` 유사, `ResourceType` 키) — 요리별 허기 회복량·재생(초당·지속)·보온(가산·지속). **한 요리가 두 버프를 함께 가질 수 있다** (스튜 = 소량 재생 + 보온)
- 복제: 버프는 개인 상태 — 종류+만료 시각 `NetworkVariable` (게스트 HUD 동일 표시)
- HUD: 활성 버프 아이콘 + 남은 시간 소표시

## 5. 소규모 항목 (3차 검증 후속)

1. **사망 중 건설 차단** (버그): `RepairHammerController`가 입력 처리 전 `PlayerHealth.IsAlive`를
   보지 않는다 — 클라이언트 입력 게이트 + **서버 RPC 재검증** (요청자 생존 확인) 이중으로.
   같은 스윕에서 사망 중 제작·창고·섭취·버리기도 함께 점검 (신규 섭취 RPC 포함)
2. **Esc 우선순위**: `SessionExitHud`가 Esc를 즉시 세션 메뉴로 소비한다 — 열린 창(I 창·창고·제작)
   이 있으면 **먼저 닫고**, 없을 때만 세션 메뉴. `InventoryHud`와의 규약은 "열린 창 있음" 질의
   서비스 또는 로컬 이벤트 중 구현 시 단순한 쪽 (UI 계층 내 해결 — 아키텍처 규칙의 단방향 의존 유지)
3. **몬스터 스폰 토글 디버그 키**: `QaDebugHotkeys`에 숫자패드 5 추가 — 웨이브 스포너 on/off
   (호스트 확정, 기존 키 규약대로 ServerRpc 경유). **3차 이월 검증(B1·B2·B6·B7·F7·F10)의 선결 조건**

## 7. 작업 순서 (커밋 단위 제안)

1. **허기 3층** — Settings·Math·PlayerHunger + HUD 게이지·경고 + EditMode 테스트
