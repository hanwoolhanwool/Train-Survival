# M5 1차 플레이 검증 항목 — 자원 종류·제작·리볼버 탄약

작성일: 2026-08-05 · 대상: `feat/m5-combat-survival` · 상태: **검증 대기**

> **1차 목표** (개발 가이드 §5 M5 차수 분할): 자원 종류(ResourceType) 분화 + 지역별 자원 스폰 +
> 제작 골격 + 리볼버 예비 탄약 — **"사막 채집 → 제작 → 사격"의 탄약 루프가 종단으로 성립**하고,
> 밸런스 수치가 에셋 수정만으로 바뀐다.
> **검증 구성**: 개발 6원칙 1·2에 따라 **항상 호스트 1 + 클라이언트 1**로 확인한다.

## 0. 사전 준비

- [ ] Boot 씬에서 Play → 호스트 시작. 클라이언트 1대 접속(MPPM 가상 플레이어 또는 빌드)
- [ ] 접속이 조용히 거부되면(`ClosedByRemote`) **프리팹 해시 문제**다 — 이번 차수에서
      `Player.prefab`·`ResourceNode.prefab`(1939677764)을 수정했으므로 `GlobalObjectIdHash`가
      커밋 값과 같은지 먼저 확인 (diff 검수는 마쳤으나 접속으로 최종 판정)
- [ ] 콘솔을 열어둔다

**디버그 키** (호스트/클라 어디서 눌러도 호스트 권위 RPC로 처리)

|---|---|---|---|---|---|

건설 비용(건자재 아무거나): 돔 3 · 칸 5 · 재결합 2 · 자원 스폰 간격: 숲 12 m / 사막 24 m

## A. 자원 종류·스폰 (숲)

- [ ] **A1** Play 직후 지상 자원이 **갈색(목재)·회색(돌) 두 색**으로 섞여 스폰된다
- [ ] **A2** 비율이 대략 목재 7 : 돌 3 — 20개쯤 눈으로 세서 극단적 쏠림만 아니면 통과
- [ ] **A3** 게스트 화면에서도 **같은 노드가 같은 색**이다 (종류 byte 복제 — 색은 각 피어가 카탈로그 조회)
- [ ] **A4** 자원이 뒤로 밀려 회수·재스폰되는 순환이 정상이다 (풀 재사용 시 색이 이전 종류로 남지 않는다)

## B. 자원 종류·스폰 (사막)

- [ ] **B1** 숫자패드 3 ×5 → Day 6 사막 진입 후 새 스폰 자원이 **적갈색(고철)·노랑(화약 원료)**로 바뀐다
      → 지역 전환 직전에 심어진 숲 자원이 잠시 남아 있는 것은 정상 ("이후 생성분부터 교체")
- [ ] **B2** 사막 스폰 간격이 숲의 약 2배로 벌어진다 (12 m → 24 m, M4 회귀 겸)
- [ ] **B3** 비율이 대략 고철 6 : 화약 원료 4

## C. 채집·스택 (핫바)

- [ ] **C1** 목재를 채집하면 핫바에 **"목재 n/5"** 로 표시된다 (종류 표시명 — "자원" 아님)
- [ ] **C2** 목재를 든 상태로 돌을 채집하면 **다른 칸에 새 스택**이 생긴다 (종류별 스택 분리 — 병합 안 됨)
- [ ] **C3** 같은 종류는 기존 스택부터 채운다 (목재 2 소지 → 목재 채집 → 3)
- [ ] **C4** 한 종류 스택이 5에서 더 안 쌓이고 다음 빈 칸으로 넘어간다. 전 칸이 차면 획득 실패(그 자리 낙하)
- [ ] **C5** I 창 드래그로 종류가 다른 스택을 교환해도 종류·수량이 보존된다
- [ ] **C6** 게스트가 채집해도 C1~C4가 동일하다 (증감 확정 = 호스트)

## D. 엔진 투입 (발열 차등)

콘솔 없이 HUD 연료 게이지 증가량으로 판정한다.

- [ ] **D1** 목재 1개 투입 시 연료 증가가 돌 1개의 **3배**다 (6 vs 2 — 게이지 눈금으로 비교)
- [ ] **D2** 고철 1개는 그 중간이다 (3)
- [ ] **D3** **화약 원료를 든 채로는 투입 안내 자체가 뜨지 않고**, E·좌클릭을 눌러도 소모되지 않는다
- [ ] **D4** **권총탄을 든 채로도** 마찬가지다 (탄약이 연료로 새는 것 차단)
- [ ] **D5** 투입은 항상 "든 칸"에서만 소모된다 (다른 칸의 같은 종류가 줄지 않는다 — M2 회귀 겸)
- [ ] **D6** 게스트 투입도 D1~D4 동일

## E. 건설 비용 (건자재 한정)

- [ ] **E1** 목재·돌·고철만 소지하면 망치 HUD의 비용 표시(잔량)가 그 합계다
- [ ] **E2** **화약 원료·권총탄만** 소지한 상태에서는 돔 설치가 "자원 부족"으로 거부된다
      (비건자재는 `Count`에 안 잡힌다)
- [ ] **E3** 목재 2 + 고철 1로 돔 설치(비용 3) 성공 — **종류가 섞여도 건자재면 지불된다**
- [ ] **E4** 지불 시 **탄약·화약 원료 스택은 절대 줄지 않는다** (설치 전후 수량 비교)
- [ ] **E5** 칸 건설(5)·재결합(2)도 정상 동작 (숫자패드 7로 이탈 → 손잡이로 회수 → 재결합, M3 회귀 겸)
- [ ] **E6** 자원이 부족한 상태로 건설을 시도해도 자원이 사라지지 않는다 (`ServerTrySpend` 원자 확정)

## F. 제작

- [ ] **F1** 기관차 위 제작대(엔진 투입구 옆 상자)에 다가가 쳐다보면 **"E — 제작"** 안내
- [ ] **F2** E로 제작 창이 열린다 — **시점 회전·무기 발사가 멈추고 커서가 표시**된다 (I 창과 동일 규약)
- [ ] **F3** 창에 "권총탄 제작 → 권총탄 ×4"와 재료 보유/필요(`고철 n/1  화약 원료 n/1`)가 표시된다
- [ ] **F4** 재료 부족 시 부족한 재료가 빨간색이고 **제작 버튼이 비활성**이다
- [ ] **F5** 숫자패드 9로 재료 지급 → 제작 클릭 → **고철 −1 · 화약 원료 −1 · 권총탄 +4**가 정확하다
- [ ] **F6** 연타로 재료 소진까지 제작해도 수량이 정확하다 (음수·초과 지급 없음)
- [ ] **F7** E 재입력 또는 제작대에서 멀어지면 창이 닫히고 시점·무기 입력이 복귀한다
- [ ] **F8** **게스트도 F1~F7 전부 동일하게 동작**한다 (확정 = 호스트, 거리 재검증 통과)
- [ ] **F9** 제작 창이 열린 동안 엔진 투입·망치 등 다른 상호작용이 발동하지 않는다

## G. 리볼버 예비 탄약

- [ ] **G1** 시작 시 핫바 슬롯 4에 **"권총탄 8/12"**, 리볼버를 들면 HUD에 **"6 / 6 | 예비 8"**
- [ ] **G2** 6발 발사 → R 재장전 → 완료 후 **"6 / 6 | 예비 2"** (예비에서 6발 차감)
- [ ] **G3** 예비 2발만 남기고 4발 발사 → 재장전 → **부분 장전** ("4 / 6 | 예비 0" — 2발만 채워진다)
- [ ] **G4** **예비 0에서 R을 눌러도 재장전이 시작되지 않는다** (빈 실린더 좌클릭도 동일)
- [ ] **G5** 빈 실린더에서 좌클릭하면 (예비가 있을 때) 자동 재장전이 시작된다 (M2 회귀 겸)
- [ ] **G6** 재장전 중 발사 불가, 완료 전 "재장전 중…" 표시 (M2 회귀 겸)
- [ ] **G7** 제작으로 얻은 권총탄이 그대로 예비량에 합산된다 — **채집 → 제작 → 사격 루프 종단 확인**
- [ ] **G8** **게스트 재장전**: 차감·장전 발수가 호스트 화면의 게스트 인벤토리와 일치한다
- [ ] **G9** 탄약 스택을 I 창에서 가방 칸으로 옮겨도 예비량 집계에 포함된다 (`CountOf`는 전 슬롯 대상)

## H. 멀티 정합성·재접속

- [ ] **H1** 게스트 화면에서 자원 노드 색·채집 결과·핫바 표시가 호스트와 어긋나는 순간이 없다
- [ ] **H2** 호스트·게스트가 **같은 노드를 동시에 그랩**해도 한쪽만 성공하고 다른 쪽은 정상 실패한다 (M1 회귀 겸)
- [ ] **H3** 게스트 재접속 시 핫바의 **종류·수량이 그대로 복원**된다 (NetworkList 후발 동기화 — 종류 byte 포함)
