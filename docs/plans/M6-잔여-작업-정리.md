## 2. 지상 원격 플레이어 떨림 (폴리싱 — 시도 ① 실패)

- **증상**: 지상에서 둘이 정지 상태(= 함께 스크롤에 밀리는 중)일 때 근거리 원격 플레이어 떨림.
- **분석 완료**: 상시 외력(스크롤 밀림)은 소유자 로컬 적용, 원격 표시는 스냅샷+보간 —
  관찰자 자신의 연속 이동과 보간의 위상차. 열차 위(델타 0)에서는 나타나지 않는다.
- **시도 ①**: `OwnerNetworkTransform` 위치 보간 `LegacyLerp(0)` → `SmoothDampening(2)` —
  **떨림 악화로 롤백** (저지연 로컬에서 감쇠가 진동을 키움. 프리팹 원복, 해시 무변 1135503018).
- **다음 후보 (착수 전 사용자 결정)**: ⓐ `Lerp(1)` — 신형 선형 버퍼 소비, 프리팹 1줄 (권장 첫 시도)
  ⓑ 틱 레이트 30 → 60 — 스냅샷 밀도 상향, 대역폭 증가 ⓒ 관찰자 로컬 스크롤 보정(지상 원격
  표시를 스크롤 속도만큼 예측) — 효과 확실·비용 최대. 재검 = 2차 검증 문서 P1.

## 3. 호스트 이탈 시 관전 카메라 (폴리싱 — H9 관찰)

- 호스트가 나가면 남은 피어의 플레이어 오브젝트(1인칭 카메라 포함)가 세션과 함께 despawn되어
  씬 카메라로 폴백 — 게임오버/세션 종료 화면의 배경 시점이 갑자기 바뀐다. **기존 동작**(M6
  회귀 아님). 개선하려면 플레이어와 수명이 분리된 로컬 관전 카메라(마지막 시점 유지)가 필요.

## 4. Steam 릴리스 전 항목

- **자체 AppID 발급** — 임시 480(Spacewar) 대체. 발급 전까지 G4(게임 미실행 초대 수락)는
  `+connect_lobby` 수동 인자 대체 검증 유지.
- **업적 실 매핑** — `SteamAchievementsMirror`의 임시 매핑(`first_game_over` →
  `ACH_WIN_ONE_GAME`)을 자체 AppID의 실제 업적 id로 교체 + 업적 목록 기획 협의.
- **Auth Ticket 검증 검토** — 승인 페이로드의 SteamID가 자기 신고인 한계 (2차 비범위 —
  친구 전용 로비 전제로 수용 중).

## 5. 게임 상태 머신 배치 재론 (아키텍처 메모)

- 3차 게임오버는 "판정 1건 + 종단 플래그"라 `Gameplay/Session`에 두었다 (Gameplay 타입 직접
  참조 필요 — 단방향 제약). 개발 가이드의 "게임 상태 머신(로비→인게임→게임오버) = `Systems/`"
  배치 지정은 **전체 상태 머신이 생기는 시점에 재론**한다 (3차 계획 §2.2).

## 6. 기타 (마무리 시점 작업 상태)

- **커밋 미실행** — 3차 구현분 + 검증 대응 수정분(H5 종단 가드·D3 재개정)이 워킹 트리에 있다.
  `EditorSettings.asset` 외부 변경(EnterPlayModeOptions 0→1)도 미커밋 — 커밋 정리 필요.
- 신규 drop-in 정책은 "재접속(복귀)만 허용" 유지 (준비 문서 결정 ④ 1안) — 난입 허용은
  인원 비례 밸런스와 함께 후속 결정.
