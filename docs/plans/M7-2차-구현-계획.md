# M7 2차 구현 계획 — 지역 보스 (졸업 시험의 완성)

작성일: 2026-08-14 · 대상: `feat/m7-endgame` · 상태: **착수 전 결정 ①~⑥ 확정
(2026-08-14, 사용자 결정 — §1)** (차수 편성: [M7-착수-준비.md](M7-착수-준비.md) §4 —
2차 = 지역 보스. 선행: 1차 구현 완료 — [M7-1차-구현-계획.md](M7-1차-구현-계획.md) ·
검증 대기 [M7-1차-플레이-검증-항목.md](M7-1차-플레이-검증-항목.md))

> **2차 목표**: **"지역 마지막 밤 = 대형 웨이브 + 지역 보스"(기획서 §5)가 숲·사막·대초원
> 세 지역 모두에서 성립한다.** 보스는 전용 개체(준비 문서 결정 ④)로 지역별 프리팹 3종 —
> 각기 다른 패턴 셋을 갖고(결정 ②), **처치 전까지 새벽이 오지 않는다**(결정 ④ — 진짜
> "졸업 시험"). 골격(스폰·페이즈·패턴·보상·HUD·밤 지속)을 이 차수에 세워 북극(3차)·최종
> 보스(6차)가 조립이 되게 한다.

---

## 0. 범위

**코어** (보스 골격 축):

1. **전용 보스 개체 3종** — 지역별 전용 프리팹 (결정 ①) + 풀링·NetworkPrefabs 등록 3건.
   에이전트·체력은 전용 컴포넌트, 조향·스냅샷 보간·`IDamageable`은 기존 계약 재사용
2. **보스 정의 데이터** — `BossDefinition` SO 3장 + `RegionDefinition` 확장 참조 필드
3. **마지막 밤 합류 + 밤 지속** — `IsFinalNightOfRegion` 밤에 대형 웨이브와 병행 스폰,
   **보스 처치 전까지 새벽 보류** (결정 ④ — 상한 없음)
4. **보스별 패턴 셋** (결정 ②) — 공통 골격(추격·돌진·페이즈) 위에 지역별 고유 패턴:
   사막 = **원거리 투사체**(신규 축, 결정 ②-b) · 대초원 = **무리 호출**(1차 스탬피드 재사용)
5. **처치 보상 — 전용 희귀 자원 "보스 핵" 신설** (결정 ③) + 지상 드랍 경로 재사용
6. **지역 중간 밤 강화 웨이브** (결정 ⑥ — 기획서 §5 잔여 이행, `WaveMath` 확장)

**소규모**:

7. **보스 체력 HUD** — 마지막 밤 한정 표시 (복제 체력 구독)
8. **QA 소환 키** — 넘패드 `/`(나누기): 현재 지역 보스 즉시 소환 (밤·웨이브 무관 격리 검증)

**비범위** (후속):

- 보스 외형 애셋 — **임시 프리미티브 조합 3종(색·실루엣 차별화)으로 개발** (결정 ⑤).
  **Tripo 생성 애셋 임포트는 사용자 준비 후 별도 반영** — 외형 자식 교체만으로 닫히게
  프리팹을 구성해 둔다 (§2.2)
- 북극 보스 (3차 — 이 골격에 프리팹·정의 1쌍 추가) · 최종 보스 "근원" (6차 — §8.3 병행 확정)
- 보스 핵의 **소비처** — 3~5차에서 연결 (북극 최종 강화·거치 무기·도약 기관 부품 후보).
  이번 차수는 획득·보관·표시까지 성립

## 2. 설계

### 2.1 데이터 — `BossDefinition` + `RegionDefinition` 확장

- `BossDefinition` (SO, `Gameplay/Monsters`): 표시명 · 프리팹 참조 (결정 ① — 정의가 자기
  프리팹을 갖는다) · 기본 체력 · 이동/접촉·돌진 파라미터 · 페이즈 임계 배열 ·
  고유 패턴 종류(enum: None/Summon/Projectile/HerdCall)와 파라미터 · 드랍 테이블(종류+수량 배열).
- `RegionDefinition`에 `_bossDefinition` 참조 append — **null = 보스 없음** (하위 호환,
  스탬피드 확률과 같은 소급 규약). 숲·사막·대초원 에셋에 각 1장 연결.
- 결정 ⑥: `WaveSettings`에 강화 밤 배율 2필드. 중간 밤 판정은 `DayInRegion`/`RegionDayCount`
  순수 함수 — 지역 에셋 추가 불요.

### 2.2 전용 개체 — 프리팹 3종 (결정 ①·⑤)

- `Boss_Forest / Boss_Desert / Boss_Grassland.prefab`: `NetworkObject` + `BossAgent` +
  `BossHealth` + **`Visual` 자식 루트**(임시 프리미티브 조합 — Tripo 애셋 반영 시 이 자식만
  교체, 컴포넌트·NetworkObject 무변 = GlobalObjectIdHash 안전).
- **풀링·네트워크 규약 3건 × 3종**: `PoolManager` 등록 + `PooledNetworkPrefabHandler` 경유,
  NetworkPrefabs 목록 중복 등록 금지 · `AutoObjectParentSync` 끄기 · YAML 편집 후 해시
  정규화 확인. 검증 문서에 **클라 접속 회귀** 항목 명시.
- `BossAgent` (호스트 시뮬 + 클라 보간): `MonsterSteering`·`MotionSnapshotBuffer` 재사용.
  갑판 도약 없음 — 보스는 지상 개체로 열차 측면을 따라붙어 칸·연결부를 때린다 (지붕 난전은
  웨이브 몫). 패턴 상태는 서버 전용, 돌진 예고·투사체 발사는 RPC 연출.
- `BossHealth`: `IDamageable` + 체력 `NetworkVariable` 복제 (HUD 사양). 사망 시 드랍
  테이블 → `IResourceDropper`(1차 경로) + `BossDiedEvent` 발행.

### 2.3 스폰·밤 지속 — `BossSpawner` + 새벽 보류 (결정 ④)

- **스폰**: `DayPhaseChangedEvent` 밤 + `IsFinalNightOfRegion` + 지역 `BossDefinition != null`
  → 보스 1기 스폰 (대형 웨이브 병행 — 상호 무간섭). Day 기준 조회 규약 (`EvaluateForDay`).
- **밤 지속**: 낮/밤은 호스트가 올리는 누적 시간 `_totalSeconds`의 순수 함수다
  (`DayCycleController`). 새벽 보류 = **호스트가 누적을 밤 끝 경계 직전에 클램프** —
  전 피어·후발 접속이 복제 시간에서 같은 밤을 유도하므로 **추가 복제 0**. 구현:
  - `INightHoldGate` 계약을 `Gameplay/Cycle`에 신설 (사이클이 소비자 — 의존 역전.
    "보류 중인가"만 노출), `BossSpawner`가 구현·등록 (마지막 밤 보스 생존 = 보류).
  - `DayCycleController`는 게이트 활성 시 누적 증가를 경계에서 멈춘다. 클램프 계산은
    순수 함수(`DayTimelineMath` 곁 — EditMode 대상)로 분리.
  - 보스 사망 → 게이트 해제 → 시간 재개 = 새벽. QA 넘패드 3(Day 스킵)은 강제 점프이므로
    보류를 무시하고 넘어간다 — 이때 `BossSpawner`가 낮 전환 이벤트에서 생존 보스를 회수
    (디버그 탈출구 유지).
- **웨이브 상호작용**: 밤 계획 총량은 고정이라 연장 시간에 비례해 유입이 늘지 않는다
  (④-b 자연 성립). 스탬피드는 낮 이벤트라 무간섭.

### 2.4 패턴 — 공통 골격 + 보스별 셋 (결정 ②)

| 패턴 | 공통/고유 | 내용 | 재료 |
|---|---|---|---|
| 근접 추격 | 공통 | 최근접 표적(플레이어·열차 부위) 추격 + 접촉 공격 | `MonsterSteering` 재사용 |
| 돌진 | 공통 | 예고(전 피어 연출) → 직선 돌진 — 경로상 칸·연결부·플레이어 피해, 벽 충돌 시 잠깐 경직(반격 틈) | 1차 `ComputePassVelocity` 전례 |
| 페이즈 | 공통 | 체력 임계로 패턴 빈도·이동속도 상승 + 고유 패턴 해금 | `BossPhaseMath` (순수) |
| 부하 소환 | 숲 고유 | 페이즈 2부터 주기 소환 — 기존 몬스터·변종 경로 재사용, 보스 소속 목록 관리 | `MonsterWaveSpawner` 스폰 규약 |
| 원거리 투사체 | 사막 고유 (②-b 신규 축) | 포물선 투사체 — 호스트 판정(낙점 범위 피해) + 낙점 예고 링 연출. 궤적은 발사 파라미터만 RPC로 보내 각 피어 로컬 재생 (탄체 복제 없음 — 대역폭 0 증분) | 신규 `BossProjectileMath` (순수 탄도) — 6차 최종 보스 재사용 |
| 무리 호출 | 대초원 고유 | 페이즈 2부터 스탬피드 통과 무리 1열 유입 — 보스와 같은 측면으로 스쳐 지나가며 압박 | 1차 `StampedeController` 유입 로직 재사용 |

### 2.5 보상 — 보스 핵 (결정 ③)

- `ResourceType.BossCore = 10` append (자연 대역 — 채집·드랍 계열. 비연료·비건자재).
  `ResourceCatalog` 등재: 표시명 "보스 핵" · 스택 5 · 무게 1 · 식별 색(진홍/보라 계열).
- 드랍 = 기존 지상 스폰 경로 (`IResourceDropper`) — 집게·컨베이어 회수 자동 편입.
- 소비처는 비범위 (3~5차 연결). 이번 차수 검증은 "획득 → 창고 보관"까지.

### 2.6 HUD·QA (소규모)

- `BossHudView`: `BossHealth` 스폰 존재 = 표시 조건. 체력 바 + 보스 이름 + 페이즈 표시(선택).
- `QaDebugHotkeys` 넘패드 `/` append: 현재 지역 보스 즉시 소환 (넘패드 5 웨이브 토글과
  조합 = 보스 단독 격리. 소환된 보스도 밤 지속 게이트에 걸리지 않게 **QA 소환은 게이트
  비등록** — 낮 검증 가능).

## 3. 구현 순서

1. `BossDefinition`·`RegionDefinition` 확장 + 에셋 3장 + 임시 외형 프리팹 3종·풀·
   NetworkPrefabs 등록 (§2.1·2.2 — 해시 정규화·클라 접속 확인까지)
2. `BossSpawner` + `BossAgent`(추격·접촉) + `BossHealth`(복제·드랍·이벤트) 골격 —
   넘패드 `/` QA 소환으로 스모크
3. `BossPhaseMath` + 공통 패턴(돌진·페이즈) → 숲 보스 완성 (부하 소환) —
   넘패드 3 반복 → Day 5 마지막 밤 병행 스모크
4. **새벽 보류** (§2.3 — `INightHoldGate` + 누적 클램프 순수 로직) → 처치 전 새벽 불가 확인
5. 사막 투사체 (`BossProjectileMath` — ②-b) + 대초원 무리 호출 (1차 재사용) → 3종 완성
6. 보스 핵 (§2.5) + 보스 HUD (§2.6) + 중간 밤 강화 웨이브 (결정 ⑥ — `WaveMath` 확장)
7. EditMode 신규 → 검증 문서 작성. (Tripo 애셋 도착 시: Visual 자식 교체 — 순서 무관 반영 가능)
