# M7 1차 플레이 검증 항목 — 대초원 (풍요·비축 루프)

작성일: 2026-08-14 · 대상: `feat/m7-endgame` · 상태: **검증 대기**
(구현: [M7-1차-구현-계획.md](M7-1차-구현-계획.md) — 결정 ①~④ 반영.
EditMode 365/365 통과 상태에서 시작)

> **1차 목표** (계획 문서): **대초원(가을)이 세 번째 지역으로 등재되어 숲 → 사막 → 대초원
> 흐름이 성립하고, 벼·보존식·스탬피드로 "북극행 식량 대량 비축"(기획서 §4.3) 루프가 선다.**
> 지역 등재는 "지역 추가 = 에셋 경로 (코드 0줄)"의 as-built 실증 — **A 구역에서 하나라도
> 코드 수정 없이 성립하지 않으면 그 자체가 발견이다** (계획 §2.1).
> **검증 구성**: 원칙대로 **호스트 1 + 클라이언트 1** (MPPM 가상 플레이어).
> **편입**: M6 이월 중 이 차수 관련 축 — **E5**(지역 경계 트림, 3지역으로 재검) (준비 문서 결정 ⑨).

## A. 지역 등재 — 에셋 경로 실증 (코드 0줄 자동 성립 훅, 계획 §2.1)

넘패드 3 반복으로 Day 8부터 천천히 진행하며 확인한다.

- [ ] **A1** 사막 3~4일차(Day 8·9)에 예고 HUD가 "**다음 지역: 대초원**"을 띄운다 (`RegionTimelineMath` 자동)
- [ ] **A2** Day 10 낮 시작에 대초원 진입 — HUD 지역명 전환, 지형 타일이 황금빛으로 교체된다
- [ ] **A3** 온도가 가을 값으로 바뀐다 — 낮 18 ℃(쾌적)·밤 8 ℃(노숙 압박, 난방 칸 안전). 사막의 낮 고온 페널티가 사라진다
- [ ] **A4** Day 13 밤 = 대초원 마지막 밤 — **대형 웨이브** 로그·물량 (보스는 2차 소급, 이번엔 웨이브만)
- [ ] **A5** Day 14 = 숲 복귀 (순환) — HUD·지형·난이도 보너스 가산
- [ ] **A6** 게스트 화면에서도 A2·A4가 같은 타이밍에 보인다 (지형 경계 복제 — M6 1차 훅)
- [ ] **A7** 대초원 진입 **후** 게스트가 재접속해도 대초원 지형·HUD로 합류한다 (후발 접속 훅)
- [ ] **A8** 날씨는 항상 맑음 — 대초원 날씨 목록은 의도적으로 비워 뒀다 (3차 폭설과 함께 재론, **결함 아님**)
- [ ] **E5 (M6 이월)** 지역 전환 여러 번(넘패드 3 반복, 3지역 × 2바퀴 이상) 후에도 지형
      표시·재판정에 이상이 없다 — 경계 트림 관측 (장시간: 이상 없음이면 통과)

## B. 신규 자원 — 벼·소금 (계획 §2.2)

- [ ] **B1** 대초원 지상에 **벼(황금색) 노드**가 눈에 띄게 흔하다 (가중 0.4 + 간격 ×0.8 — "풍요")
- [ ] **B2** 사막 지상에 **소금(백색) 노드**가 간간이 나온다 (소급 0.15 — 기존 4종도 계속 나옴)
- [ ] **B3** 벼·소금 모두 1단계 집게로 낚아채진다 (무게 1 — 기존 게이트 무회귀)
- [ ] **B4** 핫바·창고에서 표시명 "벼"·"소금", 스택 5로 쌓인다
- [ ] **B5** 벼·소금은 엔진 투입 불가·건자재 사용 불가다 (비연료·비건자재)
- [ ] **B6** 숫자패드 9 지급에 벼 4·소금 2가 포함된다 (검증 편의 확장)

## C. 요리·보존식 — 비축 루프 (계획 §2.3, 결정 ②)

화덕 앞에서 확인한다 (넘패드 9로 재료 확보 가능).

- [ ] **C1** 화덕 목록에 "**밥 짓기**"(벼 2 → 밥 2)·"**보존식 만들기**"(식재료 2 + 소금 1 → 보존식 2)가 뜬다 — 제작대/기관차에서는 안 뜬다 (화덕 전용)
- [ ] **C2** 밥 섭취 — 허기 45 회복 + 약한 재생 (구운 식사보다 회복은 크고 재생은 약하다 — 상위 호환 아님)
- [ ] **C3** 보존식 섭취 — 허기 35 회복, 버프 없음 (보온은 스튜 고유 역할 유지)
- [ ] **C4** **보존식이 한 슬롯에 10개** 쌓인다 — 일반 요리(5) 대비 2배, "창고 슬롯당 끼니 수"가 커진다
- [ ] **C5** 보존식을 공유 창고에 쌓기 — 기존 창고·보따리·집게 일괄 획득이 종류 무관으로 그대로 동작 (신규 코드 없음 확인)
- [ ] **C6** 소금 없이 보존식 제작 불가 — 버튼 비활성 (재료 게이트. "사막에서 소금을 챙겨 왔는가")

## D. 스탬피드 (계획 §2.4, 결정 ③·④)

대초원 2일차 이후 낮. 안 뜨면 넘패드 3으로 다음 낮 (확률 0.5).

- [ ] **D1** 대초원 **1일차(Day 10)에는 절대 발생하지 않는다** (지역 첫날 제외 — 날씨 규약)
- [ ] **D2** 숲·사막에서는 발생하지 않는다 (확률 0 — 지역 데이터)
- [ ] **D3** 발생 시 낮에 대형 개체(들소 — 갈색·1.4배) 무리가 **한쪽 측면**에서 열(列)을 지어 전방에서 후방으로 스쳐 지나간다
- [ ] **D4** 무리는 열차·플레이어를 **추격하지 않는다** — 갑판 도약 없음, 직선 주행 유지
- [ ] **D5** 지상에서 무리 경로에 서 있으면 **접촉 피해**를 받는다 (12/타 — "방심 방지")
- [ ] **D6** 무리 개체를 쏘아 잡으면 **식재료가 지상에 드랍**된다 — 집게로 회수 가능 (버리기 낙하와 같은 경로)
- [ ] **D7** 일반 밤 웨이브 몬스터는 여전히 **드랍 없음** (탄약 경제 보호 — 회귀 확인)
- [ ] **D8** 밤 진입 시 남은 무리가 즉시 회수된다 (낮 이벤트 — 밤 방어전과 안 겹침)
- [ ] **D9** 동시 개체가 12마리를 넘지 않는다 (대역폭 방어선 — 대략 관측)
- [ ] **D10** 넘패드 5로 밤 웨이브를 꺼도 스탬피드는 발생한다 (독립 — 격리 관찰 성립)
- [ ] **D11** 게스트 화면에서 무리 이동이 매끄럽다 (기존 12 Hz 스냅샷 보간 채널 그대로)
- [ ] **D12** 통과 개체를 집게로 파지·투척할 수 있고, 놓으면 주행을 재개한다 (기존 그랩 규약과의 상호작용 — 관찰 항목)

## E. 에셋 조정 가능성 실측 (M4 규약 — 밸런스가 에셋만으로 바뀌는가)

플레이 중 한 가지 이상 골라 실측하고 기록한다 (에디터에서 값 수정 → 재실행 → 반영 확인).

- [ ] **E1** `Region_Grassland` 스탬피드 확률 0.5 → 1로 — 매일 발생하는가
- [ ] **E2** `StampedeSettings` 총량·간격 수정 — 무리 규모가 바뀌는가
- [ ] **E3** `Recipe_PreservedMeal` 재료 수 수정 — 화덕 목록·게이트가 따라오는가
- [ ] **E4** `ResourceCatalog` 보존식 스택 10 → 다른 값 — 슬롯 적재가 따라오는가
