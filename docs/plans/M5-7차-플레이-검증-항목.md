# M5 7차 플레이 검증 항목 — 온도 축·낙하 위치 2건 (+ 6차 이월 26건)

작성일: 2026-08-10 · 대상: `feat/m5-combat-survival` · 상태: **검증 대기**
(구현: [M5-7차-구현-계획.md](M5-7차-구현-계획.md) · EditMode 308/308)

> **7차 목표** (계획 문서): **옷·난방의 가치가 전 지역에서 상시 성립**한다 — 보온 장비가
> "환경을 덜 춥게"를 넘어 **평상 체온 자체를 밀어 올리고**(돔에 들어가도 그 높아진 값까지만
> 내려간다), 사막 밖에서도 온도 압박이 존재한다. 함께 낙하 위치 2건(5차 A3 열차 위 낙하 ·
> 5차 A6 취소 순간이동)을 해소했다.
> **검증 구성**: 개발 6원칙 1·2에 따라 **항상 호스트 1 + 클라이언트 1**로 확인한다.
> **6차 검증 잔여 26건을 이번 검증에 편입한다** (→ E 구역, 이월 결정 2026-08-10).

| 항목 | 위치 | 값 |

**검산 메모** (숲 밤, 맨몸): 표류 = (10 − 5) × 0.012 = **0.06 ℃/s** → 저온 경고(35 ℃)까지
약 **25초**, 피해(34 ℃ 미만)까지 약 **42초**. 가죽 옷 + 누비 바지(단열 합산 0.75) 착용 시
실효 환경 8.75 ℃ → 표류 **0.015 ℃/s (¼)**.

## A. 보온 장비 기본 체온 상향 (코어 ① — 5차 개선 5번)

수렴점 축이다 — 단열(표류 완화)과 달리 **쾌적한 환경에서도 체온이 높게 유지**된다.

- [ ] **A1** 맨몸·쾌적 환경(숲 낮)에서 체온이 **36.5 ℃로 유지**된다 (회귀 — 기준선)
- [ ] **A2** **가죽 옷 착용** → 체온이 **37.0 ℃까지 올라가 유지**된다 (HUD 수치로 확인)
- [ ] **A3** **가죽 옷 + 누비 바지** → **37.2 ℃** (합산 0.7 — 상한 1.0 미만이라 그대로 반영)
- [ ] **A4** **돔(그늘) 아래에서도 높아진 값까지만 내려간다** — 사막 낮 돔 아래(실효 25.8 ℃ =
      쾌적)에서 가죽 옷 착용 시 체온이 37.0으로 수렴하고 36.5까지 내려가지 않는다 (사용자 원문 요청의 핵심)
- [ ] **A5** 장비를 벗으면 36.5 ℃로 회복된다 (축 해제)
- [ ] **A6** 장비만으로 **고온 경고(38 ℃)에 도달하지 않는다** — 현 카탈로그 최대 조합 37.2 < 38
      (상한 안전선의 실효 확인)
- [ ] **A7** **사막 낮 가죽 옷 역효과는 그대로**다 — 더위 단열 −0.15가 여전히 적용돼 맨몸보다
      빨리 더워진다 (체온 상향 축이 단열 축을 건드리지 않았다는 회귀)
- [ ] **A8** **게스트도 동일하다** — 게스트가 착용하면 게스트 체온이 상향된다 (판정 = 호스트,
      HUD = 게스트 화면)

## B. 전 지역 온도 (코어 ② — 5차 개선 6번)

- [ ] **B1** **숲 밤(숫자패드 2)에 체온이 내려가기 시작한다** — 7차 전에는 숲에서 압박 0
- [ ] **B2** 맨몸 방치 시 **약 25초에 저온 경고(35 ℃)**, 계속 방치하면 34 ℃ 미만에서 지속 피해
      (검산 메모와 일치하는지)
- [ ] **B3** **난방기 칸 위에서는 회복된다** — 실효 환경이 쾌적대로 당겨져 정상 체온으로 돌아온다
      (밤마다 난방기의 가치가 성립)
- [ ] **B4** **보온 장비 착용 시 압박이 크게 완화된다** — 가죽 옷 + 누비 바지로 표류가 ¼로 줄어
      밤 동안 경고에 도달하지 않거나 크게 늦어진다 (옷의 가치가 상시 성립 — 의도된 보상 구조)
- [ ] **B5** **숲 낮은 쾌적 그대로**다 (22 ℃ — "온화한 낮"이 지역 개성. 낮에는 압박 없음)
- [ ] **B6** **사막 낮·밤은 기존과 동일**하다 (45 / 2 ℃ 무변 — 회귀)
- [ ] **B7** 스튜 즉시 체온·보온 버프가 숲 밤에도 유효하다 — 먹으면 즉시 오르고, 버프 지속 동안
      추위 표류가 완화된다 (요리 축과의 결합)

## C. 해제 하강 낙하 (5차 A6 — 취소 순간이동 해소)

- [ ] **C1** 자원을 공중으로 견인하다 **우클릭 취소 → 순간이동 없이 현재 높이에서 천천히
      하강**해 지면에 안착한다 (7차 전에는 스폰 높이로 즉시 떨어졌다)
- [ ] **C2** **하강 중에도 재그랩된다** — 떨어지는 것을 다시 쏘면 견인이 이어진다
- [ ] **C3** **게스트 화면에서도** 순간이동 없이 같은 하강이 보인다 (스폰 Y 동기화 경유 —
      신규 채널 없음)
- [ ] **C4** 하강 완료 후 노드가 **컨베이어로 정상적으로 흘러가고** 재그랩·수납이 그대로 된다 (회귀)

## D. 갑판 휴지 (5차 A3 — 열차 위 낙하)

- [ ] **D1** **인벤토리를 가득 채우고** 자원을 회수하면(도착 시 수납 실패) 노드가 **발밑(갑판)에
      떨어져 그 자리에 남는다** — 뒤로 흘러가지 않는다 (5차 A3 원문 시나리오)
- [ ] **D2** 갑판 위로 끌어온 자원을 **우클릭 취소해도 갑판에 안착**해 남는다
- [ ] **D3** 갑판 휴지 노드는 **열차가 달려도 제자리**다 — 옆의 지상 자원들은 흘러가는데
      갑판 위 노드만 고정 (열차 프레임 소속의 육안 확인)
- [ ] **D4** 갑판 휴지 노드를 **재그랩하면 정상 회수(수납·소멸)** 된다 — 인벤을 비운 뒤 다시 쏜다
- [ ] **D5** 갑판 휴지 노드를 그랩해 **열차 밖(지상)에서 놓으면 월드 프레임으로 복귀**해
      흘러간다 — 갑판 ↔ 지상 왕복이 성립
- [ ] **D6** 갑판 휴지 노드는 **후방 회수로 사라지지 않는다** — 갑판에 올려 둔 채 한동안 주행해도
      남아 있다 (지상 노드는 뒤로 밀리면 회수되는 것과 대비)
- [ ] **D7** **열차 옆(지상, 폭 밖)에서 놓으면 기존대로 흘러간다** — 갑판 판정 경계 확인
      (|x| > 반폭 1.5 + 여유 0.5)
- [ ] **D8** **게스트가 놓아도 동일**하다 — 게스트가 갑판 위에서 취소하면 양쪽 화면 모두 갑판에
      남는다 (판정 = 호스트)
- [ ] **D9** (관찰) **이탈 칸 갑판 위에서 놓으면** 그 자리에 남는다 — 이후 칸이 더 밀려나도
      노드는 재판정하지 않는다 (착수 전 결정: 최소안. 어색함이 크면 개선 방향에 기록)

## G. 데이터 조정 가능성 (에셋 수정만으로)

6차 I 구역과 같은 방식 — 코드 경로 검수로 정적 확인 (문서 작성 시 수행, 2026-08-10).
각 수치가 단일 소비처에서만 쓰임을 확인했다. 에셋을 실제로 바꾸지 않았으므로 원복 절차 불필요.

- [x] **G1** 숲 밤 5 → 10 ℃ (압박 끄기) — **성립**: `NightAmbientTemperature`의 유일 소비처가
      `PlayerTemperature.GetRegionAmbient` 하나다. 10 ℃ = 쾌적 하한이라 표류 0
- [x] **G2** 가죽 옷 체온 상향 0.5 → 0 (축 끄기) — **성립**: `_bodyWarmthBonus`는
      `GetBodyWarmthBonus → GetEquippedBodyWarmth → ToCurve(bonus)` 한 줄기로만 흐른다.
      0이면 `ToCurve(0)` = 기존 곡선과 동일 (EditMode `음수_보너스는_무시된다`가 하한도 고정)
- [x] **G3** 하강 속도 6 → 60 m/s (사실상 즉시 낙하로 회귀) — **성립**: `_fallSpeed`의 유일
      소비처가 `StepFall`의 `MoveTowards` 속도 인자다 — 큰 값 = 한 프레임 안착
- [x] **G4** 체온 상향 합산 상한(+1.0)·갑판 판정 여유(0.5 m)는 **코드 상수**다 — 에셋 조정
      대상이 아님을 명시 (바꾸려면 코드 수정. 상한은 EditMode가 경계를 고정하고 있다)
