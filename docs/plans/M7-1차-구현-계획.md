## 0. 범위

**코어** (비축 루프 축):

1. **지역 3종 등재** — `Region_Grassland` 에셋 + `RegionTimelineSettings` append.
   목표 = 코드 0줄 (예고 HUD·마지막 밤 대형 웨이브·지형 경계 복제·후발 접속·온도·날씨
   훅이 전부 자동 성립하는지 실증)
2. **신규 자원** — 벼(Rice) + 소금(Salt — 사막 스폰 소급, 기획서 §4.2 미구현분) (결정 ①)
3. **요리·보존식** — 밥(벼 기반, §7.3) + 보존식(소금 절임/훈제 — 북극행 비축) 레시피·
   FoodCatalog 등재 (결정 ②)
4. **스탬피드 이벤트** — 대초원 정체성 이벤트 (기획서 §4.3 "방심 방지") (결정 ③·④)

**소규모**:

5. **대초원 지형 타일·자원 외형** — 황금빛 색채 규약 (기존 프리미티브·색 구분 유지 —
   외부 애셋 도입은 보스(2차)부터)

**비범위** (후속 차수 — [M7-착수-준비.md](M7-착수-준비.md) §4):

- 지역 보스 (2차 — 대초원 마지막 밤 보스는 2차에서 소급 편입, 1차는 기존 대형 웨이브만)
- 북극·동상·정수 건축물 (3차) · 거치 무기 (4차)
- **부패(신선도) 시스템 없음** — 보존식의 가치는 부패가 아니라 결정 ②의 축으로 성립
- **사냥용 야생 동물 개체 신설 없음** — "사냥감 풍부"는 결정 ③(스탬피드 드랍)과
  식재료 스폰 가중치로 표현

## 2. 설계

### 2.1 지역 등재 — 에셋 경로 실증 (목표: 코드 0줄)

- `Region_Grassland.asset` 신설(위 초기값) + `RegionTimelineSettings._regions`에 3번째로
  append. 지형 타일 프리팹은 기존 타일 복제 + 황금빛 머티리얼.
- **자동 성립을 실증할 기존 훅** (전부 M4~M6에 구현 완료 — 재작업 없이 타야 정상):
  - 예고 HUD "다음 지역 예고: 대초원" (`RegionTimelineMath` — 사막 마지막 1~2일)
  - 지역 마지막 밤 대형 웨이브 (`IsFinalNight` — 보스 소급은 2차)
  - 지형 경계 복제·후발 접속 표시 (`TerrainRegionBoundary` — M6 1차)
  - 전 지역 온도(M5 7차)·날씨 훅(비워 두면 항상 맑음 — 대초원 날씨는 3차 폭설과 함께 재론)
- 하나라도 코드 수정이 필요해지면 **그 자체가 발견**이다 — as-built 명세와의 괴리를
  기록하고 최소 수정한다.

### 2.2 신규 자원 — `ResourceType` append (값 고정 규약)

- 자연 자원 대역(1~15)에 append: `Rice = 8`(벼 — 비연료·비건자재, 요리 재료),
  `Salt = 9`(소금 — 비연료·비건자재, 보존식 재료. 결정 ①). 제작품 대역(16+)과 분리 유지.
- `ResourceCatalog` 등재: 표시명·스택·식별 색(벼 = 황금색 / 소금 = 백색), **무게 1**
  (기존 집게 게이트 무회귀 — 미등재 = 무게 1 규약과 동치이나 명시 등재).
- 스폰 목록: 대초원 = 벼 0.4 / 식재료 0.35 / 목재 0.15 / 돌 0.1 (식량 지수 4 —
  "풍요"가 목록만으로 성립). 사막에 소금 0.15 소급 append (기존 가중치 비율 유지 재조정).
- 몬스터 변종·자원 종류 규약 그대로 — 프리팹·풀·네트워크 목록 무증가 (byte 인덱스 복제).

### 2.3 요리·보존식 — `RecipeCatalog`/`FoodCatalog` append

- 제작품 대역 append: `CookedRice = 21`(밥) · `PreservedMeal = 22`(보존식).
  (19·20 = 기존 구운 식사·스튜, `RecipeCatalog` 인덱스 = RPC 식별자 — append-only 규약.)
- 레시피 (화덕 `CraftStationKind` — M5 4차 요구 지점 규약 재사용):
  - 밥: 벼 2 → 밥 2 — 허기 회복 45 + 소량 재생 (구운 식사 상위 호환이 되지 않게 재생은 낮게)
  - 보존식: 식재료 2 + 소금 1 → 보존식 2 — 결정 ② 축 (권장: 회복 35 · 스택 10)
- 비축 루프의 종단 = **공유 창고에 보존식을 쌓는 것** — 신규 코드 없음
  (`TrainStorage`·보따리·집게 일괄 획득이 전부 종류 무관으로 이미 동작).

### 2.4 스탬피드 — 신규 이벤트 (호스트 권위, `Gameplay/Monsters`)

- **날씨가 아니라 몬스터 이벤트다** (착수 준비 §2) — `WeatherController`를 확장하지 않고
  `StampedeController`(호스트 전용 MonoBehaviour)를 신설한다.
- **발생**: 결정 ④ — 낮 시작 이벤트(`DayPhaseChangedEvent`) 구독, 지역 데이터 확률로
  호스트 추첨. 날씨 규약 준수: 지역 첫날 제외 · Day 기준 조회(`EvaluateForDay` 전례 —
  처리 순서 의존 금지) · 밤 진입 시 강제 종료.
- **개체**: 기존 몬스터 프리팹·풀·변종 규약 재사용 (스탬피드 전용 변종 인덱스 —
  `MonsterVariantCatalog` append, 외형 = 스케일·색 구분). `MonsterAgent`에 **통과 모드**
  신설 — 추격·공격 조향을 끄고 열차와 평행한 직선 주행(스크롤 상대 속도), 접촉 피해만.
  경로 이탈(후방 한계) 시 despawn·풀 반환.
- **물량·대역폭**: 동시 상한 별도 필드(제안 12마리 — 밤 웨이브 상한과 독립), 12 Hz
  스냅샷 보간은 기존 채널 그대로. 무리는 "연속 유입 열(列)"로 표현해 동시 수를 억제한다.
- **드랍**: 결정 ③ — 처치 시 식재료를 `GroundResourceSpawner` 경로로 지상 스폰
  (버리기·보따리 투척과 같은 재사용 — 컨베이어·집게 회수 자동 편입). 드랍은
  스탬피드 개체 한정 (일반 웨이브 몬스터 드랍 없음 유지 — 탄약 경제 보호).
- **순수 로직 분리** (EditMode): 발생 추첨(난수 주입) · 유입 계획(총량·간격·상한) ·
  통과 경로 산출. `WaveMath`와 나란한 `StampedeMath`.

## 3. 구현 순서

1. `ResourceType`·카탈로그·스폰 목록 append (§2.2 — 벼·소금) + 대초원 에셋·타임라인
   등재 (§2.1) → 넘패드 3 반복으로 대초원 진입 스모크 (자동 성립 훅 확인)
2. 레시피·FoodCatalog append (§2.3 — 밥·보존식) → 화덕 요리·창고 비축 스모크
3. `StampedeMath` + `StampedeController` + `MonsterAgent` 통과 모드 + 변종 append (§2.4)
4. 드랍 경로 연결 (결정 ③) + 밸런스 에셋 1차 조정
5. EditMode 신규(추첨·유입 계획·타임라인 3지역 경계·레시피 원자성 회귀) → 검증 문서 작성

## 4. 테스트·검증 계획

- **EditMode**: 타임라인 3지역 경계(숲 5 + 사막 4 + 대초원 4 = Day 13 순환·예고 트리거) ·
  스탬피드 추첨(첫날 제외·확률 0 지역 미발생) · 유입 계획(총량·동시 상한) ·
  신규 레시피 원자성(기존 `CraftingLogic` 규약 회귀).
- **재현 수단**: 숫자패드 3(다음 Day 스킵) 반복 = Day 10 대초원 진입 · 숫자패드 9
  (자원 지급)에 벼·소금 추가 — 요리 루프를 채집 없이 검증 · 숫자패드 5(웨이브 토글)로
  스탬피드만 격리 관찰. 검증 구성은 원칙대로 호스트 1 + 클라이언트 1 (MPPM).
- **검증 문서**: 구현 완료 후 `M7-1차-플레이-검증-항목.md` — 지역 전환·자원·요리·
  스탬피드·비축 루프 + **에셋 조정 가능성 실측**(M4 규약 — 밸런스가 에셋만으로 바뀌는가).
  M5·M6 이월 중 이 차수 관련 축(지역 경계 트림 E5 등)만 편입 (준비 문서 결정 ⑨).
