# M5 6차 플레이 검증 항목 — 파지·열차 하부 즉사 존·처형 제거 (+ 5차 이월)

작성일: 2026-08-09 · 대상: `feat/m5-combat-survival` · 상태: **검증 대기**

> **6차 목표** (계획 문서): **"몬스터를 낚아채면 놓을 때까지 집게에 매달려 있고, 든 채로 이동해
> 아군 앞이나 열차 바퀴에 넘겨 처치하는" 루프가 종단으로 성립**한다 — 처형 배율이 아니라
> **운반**이 집게의 가치가 된다. 놓인 몬스터는 잠깐 기절했다가 복귀한다 (처형 창 아님).
> **검증 구성**: 개발 6원칙 1·2에 따라 **항상 호스트 1 + 클라이언트 1**로 확인한다.

> 통과 기록은 이번 설계 반전으로 **역사 기록**이 됐다 — A·B 구역이 새 명세로 대체한다.

## A. 처형 부재 확인 (역방향 — 설계 반전의 확인)

5차 F 구역(처형 7건)·K10·K11의 통과 기록을 **무효화하는 새 명세**다. 처형 축이 정말 사라졌는가.

- [0] **A1** 파지·기절 중인 몬스터를 근접(마체테)으로 쳐도 **한 방에 죽지 않는다** — 일반 데미지만 들어간다
- [0] **A2** 파지·기절 중인 몬스터를 총으로 쏴도 동일하다 (배율 없음 — 체력만큼 때려야 죽는다)
- [0] **A3** 몬스터를 어떤 방식으로 죽여도 **"처형!" 배너가 뜨지 않는다** (표면 제거 확인)
- [0] **A4** 평상시 몬스터 전투가 5차와 동일하다 (배율 제거는 평시 데미지에 영향 없음)
- [0] **A5** 처치 수(HUD)는 여전히 정상적으로 오른다 (이벤트 시그니처 복귀의 회귀 확인)


## B. 파지 (5차 E 구역 대체 — 새 명세, 2026-08-10 "원하는 방향" 반영)

핵심 반전: **도착 = 소멸도 기절도 아닌 파지 유지**. 5차의 견인 파이프라인(E1~E3·E13~E15)은
그대로이고, 도착 이후가 바뀌었다.
**2차 반영 (2026-08-10)**: ① 파지 중 좌클릭 = **투척(슬램)** ② **무기를 바꿔도 놓지 않는다**
③ 앵커가 **화면 좌측 앞**이고 전 피어가 **로컬 부착**해 홀더와 **한 몸처럼** 움직인다.

- [ ] **B1** 몬스터를 낚아채 릴이 끝나면 **소멸하지 않고 화면 좌측 앞에 매달린다** (전방 1.5 m · 왼쪽 0.8 m · 높이 1.2 m)
- [ ] **B2** 파지 중 **로프·훅이 계속 보인다** (회수되지 않는다)
- [ ] **B3** **든 채로 이동하면 몬스터가 한 몸처럼 붙어 움직인다** — 걷기·달리기·방향 전환에
      "뒤따라오는" 지연 없이 **화면의 같은 자리에 고정**된 느낌 (로컬 부착 — 스냅샷 보간을 덮어쓴다)
- [ ] **B4** 파지 중 몬스터는 **공격·이동하지 않는다** (견인 정지 유지)
- [ ] **B5** **파지 중 좌클릭 = 투척(슬램)**: 든 몬스터가 조준 방향으로 발사된다 — 사거리는 짧다 (8 m)
- [ ] **B6** **놓기 ① 우클릭**: 몬스터가 그 자리에 떨어지고 **잠깐 기절**한다 (노란색 + 기운 자세, 2.5초)
- [ ] **B7** **무기를 바꿔도 놓지 않는다** — 파지·로프가 유지되고, 든 채 다른 무기로 쏠 수 있다.
      놓기·투척은 **집게로 돌아와서** 한다 (우클릭·좌클릭)
- [ ] **B8** **놓기 ② 대상 사망**: 파지 중 팀원(또는 무기를 바꾼 본인)이 쏴 죽이면 로프가 정리되고
      되감기로 복귀한다 (5차 E12의 새 명세)
- [ ] **B9** 기절이 끝나면 **정상 복귀**하고 다시 추격한다 — 복귀 후 재그랩 가능
- [ ] **B10** **기절 중에는 재그랩되지 않는다** (5차 E8 유지)
- [ ] **B11** **견인 중(도착 전) 우클릭 취소는 기절 없이** 즉시 복귀한다 (5차 E13 유지 — 파지에서 놓인 경우에만 기절)
- [ ] **B12** "놓고 무기 들어 싸우기"가 성립한다 — 놓기 → 기절 2.5초 안에 무기 교체 → 선제 타격
- [ ] **B13** **게스트 홀더도 성립한다** — 게스트가 파지한 채 이동해도 호스트·게스트 화면 모두 매달려 따라온다
- [ ] **B14** 게스트 화면에서 호스트의 파지(매달린 몬스터·로프)가 같게 보인다 — 원격 화면에서도
      몬스터가 **홀더에 붙어** 움직인다 (부착 기준이 각자 화면의 홀더 위치라 홀더와 어긋나지 않는다)
- [ ] **B15** **자원 회수는 한 줄도 바뀌지 않았다** — 자원은 5차 그대로 도착 = 수납·소멸 (enum 분기 회귀 확인)

**투척(슬램) — 2차 반영 신규**

- [ ] **B16** 투척한 몬스터가 **지형·구조물에 부딪히면 큰 피해(60)를 받고 그 자리에 떨어져 기절**한다
      — 돌진형(체력 60)은 즉사, 일반형(100)은 반피 이상 깎인 채 기절
- [ ] **B17** 사거리(8 m) 끝까지 아무것도 안 맞으면 **그 자리에 떨어져 기절만** 한다 (피해 없음)
- [ ] **B18** 투척 비행 모습이 게스트 화면에도 보인다 (견인 채널 재사용 — 비행 중에는 부착이 풀린다)
- [ ] **B19** **바퀴 존으로 던져 넣어도 즉사**한다 (투척 경로가 즉사 존을 지나면 C 구역 규칙 적용)
- [ ] **B20** 투척 후 집게는 쿨다운을 거쳐 정상 복귀한다 — 재발사·재그랩 가능

## C. 열차 하부 즉사 존

- [ ] **C1** **파지한 채 지상에서 열차 옆으로 걸어가 바퀴 쪽에 들이밀면** 몬스터가 즉사한다 (주 동선)
- [ ] **C2** 즉사 시 **처치 수가 오르고**, 파지가 풀리며 로프가 정리된다 (귀속 = 바퀴에 넣은 사람)
- [ ] **C3** **놓인 기절 몬스터가 존 안에 있으면** 즉사한다 (예: 열차 발자국 안 지면에 놓기)
- [ ] **C4** 견인 중(끌려오는 중) 경로가 존을 지나도 즉사한다
- [ ] **C5** **자유 몬스터는 죽지 않는다** — 밤 웨이브 몬스터가 추격 중 열차 밑을 스쳐도 무사 (밸런스 안전선)
- [ ] **C6** **갑판 위에서 파지한 채 서 있으면 죽지 않는다** (갑판 높이 3 m > 존 높이 1.2 m)
- [ ] **C7** 게스트가 바퀴에 넣어도 동일하다 (판정 = 호스트, 귀속 = 게스트)

## D. 제작 창 발견성 (5차 개선 1번)

- [ ] **D1** 제작 창이 **화면 높이의 70 %를 넘지 않는다** — 목록이 길면 스크롤이 생긴다
- [ ] **D2** **분류 머리글**이 보인다 — 순서: **집게 강화 → 탄약 → 무기·장비 → 요리**
- [ ] **D3** **승급 줄이 최상단 그룹**이다 (5차에서 12번째 줄이라 못 찾던 문제의 해소)
- [ ] **D4** 재료 부족 줄의 버튼 라벨이 **"재료 부족"** 이다 — 회색이어도 "없는 것"처럼 보이지 않는다
- [ ] **D5** 화덕 근처에서만 요리 그룹이 나타난다 (기존 지점 필터와 그룹화의 결합 확인)
- [ ] **D6** **제작 요청은 그대로 동작한다** — 그룹 순서가 바뀌어도 올바른 레시피가 제작된다 (인덱스 규약 무변)

## 원하는 방향 (사용자 원문, 2026-08-10 — **전부 반영 완료**)

세 건 모두 2차 반영으로 구현됐다 — B 구역 명세(B1·B3·B5·B7·B14·B16~B20)와 기준 수치 표가
갱신본이다. 원문 보존:

> * 몬스터를 파지한 상태에서 집게 무기를 그대로 유지한채 좌클릭 하면, 집게를 다시 발사하면 좋겠다.
> 몬스터 파지를 그대로 유지한 상태이며, 땅이든 벽이든, 어딘가에 부딛혔을 때 몬스터에게 큰 대미지 + 기절시키면 좋겠다.
> 재발사는 사거리가 길지 않으면 좋겠다. 우클릭은 몬스터를 놓기.
>
> * 현재 몬스터를 집게로 파지한 상태에서 무기를 집게에서 다른 무기로 바꿀 때 집게가 취소된다. 무기를 바꿔도 취소가 되지 않으면 좋겠다.
>
> * 현재 파지 상태에서 이동할 때 파지되어있는 몬스터가 마치 뒤따라오는 것 처럼 느껴진다. 내가 원하는 것은, 플레이어 화면 좌측 앞에 고정되는 느낌을 원한다. 따라서 집게로 끌고 도착한 상태는 다같이 하나의 오브젝트처럼 이동하는데 문제 없어야한다.

**반영 내역** (2026-08-10):

1. **파지 중 좌클릭 = 투척(슬램)** — 든 몬스터를 조준 방향으로 발사한다 (서버 확정).
   지형·구조물 충돌 시 **큰 피해 60 + 놓임(기절 2.5초)**, 미명중이면 사거리 끝에서 놓임(기절만).
   사거리는 **8 m로 짧게** — 속도·사거리·피해·판정 반경 전부 `HarpoonSettings` 에셋.
   우클릭 놓기는 그대로 (→ B5·B16~B20)
2. **무기를 바꿔도 놓지 않는다** — "놓기 ② 무기 교체" 자동 취소를 철회했다. 파지·로프가 유지되고
   든 채 다른 무기로 쏠 수 있다. 놓기·투척은 집게로 돌아와서 한다 (→ B7)
3. **화면 좌측 앞 고정 + 한 몸 이동** — 앵커에 측면 오프셋(왼쪽 0.8 m, `_holdSide`)을 더하고,
   표시를 스냅샷 보간(0.18 s 지연 — "뒤따라오는" 느낌의 원인)에서 **전 피어 로컬 부착**으로
   바꿨다: 각 피어가 자기 화면의 홀더 위치 기준으로 같은 앵커 계산(`ComputeHoldAnchor`)을 매
   프레임 대입한다. 소유자 화면은 지연 0, 원격 화면도 홀더에 붙어 함께 움직인다.
   판정 위치는 서버가 같은 계산으로 확정한다 (→ B1·B3·B14)
