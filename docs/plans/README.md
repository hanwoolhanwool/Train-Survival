# 계획 지도 (`plans/`)

차수별 **구현 계획**과 **플레이 검증 항목**을 마일스톤별로 둔다.
차수가 끝나면 이 문서들은 동결되고, 결과는 [개발 가이드](../guide/Train-Survival-개발-가이드.md) §5와
[as-built 명세](../specs/README.md)에 반영된다.

## 문서 종류

| 종류 | 언제 쓰는가 | 무엇을 담는가 |
|---|---|---|
| **착수 준비** | 마일스톤 시작 전 | 범위 결정·차수 편성·선행 조건 |
| **N차 구현 계획** | 차수 착수 전 | 범위·비범위·구현 순서·완료 기준 |
| **N차 플레이 검증 항목** | 구현 완료 후 | 체크리스트와 실제 검증 결과 |
| **잔여 작업 정리** | 마일스톤 종료 시 | 다음 차수로 넘긴 것 |
| **트러블슈팅 로그** | 한 문제를 추적할 때 | 증상→원인→처방 과정 |

## 문서 방식이 차수에 따라 다르다

**이 폴더를 읽을 때 가장 먼저 알아야 할 것** — 계획·검증 문서의 형태가 시기마다 바뀌었다.
파일이 없다고 해서 그 작업에 계획이나 검증이 없었다는 뜻이 아니다.

| 시기 | 구현 계획 | 플레이 검증 |
|---|---|---|
| **M3 · M4 · M5 1~3차** | **별도 문서 없음** — [개발 가이드 §5](../guide/Train-Survival-개발-가이드.md)의 마일스톤 절이 범위·완료 기준·구현 내역을 담당했다 | 차수별 문서 (M3만 없음 → 사후 요약본으로 대체) |
| **M5 4차~M8** | 차수별 `N차-구현-계획.md` | 차수별 `N차-플레이-검증-항목.md` |
| **M6** | 차수별 문서 | **통합 검증 문서** — 3차 검증은 별도 파일이 아니라 [1차 문서 §H](M6/M6-1차-플레이-검증-항목.md)·[2차 문서 §4](M6/M6-2차-플레이-검증-항목.md)에 구역으로 들어 있다 |

### 사후 요약본이란

M3·M8 1차는 **검증을 실제로 수행했으나 항목 문서를 만들지 않았다.** 결과 기록은 다른 문서에
흩어져 있어, 이를 모아 정리한 것이 `검증-기록-요약` 문서다.

**체크리스트가 아니다.** 근거가 남아 있는 항목만 판정을 적고, 기록이 없는 항목은
"개별 기록 없음"으로 명시한다 — 사후에 통과 표시를 만들어 넣지 않는다.
