# 건축 개편 3차 플레이 검증 항목 — 판자 증축

작성일: 2026-08-18 · 대상: `feat/structure-grid` · 상태: **검증 대기**
(구현: [건축-시스템-개편-계획.md](건축-시스템-개편-계획.md) §3 3차 — 결정 ⑥ 반영.
EditMode **503/503 통과** 상태에서 시작 — 2차 490 + 신규 13.
1·2차 잔여 구역은 이번 검증과 묶어 진행한다)

> **3차 목표** (계획 문서): **칸 옆면에 판자를 셀 열 단위로 덧대 갑판이 넓어지고, 그 위를 걸어
> 다니며 건축물을 설치할 수 있다.** 판자는 X 홀드로 철거되며(비용 50% 반환), 그 열 위에 건축물이
> 있으면 기각된다. 넓어진 폭은 **낙하·갑판 판정과 몬스터 승차 판정**에 반영된다.
> **검증 구성**: 원칙대로 **호스트 1 + 클라이언트 1** (MPPM 가상 플레이어).

## 0. 사전 준비

- [ ] **씬 변경 1건** — `Game_ArtTest`의 Train 루트에 `PlankViewSpawner` 추가
      (판자 프리팹 `Plank_Deck` + `TrainLayoutSettings` + 두께 0.15 배선)
- [ ] **에셋 3건** — `TrainExpansionSettings`
  - `_plankBuildCost = 3` (판자 1열 건설 비용)
  - `_maxPlankColumns = 1` (좌/우 각 최대 열 수 — 좌표계 예약 상한은 2)
  - `_plankRefundResource = Wood` (철거 반환 자원)
- [ ] 건자재는 **숫자패드 9**, 인게임 진입은 `Game_ArtTest` 고정

**기준 수치** (전부 에셋·좌표계 파생)

| 항목 | 값 | 확인 |
|---|---|---|
| 판자 1열 | 폭 = 그리드 셀 1.0 m · 길이 = 칸 15행 · 두께 0.15 m | 상면이 갑판 높이와 같다 |
| 비용 / 반환 | 건자재 **3** / 목재 **1** (floor(3 × 0.5)) | 건축물과 같은 반환 비율 |
| 상한 | 좌/우 **각 1열** (에셋). 좌표계 예약은 2열 | 상한 도달 시 빈 자리 조준이 성립하지 않는다 |
| 갑판 반폭 | 판자 0열 **2.3 m** → 1열 **3.0 m** (본체 그리드 2.0 + 1.0) | 낙하·승차 판정이 이 값을 쓴다 |
| 홀드 | X **0.5 s** (건축물 철거와 같은 시간) | 놓거나 표적이 바뀌면 리셋 |

## A. 판자 증축 (§2.9 — 결정 ⑥)

- [ ] **A1** 망치를 들고 갑판 위에서 **칸 가장자리 바깥**(허공)을 겨누면 판자 열 자리에
      **초록 테두리**가 뜨고 HUD에 "**칸 #N 좌측 판자 — 우클릭 증축 (소모: 건자재 3)**"이 뜬다
      (조준은 갑판 높이 평면 연장 — 콜라이더가 없는 빈 자리도 잡힌다)
- [ ] **A2** 우클릭하면 판자 1열이 칸 옆면에 붙고, 건자재 3이 소모된다. **전 피어에 동시에** 보인다
- [ ] **A3** 좌·우가 **별개 축**이다 — 좌측을 붙여도 우측 자리는 그대로 비어 있다
- [ ] **A4** **상한(1열) 도달** 시 그쪽 바깥을 겨눠도 증축 안내가 뜨지 않는다
      (열 0/7은 예약만 되어 있고 에셋 상한이 막는다)
- [ ] **A5** **자원 부족** 시 "<빨강>증축 자원 부족</>"으로 뜨고 우클릭이 먹지 않는다
- [ ] **A6** **기관차 옆·이탈 칸 옆**에는 증축 안내 자체가 뜨지 않는다 (건축물 철거와 같은 게이트)
- [ ] **A7** 클라이언트도 증축 가능 — 비용은 **증축한 사람** 가방에서 나간다
- [ ] **A8** 조작된 값(사거리 밖·상한 초과)으로 요청해도 호스트가 기각한다

## B. 판자 위 이동·건축 (§2.9 — 폭 파생 판정)

- [ ] **B1** 판자 위를 **걸어 다닐 수 있다** — 갑판과 같은 높이로 이어지고 낙하하지 않는다
- [ ] **B2** 판자 **바깥 끝을 넘어가면** 낙하한다 (반폭 3.0 m 경계)
- [ ] **B3** 판자 열 위에 **건축물을 설치할 수 있다** — 셀 스냅·회전·프리뷰가 본체와 동일하게 동작한다
- [ ] **B4** 판자가 **없는** 칸에서는 그 열에 건축물이 설치되지 않는다 (프리뷰가 본체 끝 열로 클램프)
- [ ] **B5** 제작대(2×1)가 **본체 끝 열 + 판자 열에 걸쳐** 놓인다
- [ ] **B6** 판자 위에 보따리·자원이 놓이면 갑판 위와 같이 얹힌다 (갑판 판정 공유)

## C. 판자 철거 (§2.9 — 그 열 위 건축물 우선)

- [ ] **C1** 이미 깔린 판자를 겨누면 HUD에 "**[X 홀드] 철거 (반환: 목재 1)**"이 뜬다
- [ ] **C2** X 0.5 s 홀드로 철거되고 목재 1이 가방에 들어온다. 중간에 놓으면 리셋된다
- [ ] **C3** 가방이 가득이면 잔여가 **보따리**로 그 자리에 나온다 (건축물 철거와 같은 반환 규약)
- [ ] **C4** **그 열 위에 건축물이 있으면** "<빨강>위에 놓인 건축물을 먼저 철거해야 뜯을 수 있다</>"가
      뜨고 철거되지 않는다
- [ ] **C5** 판자 위 **건축물을 직접 겨눈** X 홀드는 **건축물 철거**로 동작한다 (판자 안내는 감춰진다)
- [ ] **C6** 철거 후 그 열이 유효 열에서 빠진다 — 그 자리에 건축물 프리뷰가 더 이상 스냅되지 않고,
      그 위에 서 있으면 낙하한다

## D. 몬스터 (§2.9 — 승차 판정 확장)

- [ ] **D1** 몬스터가 **판자 위로 기어오른다** — 판자가 몬스터 안전지대가 되지 않는다
      (승차 도약 판정이 판자 반폭을 반영)
- [ ] **D2** 판자 위 건축물이 몬스터의 공격 대상이 된다 (관통 방지 규칙은 본체와 동일)
- [ ] **D3** 판자 자체는 **파괴 대상이 아니다** — 몬스터가 판자를 때리지 않는다 (1차 결정)

## E. 상태 유지 (§2.9 — 좌표계·복제)

- [ ] **E1** **칸 이탈** — 판자가 칸을 따라 뒤로 흘러가고, 소실 거리에서 칸과 함께 표현이 꺼진다
- [ ] **E2** **재결합** — 판자와 그 위 건축물이 그대로 복귀한다
- [ ] **E3** **칸 파괴** — 그 칸의 판자가 함께 사라진다
- [ ] **E4** **슬롯 재건** — 새 칸은 판자 0열로 시작한다 (옛 판자가 되살아나지 않는다)
- [ ] **E5** **후발 접속** — 판자가 있는 편성에 새 클라가 들어오면 좌/우 열이 동일하게 재구성된다
- [ ] **E6** 좌측 판자를 **나중에** 붙여도 기존 건축물의 자리가 밀리지 않는다 (고정 예약 좌표계)
