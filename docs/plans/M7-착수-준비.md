# M7 착수 준비 — 후반부·최종장

작성일: 2026-08-13 · 대상: 신규 브랜치 (M6 커밋 정리·main 머지 후 분기 — §6 선행 정리) ·
상태: **착수 전 결정 ①~⑨ 확정 (2026-08-13, 사용자 결정 — §3). 차수 분할은 §4 제안**

> **M7 범위** (개발 가이드 §5): 대초원·북극 지역 + 지역 보스 + 궤도 도약 기관 +
> 가속 방어전(B안 연출) + 우주 최종장 + 뉴게임+/챌린지 순환.
> **완료 기준 (제안)**: 숲에서 시작한 런이 대초원·북극을 거쳐 궤도 도약 기관 발사 →
> 가속 방어전 → 우주 최종장 → 엔딩까지 완주 가능하고, 잔류 선택 시 Day 챌린지
> 순환이 성립한다. 밸런스 수치는 에셋 수정만으로 바뀐다.
> **불변 지침**: 게임 중간 저장 없음(기획서 §9.1 — 런은 단일 세션 완주) ·
> 상태 변경은 호스트 권위 · 지역·웨이브·날씨·보스 정의는 전부 데이터(SO).

## 2. 기술 현황 (착수 시점 자산 — 확장 지점이 이미 준비된 것)

- **지역 확장 = 에셋 경로 (OCP)**: 지역 추가·순서·일수가 전부 `RegionDefinition` 에셋 —
  코드 무수정 예정 축 ([region-timeline §비범위](../specs/region/region-timeline.md): "대초원·북극이 이 경로로 예정").
  지형 프리팹·색채, 자원 종류+가중치, 온도, 웨이브 배율, 예고 연출 트리거까지 데이터.
- **날씨**: `WeatherDefinition` — 폭설(집게 사거리 감소)·혹한파는 에셋 추가.
  **스탬피드(대초원)는 날씨가 아니라 웨이브 이벤트** — 신규 설계 필요.
- **몬스터 변종**: `MonsterVariantCatalog`(수·체력·패턴 축 완비) + **그랩 무게 3 = 대형 변종 예약 자리**.
  보스를 변종 확장으로 갈지 전용 개체로 갈지가 결정 ④.
- **체온**: 3층 구조(`TemperatureMath` 순수/설정/호스트 권위) + 전 지역 온도(M5 7차) +
  단열·기본 체온 장비 축. **동상(부위 디버프)은 신규 축** — 허기가 체온과 대칭으로 성립했던 전례.
- **요리·보존**: `FoodCatalog`(요리별 회복·재생·보온) + `CraftingRecipe`/`RecipeCatalog`
  append-only — 보존식(소금 절임·훈제)은 레시피·요리 데이터 추가로 성립 전망.
- **건축물**: `StructureKind` byte append(현행 돔·난방·창고·제작대·화덕) — 정수 장치(얼음 → 식수)·
  **궤도 도약 기관**이 이 경로의 후보. 단, 도약 기관은 "완성 = 발사 가능"이라는 진행 상태를 갖는 점이 다르다.
- **가속 방어전 재료**: `IWorldScrollSpeedControl` 환경 배율 레이어(M4 — "부스트 아이템 등 다른
  개입원도 같은 레이어") + 연료 투입 경로(`EngineFuelPort`) — 가속 게이지의 발판.
- **게임오버·세션 종단**: M6 3차 `GameOverLogic`/`GameOverMonitor`/`SessionEvents` — 전멸 판정과
  종단 플래그가 있어, **클리어(엔딩) 분기를 같은 종단 규약으로 추가**하는 그림.
- **메타 진행**: `Systems/Meta` 저장 + `SteamAchievementsMirror`(임시 매핑) — 뉴게임+/챌린지
  해금 플래그의 저장소가 이미 있다.
- CI·EditMode 319+개(M5) 유지 — 순수 수식 분리(보스 패턴·동상·가속 게이지)로 같은 검증 방식 계속.

## 3. 착수 전 결정 — **전부 확정 (2026-08-13, 사용자 결정)**

| # | 결정 | 확정 내용 |
|---|---|---|
| ① | 최종장 상세(기획서 §8.3) 확정 시점 | **병행 확정** — 앞 차수(대초원~북극) 진행과 병행해 협의하고, 6차(우주 최종장) 착수 전까지만 확정하면 된다 |
| ② | 트랙 커브·경사 표현 (M4 이월, 시한 = M7) | **배경 연출만 — 직선 스크롤 유지** (미결 해소). 벡터 회전은 `WorldScrollMath` 위치 유도·조향·이탈 시뮬 전면 재검증이라 채택하지 않는다 |
| ③ | 터렛/거치 기관총 편입 | **M7 정식 차수로 편입** (4차) — 최종 보스 추격전(§8.3)의 "거치 무기 총동원" 전제 이행. 착수 전 결정 3건(점유 UX·탄약 경제·건축물 여부)은 해당 차수 계획에서 확정 |
| ④ | 지역 보스·최종 보스 개체 모델 | **전용 보스 개체** — 변종 확장이 아니라 전용 프리팹으로 간다. **외형 애셋은 외부 도입 예정, 프리팹 확정은 차후**(2차 계획에서 — 그 전까지 임시 외형으로 골격 개발). 풀링·네트워크 프리팹 목록 등록 규약 준수 |
| ⑤ | 대초원·북극 일수 | **기준안 착수** — 대초원 4일(Day 10~13) / 북극 3일(Day 14~16). `RegionDefinition.DayCount` 데이터라 밸런싱에서 언제든 조정 |
| ⑥ | 동상 시스템 범위 | **부위별 디버프 (기획 원안)** — 단, **완화 버프(보온·난방·스튜 등)는 몸 전체에 적용**되고, **부위별 동상 증상 여부는 그 부위에 입은 옷(장비 4부위)이 결정**한다. 기존 장비 슬롯(머리·상체·하체·신발)이 부위 단위가 된다 |
| ⑦ | 우주 최종장 무대 | **같은 Game 씬에서 환경 교체** — 지형 스트리밍 정지 + 우주 배경·산소 규칙 활성. NGO 씬 전환 신규 도입을 피하고 재접속 경로를 그대로 유지 |
| ⑧ | 뉴게임+/챌린지 순환 범위 | **최소 성립** — 잔류 = §4.5 재순환(숲→사막→… + 난이도 배율·변종) + 클리어 시 해금 플래그(Meta 저장). 뉴게임+ 전용 규칙은 출시 전 후속 |
| ⑨ | M5·M6 잔여 검증 편입 | **관련 축만 편입 (M6 방식 유지)** — 각 차수와 직결된 것만 그 차수 검증에 편입 (예: 4인 역할 분담 = 거치 무기 차수 겸사, G8 = 릴리스 전 외부 세션). M7 검증이 이월 물량에 파묻히지 않게 한다 |

## 4. 차수 분할 제안 (M5·M6 방식 — 차수별 구현 계획 + 플레이 검증 문서)

| 차수 | 내용 | 근거 |
|---|---|---|
| 1차 (대초원 — 풍요) | 지역 3종 등재(에셋 경로 실증) + 벼·사냥감 자원 + **보존식(소금 절임·훈제 — 사막 소금 연결)** + 스탬피드 이벤트 + 북극행 비축 루프 | 기획 확정도 최고(§4.3) · Steam 의존 0 · 기존 에셋 경로 검증을 겸한다 |
| 2차 (지역 보스) | **전용 보스 개체**(결정 ④ — 골격은 임시 외형으로 개발, 외부 애셋·프리팹은 이 차수 계획에서 확정) + "지역 마지막 밤 = 대형 웨이브 + **보스**"(기획서 §5) — 숲·사막 소급 포함 + 처치 보상 | M4는 대형 웨이브까지만 — 보스 골격을 북극·최종장 전에 세워 재사용 |
| 3차 (북극 — 최종 시험) | 지역 4종 등재 + 상시 혹한·**부위별 동상**(결정 ⑥ — 완화 버프는 전신, 증상 부위는 장비 4부위가 결정) + 얼음 정화(정수 건축물) + 방한 세트 + **유적 자원(우주 진입 부품 — §8 연결)** + 폭설·혹한파 날씨 | 대초원 비축 루프의 소비처 — 1·2차 산출을 전부 소모하는 검증 무대 |
| 4차 (거치 무기 — 결정 ③ 편입 확정) | 터렛 + 거치 기관총 — 열차 소유 + 조작권 점유 모델 (M5 이월 메모: `StructureKind` 확장 + `LocalInteraction` 점유 + `GunController` 재사용) | 최종장 추격전(§8.3)의 전제 — 5차보다 먼저 · 4인 역할 분담 검증 겸사 |
| 5차 (궤도 도약 기관·가속 방어전) | 도약 기관 건축물(북극 유적 부품 소모) + 발사/잔류 분기(§8.1) + **가속 방어전**(연료 투입 게이지 + 전 병력 추격 — B안) + 공간 왜곡·백화 연출 | 게임 상태 머신 재론(M6 이월)을 이 차수에서 — 분기·종단이 처음 생긴다 |
| 6차 (우주 최종장) | 산소 자원 + 잠입 몬스터 소탕(내부 근접전) + 최종 보스 "근원" 추격전(거치 무기 + 집게 피날레) + 엔딩·서사 | **결정 ①의 §8.3 확정이 선행 조건** — 1~5차와 병행 협의 |
| 7차 (챌린지 순환·메타) | 잔류 Day 챌린지(재순환 + 배율·변종) + 클리어 해금 플래그(Meta 저장·업적 후보) + 뉴게임+ 최소 성립(결정 ⑧) | 규칙·데이터 축 — 마지막에 몰아도 위험 없음 (M6 3차 전례) |
| 검증 | **완료 기준**: 숲→북극→발사→최종장→엔딩 완주 런 + 잔류 순환 성립. 편입 잔여는 결정 ⑨ | 완주 런은 실시간 소요가 크다 — QA 단축 수단(Day 스킵 등) 선결 검토 |

**차수 순서의 원칙**: 기획 확정도가 높은 것부터 (대초원·북극·보스 = §4·§5 확정 — 즉시 착수
가능), 미정 기획(§8.3)은 뒤 차수로 몰아 병행 확정한다. 보스·거치 무기 골격을 최종장보다
먼저 세워 6차가 조립이 되게 한다.
