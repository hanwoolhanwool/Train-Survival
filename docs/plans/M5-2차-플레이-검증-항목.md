# M5 2차 플레이 검증 항목 — 무기 공통 리팩터·샷건·볼트액션·마체테·무기 제작

작성일: 2026-08-05 · 대상: `feat/m5-combat-survival` · 상태: **검증 대기**

> **2차 목표** (개발 가이드 §5 M5 차수 분할): 무기 공통 리팩터(레이캐스트 3벌 복붙 해소) +
> 샷건·볼트액션·근접(마체테) + 탄약 3종 완성 + 무기 획득 = 제작 —
> **"사막 고철 → 무기·탄약 제작 → 전투" 루프가 종단으로 성립**하고, 리팩터로 기존 무기·도구
> (리볼버·수리 망치·집게)가 회귀 없이 동작하며, 밸런스 수치가 에셋 수정만으로 바뀐다.
> **검증 구성**: 개발 6원칙 1·2에 따라 **항상 호스트 1 + 클라이언트 1**로 확인한다.
> 1차 이월 TBD ③(낮/밤 사이클 회귀)을 이번 검증에서 겸사 확인한다 (→ H1).

## 0. 사전 준비

- [ ] Boot 씬에서 Play → 호스트 시작. 클라이언트 1대 접속(MPPM 가상 플레이어 또는 빌드)
- [ ] 접속이 조용히 거부되면(`ClosedByRemote`) **프리팹 해시 문제**다 — 이번 차수에서
      `Player.prefab`에 컴포넌트 3개(GunController ×2·MeleeWeaponController)를 추가했으므로
      `GlobalObjectIdHash`(1135503018)가 커밋 값과 같은지 먼저 확인 (diff 검수는 마쳤으나 접속으로 최종 판정)
- [ ] 콘솔을 열어둔다

**디버그 키** (호스트/클라 어디서 눌러도 호스트 권위 RPC로 처리)

| 키 | 동작 |
|---|---|
| 숫자패드 1 / 2 | 낮 / **밤** 국면 점프 — 밤 웨이브 전투 검증의 주 수단 |
| 숫자패드 3 | 다음 Day 아침으로 |
| 숫자패드 9 | **자원 지급: 목재 4 · 돌 2 · 고철 2 · 화약 원료 2** — 무기 제작에는 여러 번 누른다 (볼트액션 = 고철 5 필요 → 3회) |
| 숫자패드 6 | 부위 샘플 데미지 30 (망치 회귀 확인용) |
| 숫자패드 + | 세션 재시작 |

**기준 수치** (판정 근거 — 전부 데이터 에셋: `GunSettings`·`MeleeSettings`·`ResourceCatalog`·`Recipe_*`)

| 무기 | 데미지 | 사거리 | 장탄 | 발사 간격 | 재장전 | 탄약 (스택) |
|---|---|---|---|---|---|---|
| 리볼버 | 34 | 45 | 6 | 0.4 s | 2.2 s | 권총탄 (12) |
| 샷건 | **12 × 펠릿 7** (원뿔 반각 6°) | **20** | 2 | 0.8 s | 2.8 s | 산탄 (8) |
| 볼트액션 | **110** | 120 | 5 | **1.5 s (노리쇠)** | 3.2 s | 소총탄 (10) |
| 마체테 | 45 | **리치 2.6 m** (판정 반경 0.6) | — | 0.7 s | — | **없음 (무한)** |

레시피 (제작대): 권총탄 ×4 · **산탄 ×2** · **소총탄 ×3** = 각 고철 1 + 화약 원료 1 /
**마체테** = 고철 2 + 목재 1 / **샷건** = 고철 4 + 목재 2 / **볼트액션** = 고철 5 + 목재 2

몬스터 체력 (Day 체력 배율 1 기준): 일반형 100 · 돌진형 60 · 도약형 80 · 돌격형 220
→ 볼트액션 = 일반형 1방 · 샷건 전탄(84) = 돌진형 1방 · 마체테 = 돌진형 2방

## A. 리팩터 회귀 — 기존 무기·도구 (동작 변화 0 확인)

레이캐스트 통합·총기 공통화가 기존 동작을 바꾸지 않았는지 먼저 확인한다.

- [ ] **A1** 리볼버 사격·재장전·예비 탄약이 1차와 동일하다 (HUD "리볼버: 6 / 6 | 예비 8" — 표시명 포함)
- [ ] **A2** 리볼버 빈 실린더 좌클릭 자동 재장전·부분 장전·예비 0 거부가 그대로다 (1차 G3~G5 회귀)
- [ ] **A3** 수리 망치의 조준(부위 인식·체력 표시)·수리·돔 설치·칸 건설·재결합이 그대로다 (숫자패드 6으로 데미지 후 확인)
- [ ] **A4** 집게 발사가 조준점(화면 중앙)에 정확히 수렴한다 — 자원 그랩·견인·획득 정상 (M1 회귀)
- [ ] **A5** 셋 모두 **자기 몸에 맞지 않는다** (제자리에서 아래를 보고 발사/스윙해도 자기 피격 없음)

## B. 무기 제작 (획득 경로)

- [ ] **B1** 제작 창에 5줄이 추가돼 표시된다 — "산탄 제작 → 산탄 ×2" · "소총탄 제작 → 소총탄 ×3" ·
      "마체테 제작 → **마체테 ×1**" · "샷건 제작 → **샷건 ×1**" · "볼트액션 제작 → **볼트액션 ×1**"
      (무기 줄은 아이템명 ×1 표기)
- [ ] **B2** 숫자패드 9 ×3 → 마체테 제작 → **고철 −2 · 목재 −1**, 빈 칸에 "마체테" 아이템 1개 지급
- [ ] **B3** 제작한 마체테 칸을 핫바 1~5로 드래그 → 해당 숫자 키로 들 수 있다
- [ ] **B4** 샷건·볼트액션도 B2~B3과 동일 (재료 정확 차감 — 샷건: 고철 4·목재 2 / 볼트액션: 고철 5·목재 2)
- [ ] **B5** **빈 칸이 없는 상태**(전 슬롯 점유)에서 무기 제작 클릭 → 실패하고 **재료가 사라지지 않는다** (전량 실패 원자 규약)
- [ ] **B6** 같은 무기를 한 번 더 제작하면 두 번째 아이템이 생긴다 (중복 제한 없음 — 자리·재료가 곧 비용)
- [ ] **B7** **게스트도 B1~B4 동일** (확정 = 호스트, 거리 재검증 통과)

## C. 샷건

- [ ] **C1** 샷건을 들면 HUD에 **"샷건: 2 / 2 | 예비 n"** (무기별 표시명·장탄)
- [ ] **C2** 산탄 제작(고철 1+화약 1 → 2발) → 예비량에 합산 → R 재장전이 산탄만 소모한다 (권총탄 수량 불변)
- [ ] **C3** 근거리 몬스터에 1발 → **다펠릿 데미지** — 돌진형(60)이 한 방에 죽거나 일반형(100)이 크게 깎인다
      (리볼버 34와 체감 차이 확인)
- [ ] **C4** **사거리 20 밖**의 몬스터에는 데미지가 없다 (원거리 무력 — 역할 분리)
- [ ] **C5** 벽/열차 구조물 근처에서 쏘면 퍼진 탄이 구조물에 막힌다 (펠릿별 독립 판정)
- [ ] **C6** 산탄 2발 소진 → 좌클릭 → (예비가 있으면) 자동 재장전 — 리볼버와 같은 조작 규약
- [ ] **C7** 게스트 화면에서 호스트의 샷건 발사 트레이서가 보인다 (연출 브로드캐스트)

## D. 볼트액션

- [ ] **D1** 볼트액션을 들면 HUD에 **"볼트액션: 5 / 5 | 예비 n"**
- [ ] **D2** 좌클릭 연타 → **1.5 s 간격**으로만 발사된다 (노리쇠 체감 — 리볼버 0.4 s와 비교)
- [ ] **D3** 일반형(100)이 **1방**에 죽는다 (110 데미지)
- [ ] **D4** **원거리**(리볼버 사거리 45 밖, 120 안)의 몬스터가 맞는다 — 접근 전 저지 역할 성립
- [ ] **D5** 소총탄 제작 → 재장전 3.2 s 후 장전 — 예비 차감이 정확하다 (부분 장전 포함)
- [ ] **D6** 게스트도 C·D의 사격·재장전이 동일 (판정 = 쏜 클라이언트, 확정 = 호스트)

## E. 마체테

- [ ] **E1** 마체테를 들면 HUD에 탄약 줄이 **뜨지 않는다** (탄약 없는 무기)
- [ ] **E2** 리치(2.6 m) 안의 몬스터에 스윙 → 데미지 45 — 돌진형(60)은 2방
- [ ] **E3** 리치 밖에서는 스윙해도 아무 일 없다 (원거리 무력)
- [ ] **E4** 좌클릭 연타 → 0.7 s 간격으로만 스윙된다
- [ ] **E5** **탄약이 전부 0이어도 계속 쓸 수 있다** — "탄약 0일 때 최후 수단" 성립 (기획서 §6.2)
- [ ] **E6** 조준이 다소 어긋나도 맞는다 (스피어캐스트 반경 0.6 — 총기보다 관대한 판정)

## F. 핫바·HUD 통합

- [ ] **F1** 무기 전환(숫자 키) 시 HUD 탄약 줄이 **든 총의 것으로 즉시 전환**된다 (리볼버 ↔ 샷건 ↔ 볼트액션)
- [ ] **F2** 집게·망치·마체테·자원 칸을 들면 탄약 줄이 사라진다
- [ ] **F3** 인벤토리(I 창)에서 새 무기 칸이 "샷건"·"볼트액션"·"마체테"로 표시된다
- [ ] **F4** I 창·제작 창이 열린 동안 새 무기들도 발사·스윙이 정지한다 (입력 게이트 규약)
- [ ] **F5** 무기를 가방 칸으로 옮기면 들 수 없고, 핫바로 되돌리면 다시 들 수 있다
- [ ] **F6** 한 번에 한 무기만 활성이다 — 전환 직후 이전 무기 입력이 새 무기로 새지 않는다 (트레이서·판정 공유 확인)

## G. 멀티 정합성

- [ ] **G1** 게스트가 제작한 무기는 게스트만 들 수 있고, 호스트 화면의 게스트 인벤토리와 일치한다
- [ ] **G2** 게스트의 샷건·볼트액션 데미지가 호스트가 확정한 몬스터 체력에 정확히 반영된다 (킬 카운트 증가)
- [ ] **G3** 게스트의 마체테 스윙도 호스트 확정으로 몬스터가 죽는다
- [ ] **G4** 원격 플레이어의 발사 트레이서가 서로 보인다 (리볼버·샷건·볼트액션)

## H. 회귀 확인

- [ ] **H1** **낮 채집 → 밤 웨이브 → Day+1 사이클 정상** (M2 — **1차 TBD ③ 이월분**, 밤 전투 검증과 겸사)
- [ ] **H2** 밤 웨이브에서 신무기로 방어가 성립한다 — 샷건(승차 근접)·볼트액션(원거리 저지) 역할 체감
- [ ] **H3** 권총탄 제작·리볼버 루프가 그대로다 (1차 G7 회귀 — 채집 → 제작 → 사격)
- [ ] **H4** 엔진 투입·건설 비용에서 산탄·소총탄이 **소모되지 않는다** (발열량 0·비건자재 — 1차 D3·E4 확장)
- [ ] **H5** 세션 종료·재시작(숫자패드 +) 시 오류 없음
- [ ] **H6** EditMode 252개 통과 (커밋 시점 확인 완료 — 재확인만)
