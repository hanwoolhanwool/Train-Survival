# M5 4차 플레이 검증 항목 — 허기·식량·화덕·요리 버프 (+ 3차 후속·이월)

작성일: 2026-08-07 · 대상: `feat/m5-combat-survival` · 상태: **검증 대기**

> **4차 목표** (개발 가이드 §5 M5 차수 분할): 허기 스탯(체온과 같은 3층 구조) + 화덕 + 요리 버프 —
> **"낮에 채집·지급받은 식재료를 화덕에서 요리해 허기를 채우고, 요리 버프(재생·보온)가 밤 생존을
> 돕는" 루프가 종단으로 성립**하고, 밸런스 수치가 에셋 수정만으로 바뀐다.
> **검증 구성**: 개발 6원칙 1·2에 따라 **항상 호스트 1 + 클라이언트 1**로 확인한다.
> **3차 이월 8건을 이번 검증에 편입한다** (→ F·G2·H1). 선결 수단이던 몬스터 스폰 토글이
> 이번 차수에 들어왔으므로 밤 노숙 검증이 가능해졌다.

## A. 허기 스탯

- [ ] **A1** HUD 하단 상태 줄에 **"허기: 100 / 100"** 이 뜨고 시간이 지나면 줄어든다
- [ ] **A2** I 창 캐릭터 상태에도 허기가 뜬다 — 3차까지의 "이후 요리 시스템(M5)에서 추가" 문구가 사라졌다
- [ ] **A3** 30 밑으로 내려가면 **노란색 "허기! 요리를 먹어라"** 경고가 뜬다 (I 창은 "(배고픔)" 접미)
- [ ] **A4** 0에 닿으면 **빨간색 "굶주림! 체력이 깎인다"** 로 바뀌고 체력이 실제로 깎인다 (2/초)
- [ ] **A5** 굶주림으로 사망 → 부활하면 **허기가 100으로 리셋**된다 (부활 즉사 루프 없음)
- [ ] **A6** 게스트 화면의 허기도 같은 값·같은 경고다 (호스트 권위 — 각자 자기 허기만 보인다)
- [ ] **A7** 호스트와 게스트의 허기가 **서로 독립**이다 (한쪽이 먹어도 다른 쪽은 그대로)

## B. 식량 자원·요리 제작

- [ ] **B1** 숫자패드 9로 **식재료 4개**가 지급된다 (초록색 슬롯, 표시명 "식재료")
- [ ] **B2** 지상에 **식재료 노드가 스폰**되고 집게로 회수된다 (숲 가중치 0.2 / 사막 0.15 — 몇 분 관측)
- [ ] **B3** **식재료는 엔진에 투입되지 않는다** (발열량 0 — 좌클릭·E 모두 무반응, 화약 원료와 같은 취급)
- [ ] **B4** **식재료는 건설 비용으로 소모되지 않는다** (건자재 아님 — 망치 설치가 식재료를 먹지 않음)
- [ ] **B5** 화덕 근처 제작 창에 **요리 2줄**이 뜬다 — "구운 식사 요리 → 구운 식사 ×1" / "든든한 스튜 요리 → 든든한 스튜 ×1"
- [ ] **B6** 재료가 정확히 차감된다 (구운 식사 = 식재료 2 / 스튜 = 식재료 4), 부족하면 버튼이 비활성
- [ ] **B7** 요리는 **스택으로 적재**된다 (무기 산출과 달리 빈 칸 강제 없음, 스택 상한 5)
- [ ] **B8** 게스트의 요리 제작도 동일하게 확정된다

## C. 화덕 건축물·제작 지점 필터

- [ ] **C1** 망치 R 키 순환이 **5종**이 됐다 — 돔 → 난방기 → 창고 → 제작대 → **화덕** → 돔
- [ ] **C2** 화덕 설치 비용이 3으로 표시·차감되고, 배너가 **"화덕 설치! (#n번 칸)"** 로 뜬다
- [ ] **C3** 화덕 외형이 다른 4종과 구분된다 (납작한 숯색 원통), 게스트 화면도 같다
- [ ] **C4** 화덕 칸 근처에서 E → **제작 창이 열리고 요리 2줄만 보인다** (탄약·무기·장비 줄은 안 보임)
- [ ] **C5** **제작대·기관차 근처에서는 요리 줄이 안 보인다** (기존 레시피 11종만) — 지점 종류 분리
- [ ] **C6** 화덕과 제작대를 **모두 근처에 두면 양쪽 레시피가 다 보인다** (두 지점 동시 유효)
- [ ] **C7** 화덕이 파괴되면(숫자패드 6) 그 칸에서 요리 줄이 사라진다 (제작대·기관차는 그대로)
- [ ] **C8** 화덕 칸 위는 **밤 추위를 막지 못한다** (난방 아님 — 난방기와 역할 분리, §3 결정)
- [ ] **C9** 몬스터가 화덕도 공격한다 (표적 등록 회귀 — 스폰 토글을 켠 상태로)
- [ ] **C10** 수리 망치 좌클릭 수리가 화덕에도 동작한다

## D. 섭취·버프

- [ ] **D1** 요리 슬롯을 들고 **좌클릭 = 먹기** — 1개가 차감되고 허기가 오른다 (구운 식사 +35 / 스튜 +60)
- [ ] **D2** **엔진 앞에서 요리를 들고 좌클릭해도 연료로 들어가지 않는다** (먹기만 확정 — 이중 소모 없음)
- [ ] **D3** 허기가 **가득일 때는 먹어도 소모되지 않는다** (낭비 섭취 거부)
- [ ] **D4** I 창·창고 창·제작 창이 열린 동안에는 좌클릭으로 먹히지 않는다 (창 규약)
- [ ] **D5** **사망 상태에서는 먹을 수 없다**
- [ ] **D6** 구운 식사 → HUD에 **"버프: 재생 15s"** 가 뜨고 체력이 초당 1씩 찬다 (최대치에서 멈춤)
- [ ] **D7** 스튜 → **"버프: 재생 20s 보온 90s"** 가 함께 뜬다 (한 요리 두 버프)
- [ ] **D8** 버프 잔여 시간이 실시간으로 줄고 0이 되면 줄이 사라진다
- [ ] **D9** 같은 버프를 다시 먹으면 **지속이 갱신**된다 (중첩 아님 — 세기는 그대로)
- [ ] **D10** 사망하면 버프가 사라진다 (부활 후 이전 식사 효과가 남지 않음)
- [ ] **D11** **보온 버프 중 사막 밤 노숙 → 체온 하락이 느려진다** (실효 4.4 ℃ — 26초 → 37초)
- [ ] **D12** **가죽 옷 + 보온 버프 → 실효 8.4 ℃** (34 ℃ 도달 130초 — 밤을 거의 버틴다)
- [ ] **D13** 게스트의 섭취·버프·효과가 동일하다 (확정·적용 모두 호스트)

## E. 3차 후속 소규모

- [ ] **E1** **사망 상태에서 건축물 설치가 안 된다** (3차 발견 버그 — 우클릭 무반응)
- [ ] **E2** 사망 중 수리·칸 건설·재결합도 안 된다 (같은 게이트)
- [ ] **E3** 부활하면 다시 정상 동작한다 (게이트가 영구히 닫히지 않음)
- [ ] **E4** **Esc가 열린 I 창을 먼저 닫는다** (세션 메뉴가 뜨지 않음) — 3차 개선 방향
- [ ] **E5** Esc가 열린 **창고 창**을 닫는다 / **제작 창**을 닫는다
- [ ] **E6** 열린 창이 없을 때 Esc → **세션 메뉴가 열린다** (기존 동작 유지)
- [ ] **E7** 세션 메뉴가 열린 상태에서 Esc → 메뉴가 닫힌다
- [ ] **E8** **숫자패드 5로 몬스터 스폰이 꺼진다** — 진행 중이던 웨이브가 즉시 회수되고 콘솔에 로그가 뜬다
- [ ] **E9** 꺼진 상태로 밤에 진입해도 **몬스터가 나오지 않는다** ("밤 웨이브 생략" 로그)
- [ ] **E10** 다시 눌러 켜면 **다음 밤부터 웨이브가 재개**된다
- [ ] **E11** 게스트가 눌러도 호스트 확정으로 동작한다 (RPC 경유)

## F. 3차 이월 재검증 (밤 노숙 계열 — 스폰 토글로 가능해짐)

> 진행법: 숫자패드 3으로 사막(Day 6+) 진입 → **숫자패드 5로 몬스터 끄기** → 숫자패드 2로 밤 점프 → 갑판이 아닌 지상/노출 위치에서 관측.

- [ ] **F1** (3차 B1) 사막 밤 노숙 → 체온이 계속 내려가 **34 ℃ 밑에서 지속 피해** — 2 ℃ 복원 확인
- [ ] **F2** (3차 B2) 추위 경고 HUD에 **"추위! 난방 칸 위로"** 행동 지시가 뜬다
- [ ] **F3** (3차 B6) **난방기가 파괴되면 즉시 완화가 사라진다** (칸 위에서 체온이 다시 하락으로 전환)
- [ ] **F4** (3차 B7) 게스트도 F1~F3 동일 (체온은 호스트 권위 — 서버 계산 정합)
- [ ] **F5** (3차 F6) **가죽 옷 착용 → 몬스터 피해가 15% 준다** (스폰을 켜고 피격 실측 — 풀셋은 50%)
- [ ] **F6** (3차 F7) **가죽 옷 착용 → 밤 체온 하락이 느려진다** (실효 6 ℃ — 경고는 뜨되 피해 지연)
- [ ] **F7** (3차 F10) **체온 피해는 장비 피해 감소의 영향을 받지 않는다** — 방한 없는 풀 방어구로
      밤 노숙 시 피해량이 맨몸과 같다 (환경 피해 경로 분리)
- [ ] **F8** **방한 풀셋 + 스튜 보온 버프 → 사막 밤을 노숙으로 버틴다** (실효 9.2 ℃ · 클램프 0.9 확인 —
      단 버프 90초가 끊기면 다시 하락. 4차가 만든 새 생존 선택지)
- [ ] **F9** **기아 피해도 장비 피해 감소를 받지 않는다** (허기 0 + 풀 방어구 → 여전히 2/초)

## G. 멀티 정합성 (횡단 확인)

- [ ] **G1** 게스트의 화덕 설치(R 순환 포함)가 호스트 확정으로 반영되고 양쪽 화면이 같다
