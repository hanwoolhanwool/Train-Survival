## 개선사항
- 지상 위 플레이어 둘이 가만히 사있을 경우 눈 앞에 서있는 플레이어가 떨림현상이 나타난다.
  → *분석 (2026-08-13): 지상에서는 "가만히 서 있어도" 실제로는 둘 다 매 프레임 스크롤
  속도만큼 뒤로 밀리는 중이다(상시 외력형 — 소유자 로컬 적용, 네트워크 §4.2). 원격 플레이어
  표시는 NetworkTransform 스냅샷 수신 + 보간이라, 관찰자 자신의 연속 이동과 상대 스냅샷
  보간의 위상이 어긋나 근거리에서 떨림으로 보인다 — 열차 위에서는 둘 다 정지(델타 0)라
  나타나지 않는 이유.*
  → *시도 ① (2026-08-13): 위치 보간 `LegacyLerp(0)` → `SmoothDampening(2)` 교체 —
  **실패, 롤백** (재검 P1 결과: 떨림이 더 심해짐). SmoothDampening은 틱 지연이 큰 원거리
  환경용 감쇠라, MPPM처럼 지연이 거의 0인 로컬 환경에서는 감쇠 자체가 목표를 계속 뒤쫓으며
  진동을 키운 것으로 보인다. 프리팹은 원값(LegacyLerp) 복원 완료 — 해시 무변(1135503018).*
  → *다음 후보 (착수 전 사용자 결정): ⓐ `Lerp(1)` 교체 — 선형 버퍼 소비형(감쇠 없음, 신형)
  ⓑ 틱 레이트 상향(30 → 60, `NetworkManager` 설정) — 스냅샷 밀도를 올려 위상차 자체를 축소
  ⓒ 근본 처방: 지상 밀림을 관찰자도 로컬 예측(스크롤 속도만큼 원격 표시를 보정) — 구현 비용
  가장 큼. 권장 = ⓐ부터 (1줄, 즉시 재검 가능).*
