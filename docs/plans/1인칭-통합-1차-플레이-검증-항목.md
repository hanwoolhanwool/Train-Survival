# 1인칭 통합 1차 플레이 검증 항목 — 모드 스위치 + 소유자 몸 개방

작성일: 2026-08-18 · 대상: `feat/structure-grid` · 상태: **검증 대기**
(구현: [1인칭-통합-시점-전환-계획.md](1인칭-통합-시점-전환-계획.md) 단계 1~3 — §5.0의 브랜치 제약 적용.
컴파일 에러 0 상태에서 시작)

> **1차 목표**: **F10으로 분리 ↔ 통합 1인칭을 오갈 수 있고, 통합 모드에서 자기 몸이 보이며,
> 화면 전용 뷰모델은 사라진다.** 그러면서 **판정·원격 화면·대역폭은 두 모드가 완전히 같다**.
>
> **이 차수의 통합 모드는 무기가 손에 없는 미완성 상태다** — 손 파지 구현(`feat/weapon-hold`)이
> 이 브랜치에 없기 때문이며, 의도된 중간 상태다 (계획 §5.0). 무기 관련 항목은 §H로 이월한다.
>
> **검증 구성**: 원칙대로 **호스트 1 + 클라이언트 1** (MPPM 가상 플레이어). A~F는 단독으로도 가능.

## 0. 사전 준비

- [ ] **씬 변경 없음** — 코드 + `Player.prefab` 배선 2건 + 신규 에셋 1개뿐
  - `Player`(루트) → `PlayerViewModeController` (`_settings` = `PlayerViewSettings.asset`)
  - `CameraRig/CameraPivot/PlayerCamera` → `PlayerCameraTuner`
- [ ] **기본 모드는 분리(현행)** — `PlayerViewSettings._defaultMode = SplitFpTp`.
      즉 **아무것도 안 누르면 지금까지와 똑같아야 한다**
- [ ] 전환 키는 **F10** (F9 = 구속 상태 디버그, 숫자패드 = QA 핫키 — 충돌 없음)
- [ ] 전환 시 콘솔에 `[PlayerViewModeController] 시점 모드 = ...`가 찍힌다

**기준 수치** (전부 `PlayerViewSettings.asset`)

| 항목 | 분리 | 통합 |
|---|---|---|
| near clip | 0.3 | **0.08** |
| FOV | 60 | 60 |
| 카메라 로컬 오프셋 | (0, 0, 0) | **(0, 0, 0.06)** |
| 소유자 몸 렌더 | ShadowsOnly | **On** |
| 머리 본 스케일 | 원본 | **×0.001** |

## A. 모드 스위치 (계획 §3.1 · §4.1)

- [ ] **A1** F10을 누르면 화면이 즉시 바뀐다 (재접속·재스폰 불요)
- [ ] **A2** F10 **왕복 5회** — 매번 같은 그림으로 돌아온다. 잔상·이중 표시·자세 튐 없음 (멱등성)
- [ ] **A3** 콘솔 로그의 모드 값이 화면 상태와 일치한다
- [ ] **A4** `_debugToggleEnabled = false`로 두면 F10이 먹지 않고 기본 모드로 고정된다
- [ ] **A5** `_defaultMode = UnifiedFirstPerson`으로 두면 **스폰 직후부터** 통합 모드다

## B. 소유자 몸 표현 (계획 §3.2)

- [ ] **B1** 통합 모드에서 **아래를 내려다보면 자기 몸통·다리·팔이 보인다**
- [ ] **B2** 분리 모드로 되돌리면 몸이 다시 사라지고 **그림자만** 남는다 (현행 회귀 없음)
- [ ] **B3** 통합 모드에서도 자기 **그림자는 계속 나온다** (렌더 모드가 On이므로 당연 — 결손 확인용)
- [ ] **B4** 걷기·달리기·점프 중 몸이 자연스럽게 움직인다 (Animator culling 회귀 없음)
- [ ] **B5** 사망·부활 시 몸 표시가 깨지지 않는다
- [ ] **B6** 통합 모드에서 **손에 쥔 무기가 그림자가 아니라 실물로 렌더**된다
      (`HeldWeaponSocket` 모드 반영 — 분리 모드에서는 그림자만)
- [ ] **B7** **무기를 든 채로** F10을 왕복해도 손 무기의 표시/그림자 전환이 매번 반영된다
      (표시 여부는 그대로이고 그림자 모드만 바뀌는 경로 — 조기 반환 회귀 확인)

## C. 머리 은닉 (계획 결정 ③ ⓒ · R4)

- [ ] **C1** 통합 모드에서 **머리 메시가 시야를 막지 않는다**
- [ ] **C2** 고개를 위·아래(±85°)로 끝까지 돌려도 목·턱·머리카락이 화면에 침범하지 않는다
- [ ] **C3** **자기 그림자에 머리가 없다** — 이 결손이 수용 가능한지 판정한다 (**불합격 시 R4 대응**)
- [ ] **C4** 분리 모드로 되돌리면 그림자에 **머리가 돌아온다** (원복 확인)
- [ ] **C5** **다른 피어 화면에서는 내 머리가 정상**이다 (로컬 Transform 조작이라는 전제 확인)
- [ ] **C6** `_hideHeadBone = false`로 두면 머리가 그대로 보인다 (near clip 단독 판정용)

## D. 카메라 파라미터 (계획 §3.4)

- [ ] **D1** 통합 모드에서 near clip이 0.08로 적용된다 — 가까운 물체가 덜 잘린다
- [ ] **D2** **원거리 지형·열차·산에서 z-fighting(면 깜빡임)이 없다** (near 축소의 대가 확인 — V12)
- [ ] **D3** 카메라 오프셋 0.06 m 전진이 시점 이동으로 느껴지지 않는다
- [ ] **D4** 벽에 바짝 붙어도 벽 너머가 비쳐 보이지 않는다 (near 축소 부작용)
- [ ] **D5** 분리 모드 복귀 시 near 0.3 · 오프셋 0으로 정확히 되돌아온다

## E. FP 뷰모델 게이트 (계획 §3.2 · §3.6)

- [ ] **E1** 통합 모드에서 **리볼버·샷건·집게·망치 뷰모델이 화면에서 사라진다**
- [ ] **E2** 통합 모드에서 마체테 휘두르기 모션이 재생되지 않는다 (수용된 회귀 — §H로 이월)
- [ ] **E3** 분리 모드로 돌아오면 4종 뷰모델과 스윙이 **전부 정상 복귀**한다
- [ ] **E4** 핫바 슬롯을 바꿔가며 전환해도 표시 상태가 꼬이지 않는다
- [ ] **E5** UI 패널(I·제작·창고)을 연 채 전환해도 뷰모델 상태가 어긋나지 않는다

## F. 판정 불변 — **비교의 기준선** (계획 §4.2)

> 여기서 어긋나면 그 자체가 결함이다. "F10에서 달라지는 것은 내 화면뿐"이어야 한다.

- [ ] **F1** 같은 표적을 두 모드에서 사격 — **명중·데미지·킬 판정이 동일**하다
- [ ] **F2** 두 모드에서 HUD 탄약·재장전 동작이 같다
- [ ] **F3** 집게 그랩·견인이 두 모드에서 같게 성립한다 (사거리 판정 무변)
- [ ] **F4** 망치 수리·건축·철거가 두 모드에서 같게 동작한다
- [ ] **F5** 마체테 근접 타격 **판정**은 통합 모드에서도 정상이다 (모션만 없다 — E2)
- [ ] **F6** 이동·점프·손잡이 잡기가 두 모드에서 같다

## G. 2인 매트릭스 — 모드가 원격에 새지 않는지 (계획 §4.3)

> 모드는 복제되지 않으므로 호스트와 클라가 **서로 다른 모드**로 붙을 수 있다.

- [ ] **G1** 조합 **A (분리/분리)** — 현행과 완전히 동일. 회귀 없음 (기준선)
- [ ] **G2** 조합 **B (호스트 통합 / 클라 분리)** — 호스트 화면은 통합, **클라가 보는 호스트의 모습은 G1과 동일**
- [ ] **G3** 조합 **C (호스트 분리 / 클라 통합)** — B의 대칭. 어느 쪽이 서버인지가 결과를 바꾸지 않는다
- [ ] **G4** 조합 **D (통합/통합)** — 양쪽 모두 자기 몸이 보이고 서로의 모습도 정상
- [ ] **G5** 상대의 **뷰모델·조준 피치·발사 연출**이 내 모드와 무관하게 보인다
- [ ] **G6** 재접속 후 모드가 기본값으로 돌아오고 표현이 깨지지 않는다
- [ ] **G7** Girl↔Man 교대(시각 슬롯)에서 두 모델 모두 같은 몸 표시·머리 은닉이 적용된다
- [ ] **G8** 4인(또는 3인) 접속에서도 각자 모드가 서로를 오염시키지 않는다

## H. 자세 튜닝 후에 성립하는 항목 (계획 단계 4~6)

> **2026-08-18 갱신**: `feat/weapon-hold` 병합(`aff8c98`)으로 손 파지가 합류했다.
> 통합 모드에서 **무기가 손에 쥐어지지만 아직 화면 밖**이다 — 홀드 타깃이 TP용 값이라
> 카메라 기준 수직 37.9°(리볼버)~54.9°(샷건) 아래에 있고 FOV 60의 하단 경계는 30°다 (계획 §1.3).
> 아래 항목은 단계 4(프로파일 2벌)·6(자세 튜닝) 이후에 판정한다.

- [ ] **H0** (지금 확인 가능) 통합 모드에서 무기를 들면 **손에 무기가 쥐어져 있다** —
      화면 아래로 시선을 내리거나 자세를 보면 확인된다. 이것이 §1.3 진단의 실물 확인이다
- [ ] **H1** 무기 5종이 손에 쥐어져 **화면 안에** 보인다 (계획 §1.4 — 시야·도달 조건)
- [ ] **H2** 피치 ±85° 전 구간에서 팔이 부러지듯 펴지지 않는다 (R2)
- [ ] **H3** 양손 무기(샷건) 왼손 도달률 (R3)
- [ ] **H4** 트레이서·로프가 **손 무기의 총구**에서 나간다 (계획 §3.5 이중 앵커)
- [ ] **H5** 근접 휘두르기 모션 대체 경로 (계획 §3.6 ⓑ — E2의 회귀 해소)
- [ ] **H6** 로코모션 흔들림이 무기에 과하게 실리지 않는다 (`ShoulderFollow` 판정 — R6)
- [ ] **H7** 벽 근접 시 무기 관통 (R5)
