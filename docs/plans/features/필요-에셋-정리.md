# 필요 에셋 정리 — 2026-09-10 실측 / 이미지 2026-10-27 갱신

현재 저장소에 **없어서 앞으로 확보해야 하는 에셋**을 한 곳에 모은 것이다. 이미지 제작·적용 항목(§4·§9)은 2026-10-27에 갱신했고, 나머지 수치·모델 상태는 최초 실측 시점 기록이다.

[`오디오 가이드`](../../design/Train-Survival-오디오-가이드.md) §18·§21이다.

## 1. 크리처 — 화면에서 가장 크게 비어 있다

### 1.1 보스 5종 (모델 4 + 머티리얼 4 + 텍스처 4)

| 지역 | 현재 Visual | 상태 |
|---|---|---|
| 숲 · 거수 | 캡슐(2.4, 2.2, 2.4) + 구체 머리 | 프리미티브 |
| 사막 · 모래 포식자 | 큐브(2.2, 1.8, 4.4) + 큐브 머리 | 프리미티브 |
| 대초원 · 무리 우두머리 | 큐브(2.6, 2.2, 3.8) + 실린더 뿔 | 프리미티브 |
| 북극 · 설원의 파수꾼 | **사막과 서브트리가 한 글자도 안 다르다** | 프리미티브 · 복제 |
| 바다 | **`Boss_Sea.prefab`이 없다** — `BossDefinition_Sea`가 `Boss_Forest.prefab`(guid `…d801`)을 그대로 가리킨다 | 프리팹부터 없음 |

- 4종이 일반 몬스터와 **같은 `MonsterBody.mat` 한 장**을 공유하고 Emission이 0이라 눈도 별씨 결정도 없다.
- 생성 지시·크기·콜라이더 갱신값은 브리프 §N.2~§N.7에 완비돼 있다. **바다 보스만 시트가 없다.**

### 1.2 몬스터 변종

변종은 프리팹이 아니라 `MonsterSettings`로만 구분하는 규약이라, 모델이 없으면 **여우형 `Monster_Guardian`이 색만 바뀌어 나온다.**

| 변종 | 현재 모델 | 필요 |
|---|---|---|
| Runner · Brute · Leaper | `Monster_Guardian.fbx` 공유 | 실루엣 분화용 2~3종 |
| Stampede | `Mesh_Env_Bison`(절차) | 판정 후 교체 |
| **SeaLeaper** (별들린 물고기) | 없음 | `Monster_SeaLeaper` 800 tris — 브리프 §O.6 |
| **SeaFlyer** (별들린 바닷새) | 없음 | `Monster_SeaFlyer` 900 tris — 브리프 §O.6 |

### 1.3 보스 핵 `BossCore`

모델·아이콘 둘 다 없다. **채집으로 못 얻는 유일한 자원**인데 자원 12종 시트(§J)에서도 빠져 있고,
카탈로그 색 `#9E298C`가 별씨 보라 `#8E7BE8`와 달라 어느 쪽에 맞출지 미결이다.

## 2. 바다 지역 — 전용 모델 0종

바다 타일 10종을 훑으면 **커스텀 메시 참조 0 · 내장 프리미티브 참조 468**이고,
재사용 중인 6종은 전부 숲·공용 모델이다(브리프 §O.0, 2026-08-29 실측).

| 묶음 | 에셋 | tris |
|---|---|---:|
| 교량 3종 | `Env_SeaDeck_A` · `Env_SeaDeck_Open_B` · `Env_SeaLadder_A`⚠ | 400 / 600 / 300 |
| 교각 3종 | `Env_SeaPier_Truss_A` · `Env_SeaPier_Arch_A` · `Env_SeaPier_Broken_A` | 1,200 / 1,400 / 1,000 |

| 소품 2종 | `Env_Buoy_A` · `Prop_FishingRod_A` | 200 / 400 |

## 6. 애니메이션

지금 있는 것은 캐릭터 FBX 내장 **6종**(`idle` · `walk` · `run` · `jump` · `turn` · `defeat_03`)과 손 파지 3클립뿐이다.

없는 것: **채집 스윙 · 총 발사/재장전 · 근접 휘두르기 · 건설 · 수영 · 사다리 오르내리기 · 피격**.
특히 수영은 지금 **남이 헤엄치는 모습이 걷는 자세**이고(미결정 ⑭), 몬스터도 **물면 높이에서 걸어서** 온다(검증 H4).

## 8. 오디오 — **0 / 275~365 클립**

프로젝트에 `.wav`·`.mp3`·`.ogg`가 한 개도 없다. 가이드 §18의 규모 추정:

| 구분 | 클립 수 |
|---|---:|
| 열차 | 25~35 |
| 집게 | 25~30 |
| 전투 | 45~60 |
| 몬스터·보스 | 60~80 |
| 플레이어 | 40~55 |
| 건설·제작·인벤토리 | 35~45 |
| UI | 20~25 |
| 앰비언스 루프 | 15~20 |
| 음악 | 10~14 |
| **총계** | **275~365** |

전부 직접 제작한다는 뜻은 아니다 — **라이브러리 구매 + 편집**이 현실적 경로이고 **라이선스 확인이 선행**된다(§22).
가이드 §21.1에 "구독만 하면 되는 훅", §21.2에 "코드 작업이 선행되는 훅"이 갈라져 있다.

## 10. 착수 순서 제안 — 화면에 튀는 순서

1. **바다 전용 12종** — 프리미티브 468개가 한 지역을 통째로 덮고 있어 투입 대비 변화가 가장 크다
2. **보스 4종 + 사막 폭풍 VFX** — 지금 사막과 북극이 같은 것이고, 시트(§N)가 이미 완비돼 바로 생성 가능
3. **바다 몬스터 2종** — 지역 고유 위협인데 여우형이 청록색으로 튀어오른다
4. **지면 텍스처 2장** — 2026-10-27 제작·적용 완료
5. **역 프롭 6종 + BoardingRamp** — 블록아웃 씬 전체가 걸려 있다
6. 애니메이션(수영·채집·사격) → 오디오 1차(열차·집게·전투). 아이템 아이콘은 2026-10-27 제작·적용 완료

> 4·6번은 순서를 바꿔도 된다. 1~3번은 브리프에 프롬프트가 이미 있어 **생성만 하면 되는 상태**이고,
> 아이콘 데이터와 화면 연결은 완료했다. 오디오 훅 §21.2와 후속 피드백 이미지는 별도 작업이다.
