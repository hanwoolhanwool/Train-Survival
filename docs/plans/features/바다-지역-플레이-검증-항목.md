작성일: 2026-08-27 · 대상: `feat/sea-region` · 상태: **1회차 완료(결함 1건 수정) · 2회차 대기**
상위 문서: [`바다 지역 구현 계획`](바다-지역-구현-계획.md)

> **왜 필요한가.** 0~3차는 **렌더와 EditMode로만** 확인했다. EditMode 1094/1094은
> *"계산이 맞다"*는 뜻이지 *"할 만하다"*는 뜻이 아니다. 계획서가 판정을 미뤄 둔 미결정이
> 다섯 있고(⑩·⑬·⑭·⑮·⑯), 그중 **⑩과 ⑮는 걸어보고 세어봐야만** 답이 나온다.

## I. 미결정 ⑩ — 열차 옆 1.15 m ⚠⚠⚠

**이 문서에서 가장 중요한 구역이다.** 렌더로는 판정할 수 없다.
상판 ±4 m에서 기관차 오버행 2.85 m를 빼면 **걸을 수 있는 폭이 1.15 m**다.

| # | 항목 | 판단할 것 | 결과 |
|---|---|---|---|
| I1 | 걸어서 통과 | 열차 옆 통로를 **끝에서 끝까지 걸어본다** | |
| I2 | 긴장인가 불쾌인가 | *"아슬아슬해서 재밌다"* vs *"자꾸 빠져서 짜증난다"* | |
| I3 | 실수 낙하 빈도 | 몇 번 걸어서 몇 번 빠지는가 | |
| I4 | 전투 성립 | 이 폭에서 몬스터와 싸울 만한가 | |
| I5 | 집게 조작 | 이 폭에서 부표를 겨눌 만한가 | |
| I6 | **판정** | 폭 유지 / 넓힘(±5~6) / 난간 부활 **중 하나** | |

## 회차 기록

### 1회차 — 2026-08-27

| 항목 | 결과 |
|---|---|
| **B8 물면 단차** | ❌ **결함** — *"물의 높낮이가 다른 타일이 지속적으로 발생한다"* |

**원인**: E(얕은 여울)의 물면만 −1.5로 만들어 나머지(−4)와 **2.5 m 단차**. 가중 0.13이라
**평균 51초마다** 계단이 지나갔다. 여울을 *"수면이 높은 것"*으로 잘못 만든 설계 오류다 —
실제로는 **바닥이 얕은 것**이고, 수면 높이는 바다 어디나 같다.

**처방** (계획서 §3.4로 규칙화): 물면은 전 세그먼트 **−4 고정** · 해저 경계는 **−12 고정** ·
얕음은 **타일 안쪽(\|z\| ≤ 16) 둔덕**으로. E의 교각·앵커·부표·암초·사다리를 전부 새 기준에
맞추고 10종 전수로 경계면 일치를 검증했다. **사용자 확인: "물 단차는 사라졌다"** ✅

> 1회차는 **B8 하나만** 확인됐다. 나머지 구역은 2회차 대상이다.
