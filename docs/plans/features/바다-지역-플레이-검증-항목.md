# 바다 지역 플레이 검증 항목 (0·1·2차)

작성일: 2026-08-27 · 대상: `feat/sea-region` (0차 블록아웃 · 1차 화면 · 2차 수영·잠수) ·
상위 문서: [`바다 지역 구현 계획`](바다-지역-구현-계획.md)

> **왜 필요한가.** 0~2차는 전부 **렌더와 EditMode로만** 확인했다. 계획서가 판정을 미뤄 둔 항목이
> 셋 있고(미결정 ⑩·⑬·⑭), 그중 **⑩ "열차 옆 1.15 m가 살 만한가"는 걸어봐야만 알 수 있다.**
> EditMode 1069/1069은 "계산이 맞다"는 뜻이지 "할 만하다"는 뜻이 아니다.

---

## 0. 진입 절차

| 단계 | 내용 |
|---|---|
| 1 | Unity에서 **`Boot.unity`를 열고 Play** — 인게임 씬은 직접 Play할 수 없다(`NetworkManager`가 Boot에 있다) |
| 2 | 메뉴 → **방 만들기** → 대기실 → **출발** |
| 3 | 인게임(`Game_ArtTest`) 진입 — **Day 1 숲**에서 시작한다 |
| 4 | **숫자패드 `3`을 9번** 누른다 → Day 10 = **바다** |

> **라우트를 되돌려 놓았다.** `GameplaySceneRoute.Name`이 기차역 검증용
> `Game_StationBlockout`을 가리키고 있어 **`Game_ArtTest`로 원복**했다.
> 기차역 2차 B 검증을 다시 할 때는 그 상수를 도로 바꾼다.

### 쓰는 QA 키

| 키 | 용도 |
|---|---|
| 숫자패드 `3` | **다음 Day 아침** — 지역 전환의 주력. Day 10까지 9번 |
| 숫자패드 `1` / `2` | 현재 Day의 낮 / 밤 시작으로 점프 — **밤 시인성(G 구역)** 확인용 |
| `F3` | 시간 배속 ×1 → ×4 → ×16 |
| 숫자패드 `/` · `.` | 지역 보스 소환 · 즉시 처치 |

## A. 지역 편입 (1차)

| # | 항목 | 기대 |
|---|---|---|
| A1 | Day 9 → Day 10 전환 | 지역 배너가 **"바다"**로 바뀐다 |
| A2 | 예고 | Day 8~9(사막 마지막 이틀)에 HUD가 **다음 지역 = 바다**를 예고한다 |
| A3 | 순환 | Day 12 → 13에 **대초원**으로 넘어간다 (바다는 3일) |
| A4 | 온도 | 낮 24 ℃ / 밤 12 ℃ — 체온이 쾌적대를 벗어나지 않는다 |
| A5 | 기존 지역 무변 | Day 1~9(숲·사막)에서 **물이 생기거나 몬스터가 뜨지 않는다** (`HasWater` 꺼짐) |

## B. 지형·화면 (0·1차)

| # | 항목 | 기대 |
|---|---|---|
| B1 | 궤도가 물 위를 지난다 | 갑판 바로 옆이 물이다. 상판 폭은 **8 m** |
| B2 | **물 이음매** ⚠ | 타일 경계에서 **잔물결 무늬가 끊기지 않는다** (§5.2의 핵심) |
| B3 | **물이 흐른다** ⚠ | 물결이 **뒤로 흘러간다.** 정지해 보이면 `WaterScrollShaderBinder` 배선 실패 |
| B4 | 수평선 | 물 평면이 끝나는 경계가 **하늘과 이어져** 보인다 |
| B5 | 세그먼트 변주 | 교각(트러스·아치·무너진 것)·여울·난파선·등대·부표 군집·침몰 유적이 **반복 없이** 지나간다 |
| B6 | 교각 리듬 | 40 m마다 교각이 지난다 |
| B7 | 해저 | 물 아래로 **어두운 바닥**이 비친다 (수심 8 m) |

## C. 자원 채집 (1차 — §1.1 필수 조건)

| # | 항목 | 기대 |
|---|---|---|
| C1 | **부표가 뜬다** ⚠ | 자원 대역(4~16 m)에 주황 부표가 보인다 |
| C2 | **집게로 닿는다** ⚠ | 갑판에서 부표를 **1단계 집게(20 m)로 낚아챌 수 있다** |
| C3 | 자원 종류 | 표류 목재·고철·식재료·소금이 나온다 |
| C4 | 희소성 | 숲보다 확실히 드물다 (간격 배율 1.6) |

## D. 수영 (2차)

| # | 항목 | 기대 |
|---|---|---|
| D1 | 진입 | 상판 가장자리에서 걸어 나가면 **떨어져 물에 들어간다** |
| D2 | **수중 표시** ⚠ | 머리가 잠기면 화면에 **청록 물빛**이 씌워진다 |
| D3 | 부력 | 입력을 놓으면 **수면까지 떠오르고 멈춘다** (물 위로 튀어나가지 않는다) |
| D4 | 하강 | **좌 Ctrl**로 내려간다 |
| D5 | 상승 | **Space**로 올라오되 수면에서 멈춘다 |
| D6 | **수면은 밀린다** ⚠ | 수면에서 열차 쪽으로 헤엄쳐도 **점점 뒤처진다** (설계대로) |
| D7 | 경계 안정 | 수면을 오르내릴 때 수영/걷기가 **깜빡이지 않는다** (히스테리시스) |
| D8 | 사망선 | 뒤처지면 경고(30 m) 후 사망(40 m)이 **물속에서도** 작동한다 |

## E. 잠수 (2차 — 이 차수의 명제)

| # | 항목 | 기대 |
|---|---|---|
| E1 | **잠수하면 물살이 약해진다** ⚠⚠ | 깊이 내려갈수록 뒤로 밀리는 속도가 **눈에 띄게 준다** |
| E2 | **잠수하면 전진한다** ⚠⚠ | 충분히 잠수한 상태로 앞으로 헤엄치면 **열차에 다가간다** (순 +1.1 m/s) |
| E3 | 체감 차이 | 수면 수영과 잠수의 차이가 **말하지 않아도 느껴진다** |
| E4 | 침몰 유적 | J 세그먼트에서 물속 **석주 구조물**이 보인다 |
| E5 | 잠수 채집 | 유적 앵커(y −7.5)의 자원을 **잠수해서** 얻는다 |
| E6 | 수면 표지 | 유적 위 수면에 주황 표지가 있어 **"여기 뭔가 있다"**가 읽힌다 |

## F. 복귀 사다리 (2차 — 최대 결함의 처방)

| # | 항목 | 기대 |
|---|---|---|
| F1 | **물에서 올라온다** ⚠⚠ | 사다리를 잡고 물에서 **상판까지 오른다** |
| F2 | 발견성 | 물에서 사다리가 **보인다** (가로대·측면 레일) |
| F3 | 거리 | 타일당 4개라 **최대 20 m 헤엄**이면 닿는다 |
| F4 | 꼭대기 | 사다리 끝에서 **상판 위로 올라선다** (기어오르기) |
| F5 | 우선순위 | 물에서 사다리를 잡으면 **수영보다 사다리가 이긴다** |

## G. 밤 (0차 발견 검증)

| # | 항목 | 기대 |
|---|---|---|
| G1 | **밤이 낮보다 잘 읽힌다** ⚠ | 물이 하늘빛을 받아 밝게 남고, 궤도·교각이 **실루엣**이 된다 (0차 §4.2) |
| G2 | 물이 검게 죽지 않는다 | `_NightFloor`(0.72)가 하한을 잡는다 |
| G3 | 등대 | 밤에 등대 불빛이 보인다 |
| G4 | 부표 | 밤에도 부표가 식별된다 (emissive) |

## H. 몬스터 (1차 — §8.1)

| # | 항목 | 기대 |
|---|---|---|
| H1 | **물 위에 뜨지 않는다** ⚠ | 몬스터가 **물면 높이**에서 온다 (지면 y 0이 아니라) |
| H2 | 접근 | 상판 끝으로 기어올라 열차에 붙는다 |
| H3 | 보스 | 숫자패드 `/`로 바다 보스(**큰물범**)가 선다 |
| H4 | 표현 한계 | 수면 이동 애니메이션·물보라는 **아직 없다** — 걸어서 온다 (알려진 잔여) |

## I. 미결정 ⑩ — 열차 옆 1.15 m ⚠⚠⚠

**이 문서에서 가장 중요한 구역이다.** 렌더로는 판정할 수 없다.

| # | 항목 | 판단할 것 |
|---|---|---|
| I1 | 걸어서 통과 | 열차 옆 통로를 **끝에서 끝까지 걸어본다** |
| I2 | 좁아서 긴장인가 불쾌인가 | *"아슬아슬해서 재밌다"* vs *"자꾸 빠져서 짜증난다"* |
| I3 | 실수 낙하 빈도 | 몇 번 걸어서 몇 번 빠지는가 |
| I4 | 전투 성립 | 이 폭에서 몬스터와 싸울 만한가 |
| I5 | 집게 조작 | 이 폭에서 부표를 겨눌 만한가 |
| I6 | **판정** | 폭 유지 / 넓힘(±5~6) / 난간 부활 중 하나 |

## J. 멀티 (두 벌 접속)

| # | 항목 | 기대 |
|---|---|---|
| J1 | 같은 지형 | 두 피어가 **같은 세그먼트**를 본다 (결정론 추첨) |
| J2 | 원격 수영 | 남이 헤엄치는 것이 **떨지 않는다** (미결정 ①과 한 몸) |
| J3 | 원격 표현 한계 | 수영 애니메이션이 없어 **걷는 자세로 보인다** (알려진 잔여 ⑭) |
| J4 | 물 동기 | 두 화면의 물결이 어긋나지 않는다 |
