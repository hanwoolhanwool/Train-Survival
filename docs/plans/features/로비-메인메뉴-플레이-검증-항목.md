작성일: 2026-08-20 · 대상: `Main.unity` (main = `2d0d17c`) · 상태: **검증 대기**
(구현: [로비·메인 메뉴 구현 계획](로비-메인메뉴-구현-계획.md) §7의 **1~6차 전부**.
EditMode **700/700 통과** 상태에서 시작 — 1차 이전 659 + 신규 41.
**사운드는 이번 범위가 아니다** — §11 미결 8)

> **무엇을 보는가**: 이 화면의 목표는 `Lobby 시안.png`를 **동작하는 화면으로 만드는 것**이었다.
> 그러므로 검증은 두 축이다 — **그림이 시안으로 읽히는가**(A·B·I)와 **손에 걸리는 데가 없는가**(C~G).
> 마지막 H는 이 화면 고유의 질문이다: **30초 두었을 때 그림 한 장으로 보이지 않는가.**

> **검증 구성**: 대부분 **단독 실행**으로 충분하다. G 구역(세션)만 **호스트 1 + 클라이언트 1**
> (MPPM 가상 플레이어)이 필요하다.

## 0. 검증자가 먼저 읽을 것 — "결함 아님" 다섯 가지

아래는 전부 **의도된 상태**다. 결함으로 올리지 않는다.

1. **시안과 완전히 같지 않다 — 같을 수 없다** (§13 ㉘).
   실측 결과 **시안에 그려진 기차는 자기 선로 위에 있지 않다.** 후미 바닥이 레일의 소실점
   (화면 0.678)보다 위로 올라가는데, 지면 물체가 수평선보다 높은 셈이라 물리적으로 불가능하다.
   **시안 완전 재현과 선로 정합은 동시에 성립하지 않아 선로 쪽을 택했다.**
   → 그 결과 **기관차가 시안보다 약간 더 측면으로 보인다.** 이것이 이번 차수의 의도적 차이다.

2. **버전이 `v0.1.0`이다** (§13 ㊱). 시안의 `v0.2.1`은 목업 값이고, 라벨은
   `Application.version`을 읽는다. 숫자를 올리려면 Player Settings를 바꾼다.

3. **소리가 하나도 없다** (§11 미결 8). 프로젝트에 오디오 인프라가 아직 없다 —
   [오디오 가이드](../../design/Train-Survival-오디오-가이드.md) §21.3의 1차가 선행이다.

4. **오로라가 흐르지 않는다** (§11 미결 4). 배경 레이어 분리 재생성이 필요해 범위 밖이다.
   오로라는 배경 그림에 그려진 정지 이미지다.

5. **하위 패널(여정 시작·업적·설정·공고)이 밋밋하다** (§13 ㉖). 회색 판에 버튼만 있다.
   정식 스타일링은 [UI 구현 계획](UI-구현-계획.md)의 몫이라 자리와 흐름만 잡았다.

## A. 첫인상 — 시안 대조 (§8.2-1)

`Lobby 시안.png`를 옆에 띄우고 본다. **§0-1의 차이는 제외하고** 판정한다.

- [ ] **A1** 배너(표지판)의 **크기와 자리**가 시안과 같다 — 좌측 가장자리에 붙고 위아래가 잘린다
- [ ] **A2** 타이틀 각인 `TRAIN SURVIVAL`이 시안과 **같은 높이·같은 크기**다
- [ ] **A3** 명판 4장의 **세로 간격이 균등하지 않다** (아래로 갈수록 좁다) — 원근이 살아 있다
- [ ] **A4** 배너에 **회색 테두리나 잘린 자국이 없다** — 잎사귀 가장자리·격자 기둥 사이 틈 확대 확인
- [ ] **A5** 공고문 종이가 우측에 있고 **글자가 구워진 흔적(흐릿한 얼룩)이 없다**
- [ ] **A6** 전체 톤이 시안처럼 어둡다 — 회색으로 씻겨 보이지 않는다

## B. 기차 · 선로 정합 (§8.2-2·3)

- [ ] **B1** **기차가 선로와 나란하다** — 기관차부터 후미까지 바퀴가 레일을 따라간다.
      *(4차 이후 재정합의 핵심 항목. 축이 레일을 가로지르면 즉시 보고)*
- [ ] **B2** 카우캐처·바퀴가 **배경 레일에 얹혀** 보인다 — 뜨거나 파묻히지 않는다
- [ ] **B3** 후미 객차가 **배너 뒤로 자연스럽게 사라진다** — 배너 경계에서 잘린 티가 나지 않는다
- [ ] **B4** 배경 램프(좌측 플랫폼)와 **3D 기차의 하이라이트 방향이 같은 쪽**이다
- [ ] **B5** 기차가 배경보다 **밝거나 채도가 튀지 않는다** — 붙여 놓은 것처럼 보이면 결함

## C. 명판 상호작용 (§8.2-4)

- [ ] **C1** 명판에 마우스를 올리면 **황금 명판이 떠오르고** 화살표가 그 줄로 옮겨 온다
- [ ] **C2** **한 번에 한 장만** 빛난다 — 마우스와 키보드가 각각 다른 줄을 켜지 않는다
- [ ] **C3** **색 없이도** 어느 줄이 선택됐는지 안다 — 화살표 위치와 크기 변화로 읽힌다
      *(흑백 스크린샷으로 확인하면 확실하다)*
- [ ] **C4** **Main 단독 실행**에서 "게임 시작"이 **잠겨 있고**, 포커스가 "업적"에 있다
- [ ] **C5** 잠긴 "게임 시작"을 눌러도 아무 일이 없고, **위아래 이동이 그 줄을 건너뛴다**
- [ ] **C6** 각 명판이 제 패널을 연다 — 업적/설정은 스텁, 종료는 **에디터 플레이가 멈춘다**

## D. 문구 (§8.2-5)

> 원래 기준은 "`Ver1.png`와 어긋나지 않는다"였으나, 3차 실측에서 **`Ver1`/`Ver2`가 픽셀 정렬이
> 아님**이 밝혀졌다(§13 ⑯). 그래서 기준을 **시안 대조**로 바꾼다.

- [ ] **D1** `게임 시작`·`업적`·`설정`·`종료`가 명판 **가운데**에 있고 판을 넘지 않는다
- [ ] **D2** 글자 크기·굵기가 시안과 비슷하다 — 가늘거나 뭉개져 보이지 않는다
- [ ] **D3** **황금 명판 위에서도 글자가 읽힌다** — 검은 외곽선이 대비를 만든다
- [ ] **D4** 공고문의 `운행 공고`와 요약 3줄이 **장식(구분선·마무리)과 겹치지 않는다**
- [ ] **D5** 좌하단 버전이 `v0.1.0`, 우하단이 `✛ 선택` · `E 확인`이다

## E. 키보드 · 게임패드 (§8.2-6)

**마우스에서 손을 뗀 채로** 진행한다.

- [ ] **E1** ↑↓로 명판 4장을 오갈 수 있다
- [ ] **E2** 맨 아래에서 ↓를 누르면 **맨 위로 돌아온다** (순환)
- [ ] **E3** Enter/Space로 선택한 항목이 열린다
- [ ] **E4** 패널이 열리면 **포커스가 패널 안으로** 들어온다 — 뒤쪽 명판이 입력을 훔치지 않는다
- [ ] **E5** **Esc**로 패널이 닫히고 **포커스가 원래 명판으로** 돌아온다
- [ ] **E6** **게임패드**로 E1~E5가 모두 된다 (D-패드/스틱 = 이동, A = 확인, B = 취소)
      *(배선은 표준 입력 모듈 경유라 되어야 하지만 실기 확인은 이번이 처음이다)*

## F. 종횡비 (§8.2-7)

Game 뷰 해상도를 바꿔 가며 본다. **1080p / 1440p / 16:10(1920×1200) / 21:9(2560×1080)**.

- [ ] **F1** 배경에 **여백(검은 띠)이 전혀 없다** — 네 해상도 모두
- [ ] **F2** 배경이 **찌그러지지 않는다** — 종횡비가 유지된 채 잘린다
- [ ] **F3** 배너가 **늘어나지 않는다** — 잘리는 것은 왼쪽과 위아래뿐
- [ ] **F4** 명판 4장이 **화면 안에 전부** 있다 (왼쪽으로 잘려 나가지 않는다)
- [ ] **F5** 공고문이 **오른쪽으로 잘리지 않고**, 배너와 겹치지 않는다
- [ ] **F6** 버전·컨트롤 가이드가 화면 모서리에 붙어 있다

## G. 세션 흐름 (§8.2-8·9) — **Boot부터 실행**

- [ ] **G1** Boot를 거치면 "게임 시작"이 **열린다**(잠금 해제)
- [ ] **G2** 게임 시작 → **새 여정**이 호스트 세션을 열고 인게임 씬(`Game_ArtTest`)을 로드한다
- [ ] **G3** 개발용 **씬 토글**이 `Game ↔ Game_ArtTest`를 바꾸고, 바꾼 쪽으로 들어간다
- [ ] **G4** **직결 모드** — 주소 칸이 `127.0.0.1`로 채워져 있고, 호스트를 띄운 뒤
      다른 인스턴스에서 **친구 참가(주소 접속)**로 들어가진다
- [ ] **G5** **Steam 모드** — 호스트 시작이 친구 전용 로비 생성을 겸하고,
      **친구 초대가 Steam 오버레이를 실제로 연다** *(이전에는 안내 문구뿐이었다)*
- [ ] **G6** 세션이 시작된 뒤 패널 버튼이 **잠긴다** — 두 번 눌러 두 세션이 열리지 않는다
- [ ] **G7** 콘솔에 에러가 없다

## H. 연출 — 30초 (§8.2-10)

**아무것도 만지지 않고 30초 본다.** 게임 뷰에 포커스가 있어야 한다(§0.1).

- [ ] **H1** 30초 뒤에도 화면이 **그림 한 장으로 읽히지 않는다** — 이 구역의 총평이다
- [ ] **H2** **카메라가 아주 조금 움직이고**, 그때 **기차만 배경에 대해 미끄러진다**
      (배너·배경은 함께 움직이지 않는다 — 그것이 시차다)
- [ ] **H3** 드리프트가 **떨림이 아니라 흐름**으로 보인다 — 프레임마다 튀지 않는다
- [ ] **H4** 굴뚝에서 **옅은 증기**가 오르고, **하늘을 덮지 않는다**(오로라가 가려지면 결함)
- [ ] **H5** 하부 실린더에서 **주기적으로** 배기가 터진다 (약 1.3초 간격)
- [ ] **H6** 객차 창문 불빛이 **느리게 흔들리고 꺼지지 않는다**
- [ ] **H7** 헤드램프가 **화면에서 가장 밝은 점**이고 Bloom이 번진다
- [ ] **H8** 진입 시 **검은 화면에서 1.2초에 걸쳐 밝아진다** (Boot → Main 전환에서 확인)
