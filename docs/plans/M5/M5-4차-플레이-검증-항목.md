> **4차 목표** (개발 가이드 §5 M5 차수 분할): 허기 스탯(체온과 같은 3층 구조) + 화덕 + 요리 버프 —

3. **사망 창 테스트 재현성** — 부활 대기 5초는 사망 상태를 조작하기에 짧다. `PlayerHealthSettings`의
   `_respawnDelaySeconds`를 일시적으로 20초로 올려 D5·D10·E2를 확인한다 (위 "재검증 절차"에 반영)
4. **창고 동시 경합(G2) 자동화** — 사람이 같은 프레임에 두 피어를 조작할 수 없으므로,
