# M7 4차 플레이 검증 항목 — 거치 무기 (거치 기관총 + 자동 터렛)

작성일: 2026-08-25 · 대상: `feat/m7-mounted-weapons` · 상태: **검증 대기**
(구현: [M7-4차-구현-계획.md](M7-4차-구현-계획.md) — 결정 ①~⑧ 반영, A1~A9 + B1~B4 전부 구현.
EditMode **997/997 통과** 상태에서 시작)

> **4차 목표**: **열차가 화력을 갖는다.** 지금까지의 무기는 전부 플레이어 소유였고, 거치 무기는
> 열차에 설치되고 사람이 붙어서 쓰는 첫 무기다 — 소유가 아니라 **점유**다.
>
> **검증 구성**: 원칙대로 **호스트 1 + 클라이언트 1**(MPPM 가상 플레이어). 단 **H 구역은 4인**이
> 필요하다 — MPPM 가상 플레이어 3벌 + 호스트로 대체 가능한지 먼저 판단한다(계획 §5 마지막 항목).

## 0. 사전 준비

- [ ] **이번 차수는 씬·프리팹 변경이 있다**
  - `Game_ArtTest` 의 `Train` 루트에 `MountedWeaponHost` 1개 (`_catalog` = `StructureCatalog`)
  - `Prefabs/Player` 에 `MountedWeaponOperator` 1개 (`_controller`·`_aimSource` 배선됨)
  - 신규 프리팹 2종 `Structure_MountedGun`·`Structure_Turret` — 카탈로그 `_viewPrefab` 에 배선됨
  - 전부 YAML 직접 편집 — **씬 재정렬 diff 없음**(삽입 2줄 + 15줄)
- [ ] **네트워크 프리팹은 늘지 않았다.** 건축물 뷰는 `NetworkObject` 가 아니라 `PoolManager` 로컬
      스폰이다 — M7 2·3차가 매번 "최우선 관문"으로 세웠던 **`GlobalObjectIdHash` 검증이 이 차수에는
      빠진다**. 플레이어 프리팹 해시도 무변이다(**1135503018**, 컴포넌트만 추가).
- [ ] Boot 씬에서 Play → 호스트 시작. 클라이언트 = MPPM 가상 플레이어 접속
- [ ] 콘솔을 열어둔다 — 판정 근거 로그는 전부 **호스트 콘솔**이다:
  - `[MountedWeaponHost] 거치 무기 점유 기각(TooFar): client=1 structure=#3`
  - `[MountedWeaponHost] 거치 무기 발사 기각(사각 밖): …`
  - `[MountedWeaponHost] 거치 무기 명중 보고 기각(사거리 초과): …`

**재현 수단**

| 시나리오 | 조작 |
|---|---|
| 거치 기관총 즉시 설치 | 망치를 들고 갑판을 겨눠 프리뷰가 뜬 상태에서 **`F4`** (무료 + 소총탄 60) |
| 자동 터렛 즉시 설치 | 같은 상태에서 **`Shift`+`F4`** |
| 정규 설치 경로 | 망치 + `R` 순환으로 종류 고르고 우클릭 (기관총 6 / 터렛 8 건자재) |
| 밤 웨이브 | 숫자패드 `2` |
| 몬스터 1기만 | 숫자패드 `*` (요청자 전방 10 m) |
| 웨이브 끄기 | 숫자패드 `−` |
| 건축물 손상·파괴 | 망치로 겨눈 뒤 숫자패드 `9` (샘플 데미지 30 — 기관총은 2회, 터렛은 2회에 파괴) |
| 칸 파괴 | 숫자패드 `9` 를 칸에 반복 |
| 소총탄 보충 | `F4` (설치 실패해도 탄은 준다) |

**기준 수치·경로** (전부 에셋 — 코드 하드코딩 없음)

| 항목 | 위치 | 값 |
|---|---|---|
| 거치 기관총 | `Data/StructureCatalog.asset` `_kind: 7` | 체력 **60** · 비용 **6** · 발자국 **2×2** · 반환 **고철** |
| 자동 터렛 | 같은 파일 `_kind: 8` | 체력 **45** · 비용 **8** · 발자국 **2×2** · 반환 **고철** |
| 기관총 사격 | `Data/MountedGunSettings.asset` | 피해 22 · 사거리 90 · 탄창 **40** · 연사 **0.11 s** · 산탄 1.6° · 재장전 4 s · 탄종 **소총탄** |
| 터렛 사격 | `Data/TurretGunSettings.asset` | 피해 26 · 사거리 70 · 탄창 **25** · 연사 **0.85 s** · 산탄 0.8° · 탄종 **소총탄** |
| 사각·좌석 | `Data/MountedWeapon_MountedGun.asset` | yaw **±110°** · pitch **−15°~+40°** · 좌석 반경 **2.5 m** · 시선 0.6 |
| 터렛 자동화 | `Data/MountedWeapon_Turret.asset` | `_manned` **꺼짐** · 탐색 반경 **35 m** · 동시 활성 상한 **4** |
| 조준 중계 | `MountedWeaponHost` | **10 Hz** Unreliable (표현 전용) |
| 터렛 대상 주사 | `MountedWeaponHost` | **5 Hz** (0.2 s) — 발사 주기와 별개 |

> **설치 직후 탄창은 비어 있다.** 낮에 채워 두고 밤에 소모하는 루프가 여기서 시작한다 —
> 붙자마자 쏘려 하면 안 나가는 것이 **정상**이고, `R`(기관총) 또는 `E`(터렛)로 채워야 한다.

## A 구역 — 설치·철거 (그리드 경로가 코드 0줄로 성립하는가)

- [ ] A1. 망치 `R` 순환에 **거치 기관총·자동 터렛이 뜬다** (돔은 여전히 빠진다)
- [ ] A2. 프리뷰 박스가 **2×2 크기**로 뜨고, 회전(`Q`/`E`)에 따라 점유 영역이 함께 돈다
- [ ] A3. 건자재가 모자라면 설치가 기각된다 (기관총 6 · 터렛 8)
- [ ] A4. 설치 즉시 **호스트·클라 양쪽에 실물이 뜬다** (받침 + 요크 + 포신)
- [ ] A5. 겹치는 자리·칸 밖·기관차에는 설치되지 않는다
- [ ] **A6. 2×2 발자국이 갑판 통행을 막지 않는다** — 판자 미증축 칸에서 옆으로 지나갈 수 있는가.
      막히면 발자국을 2×1로 줄인다 (계획 리스크 5 — **이 항목이 이번 차수의 데이터 조정 1순위**)
- [ ] A7. `X` 홀드 철거 시 **고철**이 반환된다 (목재가 아니다)
- [ ] A8. 망치로 수리하면 체력이 오른다 (기존 건축물과 같은 경로)

## B 구역 — 점유 (1인 확정 · 경합 · 강제 하차)

- [ ] B1. 거치 기관총 근처 + 시선에서 **"E — 거치 기관총"** 안내가 뜬다
- [ ] B2. 반경(2.5 m) 밖이면 안내가 사라지고 `E` 를 눌러도 붙지 않는다 (호스트 콘솔에 `TooFar`)
- [ ] B3. `E` 로 붙으면 **전 피어에서** 그 사람이 좌석에 앉은 것으로 보인다
- [ ] B4. **다른 사람이 이미 붙어 있으면 안내 자체가 뜨지 않는다** (후보에서 빠진다)
- [ ] B5. 두 사람이 **같은 프레임에** `E` 를 눌러도 한 사람만 붙는다 (서버 도착 순서)
- [ ] B6. 붙은 채 **다른 거치 무기**에 다가가 붙으면, 앞의 것이 자동으로 풀린다 (한 사람 하나)
- [ ] **B7. 강제 하차 4사유** — 각각 즉시 풀리고 허공에 고정된 유령이 남지 않는다
  - [ ] 건축물 파괴 (숫자패드 `9` 반복)
  - [ ] 칸 파괴 (그 칸의 건축물이 통째로 사라진다)
  - [ ] 점유자 사망 (숫자패드 `5` 반복 또는 몬스터)
  - [ ] 점유자 접속 종료 (클라이언트 창 닫기 → 호스트 화면에서 좌석이 빈다)
- [ ] B8. 점유 중인 무기는 **철거되지 않는다** (`X` 홀드가 아무 일도 하지 않는다).
      점유자가 내리면 곧바로 철거된다
- [ ] B9. 강제 하차 후 그 자리에 **다른 사람이 곧바로 붙을 수 있다**

## C 구역 — 조작 (이동 잠금 · 사각 · Esc 우선순위)

- [ ] C1. 점유 중 `WASD`·`Space` 가 먹지 않는다 (몸이 좌석에 머문다)
- [ ] C2. 점유 중 핫바 `1~5` 전환이 막히고, 무기 입력(집게·망치·총)이 전부 닫힌다
- [ ] C3. 시야가 **좌우 ±110°** 에서 멈춘다 — 열차 안쪽으로는 돌아가지 않는다
- [ ] C4. 시야가 **아래 15° / 위 40°** 에서 멈춘다
- [ ] C5. `E` 로 내리면 좌석 **옆 갑판**에 서고, 이동·핫바가 즉시 돌아온다
- [ ] C6. **`Esc` 는 세션 메뉴보다 점유 해제를 먼저 소비한다** — 한 번 누르면 내려오고,
      다시 누르면 그때 세션 메뉴가 열린다
- [ ] C7. 점유 중 화면에 **"좌클릭 — 사격 · R — 재장전 · E/Esc — 내리기"** 안내가 떠 있다
- [ ] C8. 이탈 칸 위의 거치 무기에 붙어 있으면 **칸과 함께 뒤로 끌려간다** (좌석이 따라간다)

## D 구역 — 사격 (전 피어 궤적 일치 · 호스트 판정 · 아군 오사 없음)

- [ ] D1. 좌클릭을 **누르고 있으면 연사**된다 (0.11 s 간격)
- [ ] D2. **원격 피어 화면에서도 같은 궤적**의 트레이서가 보인다 (시드 중계)
- [ ] D3. **원격 피어 화면에서 포신이 함께 돈다** — 조준 중계 10 Hz 가 보간으로 흡수되는가
- [ ] D4. 몬스터가 실제로 죽는다 (호스트·클라 어느 쪽이 쏘든)
- [ ] D5. **자기 열차를 쏘지 않는다** — 칸·건축물·판자에 탄착이 나지 않는다
- [ ] D6. **다른 플레이어를 맞혀도 피해가 없다** (사람 조작 무기는 사각으로만 막는다 —
      의도적으로 아군을 겨눠 확인한다)
- [ ] D7. 사거리(90 m) 밖의 대상은 맞지 않는다
- [ ] D8. 클라이언트가 쏜 것도 **호스트 체력에 반영**된다 (호스트 화면에서 몬스터가 준다)

## E 구역 — 탄약 (재장전 · 점유 교대 잔탄 · 소총탄 경쟁)

- [ ] E1. 설치 직후 HUD 탄약 줄이 **`0 / 40`** 으로 뜬다
- [ ] E2. `R` 로 재장전하면 **개인 인벤의 소총탄이 그만큼 준다**
- [ ] E3. 예비 소총탄이 모자라면 **부분 장전**으로 끝난다 (`12 / 40` 같은 상태)
- [ ] E4. 예비가 0이면 재장전이 아무 일도 하지 않는다
- [ ] E5. **점유 교대 시 잔탄이 유지된다** — A가 20발 남기고 내리면 B가 붙었을 때 `20 / 40`
- [ ] E6. 무기가 파괴되면 **남은 탄은 소실된다** (보따리로 나오지 않는다)
- [ ] E7. 내린 뒤 HUD 탄약 줄이 **사라진다** (남의 무기 잔탄처럼 남지 않는다)
- [ ] E8. 볼트액션과 **소총탄을 공유**한다 — 거치 무기를 돌리면 저격 탄이 준다는 압박이 성립하는가.
      **밤 하나를 못 버티는 수준이면 실패다** — 탄창 용량·피해로 조정한다 (계획 리스크 6)

## F 구역 — 자동 터렛 (자동 조준 · 대상 필터 · 수동 장전 · 동시 상한)

- [ ] F1. 터렛에는 **붙을 수 없다** (`E` 안내가 "자동 터렛 **장전**"으로 뜬다)
- [ ] F2. `E` 로 장전하면 개인 인벤의 소총탄이 줄고, 안내에 **`(25/25)`** 가 붙는다
- [ ] F3. 탄이 있는 터렛이 **사람 없이 몬스터를 쏜다** (숫자패드 `*` 로 1기 스폰)
- [ ] F4. **포신이 대상을 따라 돈다** — 전 피어에서 같이 돈다
- [ ] F5. **탄이 떨어지면 멈춘다**. 사람이 채우면 다시 돈다
- [ ] F6. **플레이어를 쏘지 않는다** — 터렛 앞을 걸어다녀도 발사되지 않는다 (대상 필터)
- [ ] F7. **열차·자원 노드를 쏘지 않는다**
- [ ] F8. **사각 밖(뒤쪽)의 몬스터는 쏘지 않는다** — 터렛 뒤로 몬스터를 유인해 확인한다
- [ ] F9. 시야가 막히면(칸 뒤) 쏘지 않는다
- [ ] F10. 보스도 대상이 된다 (숫자패드 `/`)
- [ ] **F11. 동시 상한** — 터렛 6기를 세우고 전부 채운 뒤 밤 웨이브를 돌린다.
      **4기만 사격**하는가, 프레임·RPC 가 견디는가 (계획 B4 — **실측 항목**)

## G 구역 — 회귀 (기존 축이 상하지 않았는가)

- [ ] G1. 기존 건축물 **6종**이 그대로 설치·철거·파괴된다 (난방기·창고·제작대·화덕·정수기·강화 난방로)
- [ ] G2. 창고 파괴 시 보따리 배출이 그대로다
- [ ] G3. **클라이언트 접속이 정상**이다 (네트워크 프리팹 목록 무변 확인)
- [ ] G4. 이탈 칸 위 건축물이 칸을 따라가고, 재결합 시 그대로 복원된다
- [ ] G5. 개인 화기 3종(리볼버·샷건·볼트액션)의 **발사 연출·탄착이 그대로**다
      (연출 구현을 거치 무기와 공유하도록 뽑아냈다 — 이 항목이 그 회귀 관문이다)
- [ ] G6. 개인 화기 재장전·HUD 탄약 줄이 그대로다
- [ ] G7. 제작 창(`E`)·창고(`E`)·화구 투입(`E`)이 거치 무기 근처에서도 정상이다
- [ ] G8. 사다리 오르기·집게 그랩이 그대로다 (같은 이동 게이트를 건드렸다)

## H 구역 — 4인 세션 역할 분담 (M5 완료 기준 이월 — 착수 준비 결정 ⑨)

- [ ] H1. **4인 접속이 성립한다** (호스트 + MPPM 3벌로 대체 가능한지 먼저 판단)
- [ ] H2. 밤 웨이브 한 번을 **역할을 나눠** 넘긴다 — 포수 2 · 수리 1 · 보급(탄약 제작·장전) 1
- [ ] H3. 포수 2명이 **각자 다른 거치 무기**를 점유하고 동시에 쏜다
- [ ] H4. 보급 담당이 **터렛을 돌아다니며 채우는** 것이 실제로 일이 되는가 (할 일이 있는가)
- [ ] H5. 4인 동시 사격 중 **프레임·지연이 견디는가**
- [ ] H6. 역할이 갈리는 것이 **재미있는가** — 이 항목만 주관 판정이다

| 1 | **몬스터 전용 물리 레이어가 없다** (프로젝트 전체가 Default). 계획 §2.6 의 "레이어 + 계약" 중 **계약만** 쓴다 — `IHostileTarget`(몬스터·보스). 레이어보다 강한 보증이지만, 계획서 문구와는 다르다 |
| 2 | **형상은 임시다** — 프리미티브 조합. 좌석 높이·포신 길이가 어색한 것은 M8 아트 패스의 몫이고, 이 차수에서 볼 것은 **회전 축이 맞게 도는가**뿐이다 |
| 3 | **터렛 장탄은 복제하지 않는다**(결정 ⑦). 그래서 안내의 수량은 **자기가 채워 본 터렛에만** 뜬다 — 남이 채운 터렛은 수량 없이 "자동 터렛 장전"으로만 보인다 |
| 4 | **좌석은 요크와 함께 돌지 않는다.** 몸이 제자리에서 도는 형태다 — 3인칭으로 보면 다리가 고정된 채 상체만 도는 그림이 될 수 있다 |
| 5 | **PlayMode 테스트가 없다.** 계획 §4 의 "점유 → 사격 → 강제 하차 수명 주기 1건"은 미작성 — 이 문서의 B7 이 그 자리를 대신한다 |
| 6 | **`RpcTarget.Single`·`SendTo.SpecifiedInParams`·Unreliable RPC 는 컴파일만 통과한 상태**다. 장탄 확정(E1·E2)과 조준 중계(D3)가 이 셋의 첫 실기 확인이다 |
