> 이 문서는 **관측된 현상만** 담는다. 원인 분석·수정안·선택지는 넣지 않는다.
> 2026-08-15 세션에서 시도한 수정은 전부 롤백됐으므로, 아래는 **롤백 후 코드 기준**으로

## 재현 환경

- 구성: **호스트 1 + 클라이언트 1** (MPPM 가상 플레이어)
- 브랜치: `feat/m7-endgame`
- 이탈 경로: 게임 화면 → `Esc` → **"세션 나가기 — 메인 화면으로"**
- 재접속 경로: 메인 화면 → 같은 호스트에 다시 접속 (같은 MPPM 인스턴스 = 같은 식별 토큰)

---

## P1. 클라이언트가 나가도 호스트 화면에서 사라지지 않는다

클라이언트에서 "세션 나가기 → 메인 화면으로"를 눌러도 **호스트 화면에 그 플레이어가 그대로 남는다.**

- 클라이언트는 정상적으로 메인 화면으로 돌아간다
- 호스트 쪽에서만 남는다
- **과거에는 사라졌다** — 사용자 진술: *"예전에는 클라이언트에서 메인으로 나가기 버튼을 누를 경우
  호스트 화면에서 해당 플레이어가 사라졌다. 하지만 지금은 사라지지 않는다."*

## P2. 클라이언트 재접속 시 아이템이 모두 초기화된다

P1 상태에서 같은 클라이언트가 다시 접속하면 **인벤토리·장비가 전부 초기 지급 상태로 돌아간다.**

- 나가기 전에 갖고 있던 자원·제작품·착용 장비가 남지 않는다

## P3. 재접속 시 중복 식별 토큰 로그가 발생한다

## P4. 게임오버 화면에서 나가도 호스트에 남는다

게임오버(전멸) 오버레이의 **"메인 화면으로"** 버튼으로 나가는 경우에도 P1과 같은 현상이 관측된다.

## P5. 호스트가 나가면 남은 클라이언트에 세션 종료 오버레이가 뜨지 않는다

호스트가 "세션 나가기 — 메인 화면으로"를 눌렀을 때, 남은 클라이언트 화면에
**"세션이 종료되었습니다" 오버레이와 복귀 버튼이 표시되지 않는다.**

> **관측 조건 주의** — 이 현상은 **2026-08-15 세션의 수정(이탈 통지 RPC)이 적용된 상태**에서만
> 관측됐다. 그 수정은 롤백됐으므로 **현재 코드에서의 재현 여부는 확인되지 않았다.**
> P1~P4와 달리 이 항목은 **재확인이 먼저 필요하다.**
