## A. 보따리 — 건축물 파괴 (코어 A ①·② 갑판 지점)

창고 건축물만 파괴되고 칸이 살아 있는 경우 — 그 칸 갑판 위 **휴지 상태**로 스폰된다.

- [0] **A1** 창고를 짓고 아이템을 넣은 뒤 **망치 조준 + 숫자패드 6 반복**으로 창고 건축물을
      파괴하면 → 그 칸 갑판 중앙에 **보따리가 나타난다** (내용물 소실이 아니다)
- [0] **A2** 보따리는 **갑판 휴지** 상태다 — 열차가 달려도 제자리 (자원 노드 갑판 휴지와 같은 규약)
- [0] **A3** 근접 + 시선 + **E키**로 보따리 창이 열린다 — 위 보따리 격자 + 아래 개인 인벤토리
      (창고 창과 같은 레이아웃). E 재입력·Esc·거리 이탈로 닫힌다
- [0] **A4** **파괴 시점의 창고 내용물이 그대로** 들어 있다 — 자원 수량·**무기·장비 포함**
      (버리기 불가 규약의 처분 경로가 보따리로 이어진다)
- [0] **A5** 드래그로 보따리 → 인벤토리 **옮겨 담기**가 된다 — 자원 병합·스왑·무기 이동 전부
      (창고 창 규약 그대로). 인벤토리 → 보따리 방향도 된다
- [0] **A6** **슬롯을 전부 비우면 보따리가 자동으로 사라진다** (빈 보따리는 세상에 남지 않는다)
- [0] **A7** **빈 창고**를 파괴하면 보따리가 나오지 **않는다** (빈 보따리 스폰 방지)
- [0] **A8** 집게로 보따리를 쏘면 **운반 전용** — 끌려오지만 도착해도 수납되지 않고 **발밑에
      떨어진다** (E창으로만 옮겨 담는다 — 무기·장비가 있어 자동 수납 불성립, 착수 전 결정)
- [0] **A9** 집게로 갑판 → 지상, 지상 → 갑판으로 옮길 수 있다 — 해제 지점 기준 갑판 휴지 ↔
      월드 재바인딩 (안착 파이프라인 공용 — 자원 노드와 동일). 하강도 떨림 없이 매끄럽다
- [0] **A10** **게스트 화면에서도** A1~A9가 동일하다 — 특히 보따리 내용물 표시·전송 확정
      (거리·생존은 호스트 재검증 — 멀리서 전송 요청은 기각)
- [0] **A11** 운반(견인) 중에는 E창을 열 수 없고, 열려 있던 창은 닫힌다
- [0] **A12** 보따리를 실은 칸이 **이탈로 소실되면 보따리도 함께 사라진다** (소실 칸 회수 —
      7차 버그 4와 같은 규약). 슬롯 재건 시 보따리가 따라오지 않는다

## B. 보따리 — 칸 파괴 투척 (코어 A ② 지상 지점)

칸 자체가 파괴되면(갑판 소멸) 그 자리에서 지상으로 **느린 포물선 투척**된다.

- [0] **B1** 창고 있는 칸을 **칸 파괴**(망치로 칸 조준 + 숫자패드 6 반복)하면 → 보따리가
      **포물선을 그리며 선로변 지상으로 날아간다** (즉시 소실 아님)
- [0] **B2** **비행 중에는 그랩이 되지 않는다** — 착지 후부터 잡힌다 (착수 전 결정: 불허)
- [0] **B3** 착지한 보따리는 **월드 프레임 소속** — 컨베이어로 뒤로 흘러가고, 집게로 건져
      올리는 짧은 기회가 생긴다. 놓치면 후방 회수로 소실된다 (회수 기회 규약)
- [0] **B4** **게스트 화면에서도 같은 포물선**이 보인다 — 떨림 없음 (좌표는 스폰 시 1회 복제,
      각 피어 로컬 재생 — 7차 하강과 같은 규약)
- [ ] **B5** 비행 중 늦게 접속한(또는 멀리서 온) 피어도 어긋남 없이 이어 본다 (시간축 =
      동기화된 ServerTime — 참고 관찰)
- [0] **B6** 슬롯 재건(재건축) 지점에서는 보따리가 나오지 **않는다** — 파괴 시점에 이미
      나왔으므로 재건은 잔존 정리(소실)만 (이중 생성 방지)

* 집게가 3랩 이상일 경우 비행중 회수 가능하도록 변경
  → **개선 1로 등재** — 3단계 집게는 비행 중 그랩 허용 (착수 전 결정 "불허"의 등급 예외화)
* 보따리는 E로 여는 것이 아닌, 자원과 같이 집게를 통해 보따리 아이템으로 들어오며, 만약, 인벤토리에 자리가 여유 있을 경우 아이템을 모두 풀어서 획득, 자리가 없다면, 보따리에 마우스를 올렸을 때 공간이 부족합니다. 상자로 옮기세요. 표시.
  → **개선 2로 등재 — 회수 UX 재설계** (E창 → 집게 일괄 획득). 세부 확정 후 착수 (개선 방향 참조)
## C. 전투 연출 — 총기 (탄착 + 펠릿별 트레이서 + 시드 중계)

판정·데미지 경로 무변 — 표현 계층만. 원격 중계는 좌표 배열이 아니라 **발사 시드 1개**다.

- [0] **C1** 리볼버 발사 → **트레이서 1줄이 총구에서 탄착점까지** 그려지고 짧게 페이드된다
      (기존 0.05초 점멸 → 0.12초 페이드)
- [0] **C2** **샷건 발사 → 펠릿 수(7)만큼 트레이서가 부챗살로** 퍼진다 — 산탄이 눈에 보인다
- [0] **C3** 표면(갑판·지형·몬스터)에 맞으면 **탄착점에 파티클 버스트**가 튄다 — 법선 방향
- [0] **C4** 빗나간 펠릿은 최대 사거리까지 트레이서만 그려지고 탄착 이펙트가 없다
- [0] **C5** **게스트 화면에서 호스트의 발사가 같은 부챗살 패턴**으로 보인다 (시드 재계산 —
      완전 동일 궤적. 조준 원점만 복제 자세 기준이라 미세 오차 허용)
- [0] **C6** 반대로 게스트가 쏘면 호스트 화면에도 보인다 (양방향 중계)

## 개선 방향

1. ✅ **3단계 집게는 비행 중 회수 허용** (B 구역 사용자 요청 — **구현 완료 2026-08-11**):
   비행 중 `GrabWeight`를 3으로 — 그랩 검증의 등급 ≥ 무게 규칙이 그대로 게이트가 된다
   (착수 전 결정 "불허"의 등급 예외화). 낚아채는 순간 비행 종료. → R5 재확인
2. ✅ **보따리 회수 UX 재설계** (B 구역 사용자 요청 — 세부 확정 2026-08-11 후 **구현 완료**):
   집게 도착 = **일괄 획득** — 내용물(무기·장비 포함)이 전부 들어가면 풀어서 수납, 1칸이라도
   부족하면 **보따리 아이템**(1칸)으로 획득 (확정: "전부 아니면 아이템화"). 내용물은 서버
   보관소(id 1~255, 슬롯 Count에 탑재 — 세션 한정)가 맡고, 좌클릭 풀기로 수납 또는 발밑
   재설치한다. E창 코드는 휴면 유지 (사용 안 함 — 추후 확장 대비, 확정). → R3·R4 재확인
3. ✅ **버리기 당분간 비활성화** (G 구역 방침 — 확정: **기능 자체를 끈다**, 구현 완료):
   드롭 3지점·안내 문구를 `DropEnabled` 게이트로 닫음 — 수량 지정·원자 확정 코드는 유지,
   다시 켤 때 게이트만 연다. → R6 재확인 ✅ **통과 (2026-08-11 2차)**
4. ✅ **보따리 아이템 창고 풀기** (2차 검증 R3 후속 요청 — **구현 완료 2026-08-11**):
   인벤토리가 좁을 때의 처분 흐름 = 아이템 획득(1칸) 후 **칸이 넉넉한 창고로 옮기면
   풀어져 들어간다** — 전송 확정에 특례: 창고 복사본에 전부 들어갈 때만 풀고, 부족하면
   기존 이동(1칸 점유 보관)으로 폴백. 런타임 검증: 스택 분할(5+1)·무기 별도 칸·인벤 칸
   비움·보관 해제 확인. → R7 재확인
