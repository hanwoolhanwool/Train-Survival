  - 에셋: `StructureCatalog`(점유 면적·`_placeable`·반환 자원·프리팹 참조),

- [ ] Boot 씬에서 Play → 호스트 시작. 클라이언트 = MPPM 가상 플레이어 접속

  (망치로 겨눈 부위 우선 — 건축물을 겨누면 그 건축물만 맞는다)

**기준 수치·경로** (전부 에셋 — 코드 하드코딩 없음)

| 항목 | 위치 | 값 |
|---|---|---|
| 그리드 셀 | `Data/TrainLayoutSettings.asset` `_structureCellSize` | **1.0 m** → 본체 4열 × 15행 (폭 4.6 중 4.0 사용, 양옆 0.3 여백) |
| 점유 면적 | `Data/StructureCatalog.asset` `_footprint*` | 화덕·난방기·정수기 **1×1** · 제작대·창고 **2×1** · 강화 난방로 **2×2** |

**좌표계 메모** (계획 §2.3): 열 좌표는 "좌측 최대 판자열 = 열 0" 고정 예약 — 본체 = 열 2~5.
행은 칸 후미(-Z)가 0. 항목 식별은 리스트 인덱스가 아니라 **서버 발급 Id**다.

## A. 그리드 설치 코어 (§2.3·§2.4)

- [x] **A1** 망치를 들고 칸 갑판을 겨누면 **점유 셀 영역 와이어 박스 + 반투명 실물
  고스트**가 셀에 스냅되어 따라온다. 초록 = 설치 가능 / 빨강 = 불가 *(1회차 통과)*
- [x] **A2** **Q/E 회전** — 프리뷰가 90° 단위로 돌고, 제작대(2×1)는 점유 가로·세로가
  스왑된다. 설치 확정 후 실물도 같은 방향이다 *(1회차 통과 — 최초 회전 시 실물이 길게
  늘어나는 버그 발견 → 칸 비균등 스케일 보정 `StructureAnchor` 신설로 수정 후 재확인)*
- [x] **A3** **R 종류 순환** — 설치 가능 종류만 돈다. **온실 돔이 목록에 없다** *(1회차 통과)*
- [ ] **A4** **한 칸에 다중 설치** — 소형 3개(화덕·난방기·정수기) + 제작대(회전 상태) +
  창고까지 한 칸에 공존한다
- [ ] **A5** **겹침 기각** — 기존 건축물 점유 셀 위 프리뷰가 빨강이고 우클릭이 기각된다.
  회전된 2×1의 실점유 기준으로 판정된다
- [ ] **A6** **경계** — 가장자리 여백(0.3 m 폭)을 찍으면 프리뷰가 **본체 끝 열로 스냅**된다
  (계획서 §4는 "기각"이었으나 **클램프로 구현 — 의도 편차**: 여백에 걸치는 설치가 없다는
  의도는 동일하고 UX가 낫다). 2×2가 본체 끝에 딱 맞게 들어간다
- [ ] **A7** **기관차 기각** — 기관차 갑판에는 프리뷰·설치가 성립하지 않는다
- [x] **A8** **자리 점유 차단** — 설치 자리(셀 영역)에 플레이어·몬스터가 서 있으면 빨강 +
  "자리에 사람·몬스터가 있어 설치할 수 없다" 안내 + 우클릭 기각 *(1회차 통과 — 개선 요청 반영분)*
- [ ] **A9** **창고 임시 가드** — 같은 칸에 창고 2개째 설치가 기각된다 (다른 칸은 허용).
  **2차에서 해제 예정**
- [ ] **A10** 비용 지불 — 설치 시 건자재가 종류별 비용만큼 차감되고, 부족하면 빨강 안내

## B. 상태 복제·뷰 스폰 (§2.6)

- [ ] **B1** 호스트 설치가 클라이언트에도 같은 칸·같은 셀·같은 회전으로 보인다 (역방향도)
- [ ] **B2** **후발 접속** — 여러 개 설치해 둔 상태에서 새 클라 접속 시 전부 동일 재구성
- [ ] **B3** **위조 기각** — 클라 조작 가정: 점유 셀·기관차·돔 설치 요청은 호스트 재판정
  (`CanPlaceStructure`)에서 기각된다 — 프리뷰와 호스트가 같은 순수 함수를 쓴다
- [ ] **B4** 재시작(숫자패드 +) 후 건축물이 전부 사라지고 Id 발급이 새로 시작된다

## C. 파괴·수리 (§2.1 — 규칙 유지 회귀)

- [ ] **C1** 넘패드 6으로 특정 건축물만 골라 손상 → 좌클릭 수리로 회복 (만피 초과 없음)
- [ ] **C2** 파괴 시 실물이 사라지고 **그 자리에 새로(다른 종류도) 지을 수 있다**
- [ ] **C3** **몬스터/QA 파괴 시 자원 반환이 없다** (요구사항 — 반환은 2차 철거 전용)
- [ ] **C4** 창고 파괴(칸 생존) → 내용물 보따리가 그 칸 갑판에 나온다 (현행 유지)
- [ ] **C5** **칸 파괴** → 그 칸 건축물 전원 소멸 + 창고 내용물은 지상 투척 (현행 유지)
- [ ] **C6** 칸 **이탈 중** 건축물: 실물이 칸을 따라가고, 피해가 무시되며(별도 표적 아님),
  재결합하면 그대로 복원된다. 소실 거리부터 표현이 꺼진다
- [ ] **C7** 소실 칸 자리 **재건** 시 옛 건축물 잔해가 함께 사라진다 (빈 그리드로 시작)

## D. 종류별 기능 재배선 (§2.7)

- [ ] **D1** **난방** — 난방기가 있는 칸 위에서 체온이 목표 온도로 수렴한다. 같은 칸에
  다른 건축물이 함께 있어도 성립한다 ("하나라도" 판정)
- [ ] **D2** **제작 지점** — 제작대/화덕/정수기 **실물 근처 + 시선**에서 해당 레시피가
  열린다. 실물이 칸 중앙이 아닌 구석 셀에 있어도 판정 지점이 실물을 따라간다
- [ ] **D3** **창고 접근** — 창고 실물 근처 + 시선에서 E로 열린다 (판정 지점 = 실물 중심)
- [ ] **D4** **강화 난방로 연료 합산** — 설치 수만큼 초당 소모가 붙고(0.6/s), HUD 소모율
  표시와 실제 소모가 일치한다. 파괴하면 즉시 빠진다

## E. 몬스터 관통 방지 (§2.10 — 최소 구현)

- [ ] **E1** 갑판 위 몬스터가 강화 난방로(2×2)를 **통과하지 못한다** (이동 취소)
- [ ] **E2** 막힌 몬스터가 길을 막은 건축물을 **공격 대상으로 전환**해 부순다
  (추가 AI 없음 — 최근접 표적 자연 발생)
- [ ] **E3** 지상 몬스터·플레이어 이동은 변화 없다 (플레이어는 콜라이더 충돌로 이미 차단)

## 알려진 이슈 (검증 실패가 아님 — 계획서 §5)

- **스폰·부활 지점과 건축 셀 겹침** (결정 ⑪ — 임시 조치 없음): 부활 지점(후미 칸 중앙)·
  초기 스폰(첫 화차 중앙) 셀에 건축물을 세우면 부활자가 콜라이더 안에 낙하할 수 있다.
  검증 중 해당 셀 설치를 피한다. 스폰·부활 재설계(이월)에서 해소.
- **그늘/난방 효과는 칸 단위 boolean 유지** — 난방기 여러 대 = 효과 중복 없이 연료만
  각각 소모 (의식적 선택, 밸런스 조정 대상 메모).
- **`Game.unity` 미적용** — 구 치수(3×3×12) 정렬 커밋과 함께 정적 Structure 제거 +
  스포너 배선 예정. 그전까지 인게임 진입은 `Game_ArtTest` 고정.
