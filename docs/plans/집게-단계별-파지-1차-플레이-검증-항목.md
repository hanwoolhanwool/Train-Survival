# 집게 단계별 파지 1차 플레이 검증 항목 — 등급 축 · 전환 게이트 · 동료 그랩

작성일: 2026-08-18 · 대상: `feat/structure-grid` · 상태: **검증 대기**
(구현: [집게-단계별-파지-그랩-계획.md](집게-단계별-파지-그랩-계획.md) §4 단계 1~4.
EditMode **525/525 통과** 상태에서 시작 — 기존 505 + 신규 20.
**파지 손 표현(단계 5)은 이번 범위가 아니다** — 집게는 여전히 오른손에 보인다)

> **1차 목표** (계획 문서): 집게 등급이 사거리·대상만 넓히는 것이 아니라 **"잡은 채로 무엇을 할 수
> 있는가"** 를 바꾼다. **1단계는 잡으면 손이 묶이고**, **2단계부터 잡은 채 한손 무기를 쓰며**,
> **양손 무기를 고르면 그랩이 풀린다**. 그리고 **2단계부터 동료를 끌어올 수 있다**.
> **검증 구성**: 원칙대로 **호스트 1 + 클라이언트 1** (MPPM 가상 플레이어).

---

## 0. 검증자가 먼저 읽을 것 — "회귀 아님" 두 가지

이번 차수는 **기능 추가가 아니라 제약 신설**이다. 아래 둘은 **결함으로 올리지 않는다.**

1. **M5 6차 이후의 감각이 의도적으로 사라졌다** (계획 §1.1).
   지금까지는 등급과 무관하게 "잡은 채 아무 무기로나 바꿔 쏘기"가 됐다. 기획서 v0.6이 이 결정을
   **부분 번복**해 자유 전환을 2·3단계의 보상으로 재배치했다. **1단계로 몬스터를 들고 리볼버를 쏘는
   플레이는 이제 성립하지 않는다** — 회귀가 아니라 설계 변경이다.

2. **1단계 집게로 몬스터가 여전히 잡힌다** (계획 §1.2).
   기획서 §3.1은 "몬스터 = 2단계부터"로 확정했지만, **몬스터 변종 체계를 다시 설계할 예정이라
   이번에는 에셋 값을 건드리지 않았다.** 기획서가 앞서 있고 구현이 뒤따르는 상태다.
   → 이번 차수에 **등급 부족 거부를 실제로 밟는 대상은 강화 자원(원목·광맥)과 플레이어 동료뿐**이다.

## A. 등급 축 개명 — 회귀 없음 (§3.1 단계 1)

개명(`GrabWeight` → `RequiredHarpoonTier`)은 **로직 무변경**이어야 한다. 아래가 하나라도 어긋나면
`FormerlySerializedAs` 매핑이 깨진 것이므로 **즉시 중단**하고 보고한다.

- [ ] **A1** 1단계 집게로 **목재·돌·고철** 노드가 그대로 채집된다
- [ ] **A2** 1단계 집게로 **원목(요구 2)** 을 쏘면 거부되고 "**너무 무겁다 — 강화 집게가 필요하다**"가 뜬다
- [ ] **A3** 2단계로 승급하면 **원목이 잡히고**, **광맥(요구 3)** 은 여전히 거부된다
- [ ] **A4** 3단계에서 **광맥이 잡힌다**
- [ ] **A5** 1단계로 **이탈 칸 손잡이**를 잡아 저항할 수 있다 (등급 잠금 없음)
- [ ] **A6** 1단계로 **창고 보따리**를 운반할 수 있고, **투척 비행 중**인 보따리는 3단계만 잡힌다
- [ ] **A7** 1단계로 **일반형·돌진형 몬스터**가 잡힌다 — **§0-2에 따라 결함 아님**

## B. 1단계 — 잡으면 손이 묶인다 (§3.2 `Deny`)

- [ ] **B1** 1단계로 무언가를 잡은 상태(릴 감기 또는 파지)에서 **1~5 어느 키를 눌러도 슬롯이 안 바뀐다**
- [ ] **B2** 거부 순간 **화면에 이유가 뜬다** — "잡은 손이 묶였다 — 강화 집게라야 든 채로 무기를 바꾼다"
- [ ] **B3** **연타해도 문구가 쌓이지 않는다** — 같은 그랩 동안 문구는 **첫 회만**
- [ ] **B4** 그런데 **연출(슬롯이 붉게 튕김)은 누를 때마다** 나간다 (반응 없음으로 보이면 안 된다)
- [ ] **B5** 놓고 나서(우클릭) 다시 잡으면 **문구가 또 뜬다** — 억제 경계는 "한 번의 그랩"이다
- [ ] **B6** **잡지 않은 상태**에서는 1단계도 슬롯이 자유롭게 바뀐다 (평상시 조작 무변경)
- [ ] **B7** **훅이 날아가는 중(명중 전)** 에는 슬롯을 바꿀 수 있다 — 아직 잡은 것이 없다
- [ ] **B8** **이탈 저항 중(손잡이 그랩)** 에도 1단계는 전환이 막힌다
      — "잡을 수는 있고, 잡은 동안 못 바꿀 뿐"이 의도다

## C. 2·3단계 — 잡은 채 싸운다 (§3.2 `Allow` / `ReleaseThenAllow`)

- [ ] **C1** 2단계로 잡은 채 **리볼버로 전환**된다 — 그랩은 **유지**되고 좌클릭이 사격이 된다
- [ ] **C2** 2단계로 잡은 채 **마체테**로도 전환된다 (한손)
- [ ] **C3** 2단계로 잡은 채 **자원 칸·빈 칸**으로도 전환된다
- [ ] **C4** 2단계로 잡은 채 **샷건**을 고르면 **그랩이 먼저 풀리고** 샷건으로 바뀐다.
      잡았던 대상은 **그 자리에 떨어진다** (우클릭 놓기와 같은 결과)
- [ ] **C5** **라이플**도 샷건과 같다 (양손 등재)
- [ ] **C6** 3단계에서도 C1~C5가 같다
- [ ] **C7** 집게 슬롯으로 **되돌아오면** 좌클릭 투척 / 우클릭 놓기가 그대로 동작한다
- [ ] **C8** **승인 대기 중(훅이 맞은 직후)** 양손 무기로 바꿔도 **뒤늦게 잡히지 않는다**
      — 그랩이 성립하지 않고 무기만 바뀐다
- [ ] **C9** 전환으로 풀린 뒤 집게는 **미스 페널티 없이 쿨다운만** 돈다 (우클릭 취소와 같은 대우)

## D. 2인 이탈 저항 — 전환과 저항 인원 (§6.1)

- [ ] **D1** 둘이 손잡이를 잡아 저항하는 중, **한쪽이 2단계로 샷건 전환** → 그쪽 그랩만 풀리고
      **저항 인원이 정확히 1 줄어든다** (칸이 다시 멀어지기 시작)
- [ ] **D2** 1단계 쪽은 전환이 막혀 **저항이 유지된다**
- [ ] **D3** 저항 인원 변화가 **호스트·클라이언트 양쪽 화면에서 같게** 보인다

## E. 동료 그랩 — 끌어오기 (§3.5)

- [ ] **E1** 1단계로 동료를 쏘면 **거부**되고 등급 부족 문구가 뜬다
- [ ] **E2** 2단계로 동료를 쏘면 **끌려온다** — **멀쩡히 서 있는 동료도** 잡힌다 (다운 조건 없음)
- [ ] **E3** **끌리는 쪽 화면이 튀지 않는다** — 지연 없이 부드럽게 당겨진다 (소유자 구동 견인)
- [ ] **E4** 끌리는 동안 **이동 입력이 먹지 않는다**. 그러나 **시선(마우스)은 돌릴 수 있다**
- [ ] **E5** 도착하면 **그 자리에 선다** — 수납되지도, 들려 있지도 않는다. 이동 입력이 곧바로 돌아온다
- [ ] **E6** 그래버가 **우클릭으로 놓으면** 즉시 풀리고 동료가 그 자리에 선다
- [ ] **E7** **자기 자신은 못 잡는다** (조준해도 자기 콜라이더가 잡히지 않는다)
- [ ] **E8** **이미 다른 사람이 끄는 동료**는 "다른 사람이 잡고 있다"로 거부된다
- [ ] **E9** 끌려오는 동료의 위치가 **제3의 피어 화면에서도** 같게 보인다
- [ ] **E10** 끌리는 동안 **다른 조작(제작대·창고 열기)** 이 막히거나 이상하게 겹치지 않는다

## F. 낙하 중 구조 — 그랩이 이탈 사망을 이긴다 (§3.5)

- [ ] **F1** 열차 **후미 40 m 사망선 근처까지 뒤처진 동료**를 2단계 집게로 잡으면,
      **끌려오는 동안 이탈 사망이 나지 않는다** (사망선을 지나쳐도 유예된다)
- [ ] **F2** 끌어올려 도착하면 정상 복귀 — 사망·부활 절차가 **아예 일어나지 않았다**
- [ ] **F3** 구조에 **실패해(중간에 놓아) 다시 뒤처지면** 다음 순간 **정상적으로 이탈 사망**한다
      — 유예는 견인 중에만이다
- [ ] **F4** **공중에 떠서 떨어지는 동료**도 같은 방식으로 잡아 끌어올릴 수 있다

## G. 끊기는 경우 — 로프가 남지 않는다 (§3.5 구멍 표)

- [ ] **G1** 끌려오던 동료가 **몬스터에게 죽으면** 그랩이 즉시 끊기고 **로프·훅이 사라진다**
- [ ] **G2** 그 동료가 **부활한 뒤 정상적으로 움직인다** — 구속이 남아 조작이 막히지 않는다
- [ ] **G3** 끌려오던 동료가 **접속을 끊으면** 그래버 쪽 로프가 정리된다
- [ ] **G4** **그래버가 죽거나 접속을 끊어도** 끌리던 동료가 구속 상태로 굳지 않는다
- [ ] **G5** 위 어느 경우에도 **콘솔에 에러가 없다**

## H. 재접속·세션 (회귀)

- [ ] **H1** 클라이언트가 나갔다 재접속해도 **접속 거부(ClosedByRemote)가 없다**
      (프리팹에 컴포넌트가 하나 늘었다 — `GlobalObjectIdHash`는 그대로임을 확인했지만 실측한다)
- [ ] **H2** 재접속 후 집게 등급·핫바 선택이 정상 복원된다
- [ ] **H3** 4인(호스트 1 + 클라 3)에서 **동료를 서로 끌어보며 장난 여지를 체감한다** (§3.5-2)
      — 뿌리치기가 없어도 견딜 만한지가 판단 대상이다. 결함이 아니라 **설계 피드백**으로 적는다

## I. 이번 차수에 보이지 않는 것 (2차 예정)

- [ ] **I1** 2단계 이상에서도 **집게는 여전히 오른손에 보인다** — 파지 손 전환은 단계 5(2차)다.
      "왼손 집게 + 오른손 총" 그림은 **아직 나오지 않는 것이 정상**이다
- [ ] **I2** **거부음이 없다** — 프로젝트에 오디오 인프라가 없어 소리는 오디오 도입 차수로 넘겼다.
      연출은 시각(슬롯 붉은 튕김)만이다
